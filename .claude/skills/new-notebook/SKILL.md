# Новая лабораторная

Правила — `notebooks/README.md` и `docs/conventions/python.md`. Пример — `notebooks/src/la/normal_equations.py`.

## Шаги

1. **Исходник** `notebooks/src/<раздел>/<имя>.py` в формате Jupytext (`# %%`, `# %% [markdown]`). Первая ячейка — название, урок, время, ссылки, цели в измеримых глаголах.
2. **Настройка:** импорт `mlf.check`; в Colab — установка пакета курса из GitHub. Никаких данных из интернета: только генерация с `seed` или файлы из репозитория.
3. **Задания:** каждое — короткая постановка, ячейка с решением между `# BEGIN SOLUTION` и `# END SOLUTION`, сразу за ней ячейка проверки (`check.close`, `check.shape`, `check.passed`). Формы массивов проверяются явно.
4. **Код из сниппетов:** данные и эталонные функции бери из `code/snippets` (директива `# snippet: путь#регион`), чтобы урок и лабораторная не расходились.
5. **Последнее задание — исследование** без автопроверки, с вопросом для самопроверки.
6. **Собери и проверь:**
   ```bash
   python scripts/build_notebooks.py --solutions /tmp/nb
   pytest --nbmake /tmp/nb
   ```
   Ученическая версия (`notebooks/<раздел>/<имя>.ipynb`) должна содержать `raise NotImplementedError` вместо решений и не содержать выходов.
7. Ссылка Colab — на тег релиза, не на ветку.
