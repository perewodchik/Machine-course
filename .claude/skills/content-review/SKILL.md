# Ревью контента

Пройди чек-лист и выдай список проблем с приоритетом (критично / важно / мелочь), указывая файл и место.

## Математика
- [ ] Все формулы с выводом есть в `content/formulas` и проходят `cd code && pytest`.
- [ ] Условия применимости указаны (обратимость, $\Sigma \succ 0$, $\det A > 0$, симметричность).
- [ ] Нет известных ловушек: $(AB)^\top \ne A^\top B^\top$; PSD определена только для симметричных матриц; MLE дисперсии делит на $n$; $\nabla_A \log\lvert\det A\rvert = A^{-\top}$ (с модулем).
- [ ] Числа в тексте совпадают с кодом (есть тест).

## Педагогика (`docs/conventions/pedagogy.md`)
- [ ] Урок разбит на циклы по 7–12 минут, в каждом — попытка или предсказание и проверка.
- [ ] Каждая цель из карточки программы проверяется хотя бы одним заданием.
- [ ] Перед выводом есть план из подцелей; шаги с обоснованием.
- [ ] Неверные варианты ответов отражают типичные ошибки, у каждого есть разбор.
- [ ] Понятно, зачем это в ML: ссылка на раздел CS229 по изданию и названию.

## Нотация и термины (`docs/conventions/notation.md`)
- [ ] Обозначения как в CS229; расхождения с русской традицией пояснены на полях.
- [ ] Английский термин при первом появлении; термин есть в `content/glossary.yaml`.
- [ ] Символы с ролями — через `\sym`; цветных ролей не больше трёх.

## Текст и типографика (`docs/conventions/authoring.md`)
- [ ] Тон учебника: спокойно, точно, без маркетинга и без «очевидно».
- [ ] «Ёлочки», длинное тире, неразрывные пробелы; десятичная точка в числах.
- [ ] Матрицы — только выключными формулами или `smallmatrix`.

## Доступность
- [ ] У рисунков есть подпись и текстовая альтернатива; у виджетов — управление с клавиатуры.
- [ ] Цвет не единственный носитель смысла.

## Источники (`docs/conventions/sources.md`)
- [ ] Нет скопированного текста или рисунков из чужих курсов.
