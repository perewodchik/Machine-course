# Новая мини-игра

Контракт — `src/games/_engine/types.ts`. Принципы — `docs/conventions/games.md`.

## Проверь идею до кода

1. **Игровое действие — это математическая операция.** Если игру можно пройти, не понимая понятия, это викторина, а не игра.
2. **Обратная связь — математическое следствие на рисунке**, а не «неверно».
3. **Очки — метрика самого понятия:** точность, число ходов, правило Брайера для вероятностей. Не скорость.
4. **Партия 2–5 минут**, уровни подводят к граничному случаю (вырожденная матрица, отрицательный определитель, расходимость спуска).
5. **Разбор после уровня:** 1–2 вопроса, которые переводят стратегию в формулу.

## Шаги

1. Опиши игру в `docs/program/<модуль>.md` в карточке урока: механика, понятие, критерий успеха.
2. `src/games/<id>/model.ts`: `init`, чистый `step`, `status`, `score`, `describe`, `hint`, `generate(rng, difficulty)`. Случайность — только из `rng`, время — действием `tick`.
3. Тесты: юнит-тесты редьюсера; property-based (fast-check): одинаковый seed даёт одинаковую партию, каждый сгенерированный уровень решается ботом; Playwright с `?seed=`: уровень проходится только с клавиатуры, axe без ошибок.
4. Представление в `GameShell`: пауза, сброс, уровни, подсказки, справка по клавишам. Таймера по умолчанию нет.
5. В журнал событий уходит `GameResult`: игра — практика, на статус урока не влияет.
