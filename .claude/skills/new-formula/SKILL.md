# Новая формула или вывод

Формулы курса — данные: YAML в `content/formulas/`, тип описан в `src/lib/content/types.ts`, проверка — `code/mlf/formulas.py`.

## Шаги

1. **Выбери тип.** Атомарное тождество, на которое ссылаются шаги других выводов (`(AB)ᵀ = BᵀAᵀ`), — правило `rule.*` в `formulas/rules/`. Результат с выводом — формула `f.*` в `formulas/<раздел>/`.
2. **Опиши символы.** Каждому — `name`, `tex`, `meaning`, `shape` (`[n, d]`, вектор-столбец `[d, 1]`), `role` (`data` → бирюза, `param` → оранжевый, `target` → пурпур, `aux` → карандаш). Цветных ролей не больше трёх. Для обратимых или положительно определённых матриц укажи `sample: invertible | spd`, для положительных скаляров ($\sigma$, шаг) — `sample: positive` и `shape: []`.
3. **Запиши TeX** в одинарных кавычках, блочным стилем YAML. Символы с ролями — через `\sym{name}{tex}`.
4. **Вывод:** `plan` из 2–4 подцелей, затем шаги. У каждого шага: `goal`, `tex` (изменившуюся часть оберни в `\changed{…}`), `by` (ID правил и понятий), `note` (одна фраза «почему»), `check`.
5. **Проверки** — выражения NumPy над символами:
   - `same: py` — значение совпадает с предыдущим шагом `same`;
   - `gradient: py, wrt` — градиент последнего `same` (сверяется с конечными разностями);
   - `stationary: lhs, rhs` — равенство в найденной точке;
   - `solution: py, wrt` — точка минимума (в ней градиент должен обратиться в ноль);
   - для правил — `identity: lhs, rhs` или `gradient: f, grad, wrt`.
6. **Запусти** `cd code && pytest tests/test_formulas.py`. Затем испорти один шаг (например, забудь транспонирование) и убедись, что тест падает. Верни шаг.
7. **Условия применимости** (`conditions`) и типичные ошибки (`pitfalls`) обязательны, если формула верна не всегда (обратимость, $\det A > 0$, симметричность).
8. **Связи:** `dependsOn` (понятия и правила), `cs229` (издание + название раздела), `usedIn`.

## Частые ловушки

- `"\theta"` в двойных кавычках YAML превращается в табуляцию и `heta`. Только `'…'` или `|`.
- Двоеточие с пробелом в тексте без кавычек ломает YAML. Пояснения — тоже в кавычках.
- Градиент по вектору имеет ту же форму, что вектор (нотация CS229, не MML).
- В выражениях `check` нет встроенных функций Python (`len`, `range`, `sum`) и могут падать методы массивов (`.sum()`): пишите `y.size`, `np.sum(…)`, `np.einsum(…)`.
