# Новый виджет

Читай `src/README.md` (слои и обязательные свойства) и `src/design-system/README.md` (цвета, подписи, клетка).

## Структура

```
src/widgets/<раздел>/<имя>/
  model.ts         # чистые функции состояния и математики, без DOM
  model.test.ts    # Vitest: инварианты и эталонные значения (из NumPy)
  <Имя>.tsx        # представление на widgets/_kit
  index.ts         # meta { id, title, concepts } и тип пропсов
  README.md        # что показывает, пропсы, пример в MDX
```

## Шаги

1. **Модель первой.** Всё, что можно посчитать без экрана, — в `model.ts`, с тестами. Эталонные числа считай в NumPy (`code/`), а не на глаз.
2. **Пропсы для переиспользования:** `initial`, `lock` (зафиксировать часть параметров для урока), `show` (какие слои видны), `seed`. Пропсы только сериализуемые.
3. **Представление** строй на `widgets/_kit` (`Plane`, `Point`, `Vector`, `Line`, `Ellipse`, `Histogram`, `ParamSlider`, `Readout`). Прямые зависимости от Mafs или d3 в виджете запрещены.
4. **Цвета:** роли символов урока (`sym-1…3`), вспомогательное — карандашом (`--ink-3`, пунктир). Подписи на рисунке шрифтом формул (`--font-math`) с подложкой цвета фона. Бегунок окрашен в цвет величины, которую двигает.
5. **Доступность:** управление стрелками и числовыми полями (альтернатива перетаскиванию), описание состояния в `aria-live` с задержкой, видимый фокус.
6. **Детерминизм и SSR:** состояние из `seed`, без `Math.random` и `Date`; `viewBox` фиксированный и пересчитывается по ширине.
7. **Витрина:** добавь виджет на `/lab` в обоих темах; скриншот-тест Playwright.
8. Перед ревью — скилл `design-critique` по скриншоту.
