# prototype — прототип дизайна

Статичные HTML-страницы, по которым утверждается визуальный язык до сборки сайта. Используют настоящие токены из `src/design-system/tokens/tokens.css`, шрифты и KaTeX 0.19 лежат локально в `vendor/`.

```bash
npx http-server -p 8123 -c-1 .      # из корня репозитория
# открыть http://localhost:8123/prototype/
```

| Страница | Что показывает |
|---|---|
| `index.html` | Главная: продолжить урок, списки уроков с галочкой «знаю», карта курса, игры, лабораторные |
| `lesson.html` | Урок V.1: заметки на полях, живые символы, интерактивный рисунок, карточка формулы с выводом по шагам, проверка, правка красной ручкой, ячейка кода, упражнение |
| `game.html` | Игра «Матрица-пазл»: подобрать матрицу 2×2 по образам базисных векторов |
| `design-system.html` | Витрина: токены (значения и контраст читаются из CSS), символы, типографика, компоненты, блоки |

Параметры адреса: `?theme=dark` — тёмная тема; `?demo=1` — показать подсветку символа и ответы (для скриншотов).

Скриншоты лежат в `docs/design/screenshots/`. Прототип не станет кодом сайта: на этапе 1 его стили разойдутся по компонентам `src/`.
