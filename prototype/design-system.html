Дизайн-система «Тетрадь в клетку»

Курс выглядит как аккуратная рабочая тетрадь: белая бумага, клетка там, где есть координаты, поля с красной линией для заметок и три ручки с понятными ролями.

  1. Бумага, а не экран. Холодный белый фон без крема и градиентов. Клетка появляется только внутри рисунков, где у неё есть смысл.
  2. Поля тетради. Красная линия отделяет текст от заметок, английских терминов и ссылок на CS229. На узком экране заметки встают в текст.
  3. Синяя ручка — то, что делает ученик: ссылки, кнопки, ползунки, ввод, упражнения. Красная — ошибки и поправки, зелёная — «верно» и галочка «знаю». Ручки никогда не красят символы.
  4. Цвет символа закреплён за ролью и совпадает в формуле и на рисунке. Цветов три, вспомогательное — карандашом.
  5. Текст важнее интерфейса. Literata для чтения, IBM Plex Sans для управления. Без заглавных меток, эмодзи и декоративных иконок.
  6. Скругление растёт с размером: 3 px у метки, 6 px у кнопки, 10 px у рисунка. Теней нет, кроме всплывающих слоёв.

Цвет

Значения читаются из токенов текущей темы. Контраст посчитан к фону страницы; для текста нужно не меньше 4.5:1, для рамок контролов — 3:1.

Педагогические блоки

Определение 4.1. Ненулевой вектор \(v\) называется собственным для матрицы \(A\), если \(Av = \lambda v\) для некоторого числа \(\lambda\).

Теорема 4.3. У симметричной матрицы собственные значения вещественны, а собственные векторы можно выбрать ортонормированными.

Интуиция. Собственный вектор матрица только растягивает: направление остаётся тем же.

Типичная ошибка. Транспонирование меняет порядок множителей: \((AB)\T = \htmlClass{struck}{\,A\T B\T\,}\;\htmlClass{fix}{B\T A\T}\).

Упражнение 4.2. Найдите собственные значения матрицы \(\begin{pmatrix}2&1\\1&2\end{pmatrix}\).

Вывод. Пунктирная линейка отмечает рассуждение, которое можно пропустить при повторении.

Чего не делаем

  1. Кремовый фон, контрастные засечки в заголовках и терракотовый акцент — это самый узнаваемый шаблон сгенерированных страниц.
  2. Градиенты, стекло, тени у карточек, одинаковые карточки вместо текста.
  3. Метки капслоком над заголовками и строки через средние точки.
  4. Эмодзи и иконки у каждого пункта; стрелка «→» в конце ссылок.
  5. Анимация при прокрутке. Движение только там, где оно объясняет математику.
  6. Дефолтная палитра Tailwind: она отключена в теме, классы вроде bg-indigo-500 не существуют.
