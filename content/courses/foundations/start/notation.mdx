## Нотация CS229

Курс готовит к чтению конспекта CS229, поэтому пишет так же, как он. Проверим, как вы прочитаете типичную формулу.

<Exercise
  title="Предскажите"
  id="start9.predict-xi"
  spec={{
    kind: "predict",
    prompt: "В формуле $J(\\theta) = \\tfrac12 \\sum_{i=1}^{n} \\bigl(h_\\theta(x^{(i)}) - y^{(i)}\\bigr)^2$ что такое $x^{(i)}$?",
    options: [
      { text: "Признаки $i$-го объекта — вектор из $d$ чисел", correct: true, why: "Номер объекта пишут сверху в скобках, чтобы нижний индекс остался для номера признака." },
      { text: "$x$ в степени $i$", why: "Скобки в верхнем индексе отличают номер от степени. Степень пишут без скобок: $x^2$." },
      { text: "$i$-й признак", why: "Признак — нижний индекс: $x_j$. Сумма идёт по объектам до $n$, а не по признакам." },
    ],
    reveal: "$x^{(i)}$ — $i$-й объект. Его $j$-й признак — $x^{(i)}_j$, а все объекты — строки матрицы $X$.",
  }}
/>

| Запись | Что значит |
|---|---|
| $n$, $d$ | число объектов и число признаков |
| $x^{(i)} \in \mathbb{R}^d$ | признаки $i$-го объекта, вектор-столбец |
| $x_j$, $x^{(i)}_j$ | $j$-й признак; $j$-й признак $i$-го объекта |
| $X \in \mathbb{R}^{n \times d}$ | матрица признаков: строка $i$ — объект $x^{(i)}$ |
| $y^{(i)}$, $y \in \mathbb{R}^{n}$ | ответ $i$-го объекта; вектор всех ответов |
| $\theta$ | веса, или параметры, модели |
| $h_\theta(x)$ | предсказание модели с весами $\theta$ на объекте $x$ |
| $J(\theta)$ | функция потерь |
| $\ell(\theta)$ | логарифм правдоподобия |
| $\nabla_\theta J$ | градиент — той же формы, что $\theta$ |
| $\alpha$ | шаг градиентного спуска |
| $p(y \mid x; \theta)$ | вероятность $y$ при данном $x$; $\theta$ — параметр, а не случайная величина |

Векторы — столбцы, скалярное произведение — $x^\top y$, числа — с десятичной точкой: $0.5$, как в коде.

<Note label="Обозначение">В старых конспектах Эндрю Ына число объектов — $m$, признаков — $n$. Курс пишет, как конспект 2026 года: $n$ и $d$.</Note>

<Note label="По-английски">Обозначения — *notation*, конспект лекций — *lecture notes*.</Note>

## Переводчик

Русские учебники пишут те же вещи иначе, а некоторые символы и в самом CS229 значат разное в разных главах.

<Exercise
  title="Предскажите"
  id="start9.predict-ell"
  spec={{
    kind: "predict",
    prompt: "В учебнике К. В. Воронцова выборка записана как $X^\\ell = (x_i, y_i)_{i=1}^{\\ell}$. Что здесь $\\ell$?",
    options: [
      { text: "Число объектов", correct: true, why: "У Воронцова $\\ell$ — длина выборки. В курсе и в CS229 это $n$." },
      { text: "Логарифм правдоподобия", why: "Так $\\ell(\\theta)$ обозначает CS229. Один символ — два смысла: поэтому их приходится переводить." },
      { text: "Номер слоя нейросети", why: "Номер слоя в CS229 пишут в квадратных скобках, $[\\ell]$, и только в главах о нейросетях." },
    ],
    reveal: "$\\ell$ у Воронцова — число объектов, $n$ в курсе. Таблица ниже собирает такие переводы.",
  }}
/>

| Русский учебник | Курс и CS229 |
|---|---|
| $\ell$ объектов (Воронцов) | $n$ объектов |
| $\mathsf{M}\xi$, $\mathsf{D}\xi$ | $\mathbb{E}[X]$, $\operatorname{Var}(X)$ |
| $\operatorname{Sp} A$ | $\operatorname{tr} A$ |
| $\ln x$, $\lg x$ | $\log x$, $\log_{10} x$ |
| $[x > 0]$ — скобка Айверсона | $1\{x > 0\}$ |
| $(x, y)$ — скалярное произведение | $x^\top y$ или $\langle x, y \rangle$ |
| $0{,}5$ | $0.5$ |

Символы с несколькими смыслами курс разводит так:

| Символ | Смыслы | Как отличить |
|---|---|---|
| $\Sigma$ | ковариационная матрица; знак суммы | знак суммы крупнее и стоит перед слагаемым; в разложении SVD курс пишет $USV^\top$ |
| $\lvert\Sigma\rvert$ | определитель | у матрицы черты — это $\det \Sigma$, а не модуль |
| $\sigma$ | стандартное отклонение; сигмоида | сигмоиду курс, как CS229, пишет $g(z)$ |
| $\lambda$ | собственное значение; коэффициент регуляризации | собственное значение — с матрицей: $\lambda_i(A)$ |
| $\ell$ | логарифм правдоподобия; номер слоя | номер слоя — в скобках: $[\ell]$ |
| $J$ | функция потерь; якобиан | якобиан — с индексом: $J_f$ |

<Block kind="pitfall">

Читать $x^{(i)}$ как степень и $\lvert\Sigma\rvert$ как модуль. В плотности многомерного нормального распределения стоит определитель:

$$
\lvert\Sigma\rvert = \struck{\;\text{модуль } \Sigma\;}\;\; \fix{\det \Sigma}
$$

</Block>

    ],

## Итог

- $n$ объектов, $d$ признаков; $x^{(i)}$ — объект (номер сверху в скобках), $x_j$ — признак; $X$ — объекты по строкам.
- $h_\theta(x)$ — модель, $J(\theta)$ — потери, $\ell(\theta)$ — логарифм правдоподобия, $\nabla_\theta J$ — градиент формы $\theta$.
- $\lvert\Sigma\rvert = \det \Sigma$; сигмоида — $g$; номер слоя — $[\ell]$. $\mathsf{M}$, $\mathsf{D}$, $\operatorname{Sp}$, $\ell$ объектов — это $\mathbb{E}$, $\operatorname{Var}$, $\operatorname{tr}$, $n$.
