## Массивы и формы

В NumPy вектор, матрица и таблица данных — один тип, `np.ndarray`. У массива есть **форма** `shape` — кортеж размеров по осям. Начнём с самого простого массива.

Данные в курсе хранят так, как в CS229: **матрица признаков** `X` формы `(n, d)` — строка на объект, столбец на признак, — ответы `y` формы `(n,)`, веса `theta` формы `(d,)`. У одномерного массива одна ось; у столбца `(n, 1)` и строки `(1, n)` — две. Из вектора столбец делают так: `y.reshape(-1, 1)` или `y[:, None]`; обратно — `y_col.ravel()`.

Индексация начинается с нуля: `X[0]` — первый объект (строка формы `(d,)`), `X[:, 1]` — второй признак у всех объектов (форма `(n,)`), `X[2, 1]` — одно число.

<Note label="Обозначение">В формулах $x^{(i)}$ — $i$-й объект, вектор-столбец из $d$ чисел. В коде это `X[i]`: одномерный массив формы `(d,)`, а нумерация идёт с нуля.</Note>

<Note label="По-английски">Массив — *array*, форма — *shape*, ось — *axis*.</Note>

## Операции: @, транспонирование, broadcasting

Арифметика в NumPy по умолчанию поэлементная. Это главный источник ошибок при переводе формул в код.

<Exercise
  title="Предскажите"
  id="start8.predict-star"
  spec={{
    kind: "predict",
    prompt: "$\\texttt{A}$ — матрица $2 \\times 2$. Чем отличаются $\\texttt{A * A}$ и $\\texttt{A @ A}$?",
    options: [
      { text: "$\\texttt{A * A}$ возводит каждый элемент в квадрат, $\\texttt{A @ A}$ — матричное произведение $A^2$", correct: true, why: "$\\texttt{*}$ работает поэлементно, $\\texttt{@}$ — по правилу «строка на столбец»." },
      { text: "Ничем: оба — матричное произведение", why: "Так было в старом классе $\\texttt{np.matrix}$. У обычного массива $\\texttt{*}$ — поэлементное умножение." },
      { text: "$\\texttt{A * A}$ — матричное произведение, $\\texttt{A @ A}$ — поэлементное", why: "Наоборот: $\\texttt{@}$ появился в Python именно для матричного умножения." },
    ],
    reveal: "$\\texttt{A * A}$ — поэлементно, $\\texttt{A @ A}$ — матрично. Формула $X\\theta$ в коде — $\\texttt{X @ theta}$, а не $\\texttt{X * theta}$.",
  }}
/>

`A @ B` — матричное произведение: внутренние размеры должны совпадать, `(n, d) @ (d,)` даёт `(n,)`. `A.T` — транспонирование. Остальная арифметика — `+`, `-`, `*`, `/`, `**`, `np.exp`, `np.log` — поэлементная.

Массивы разных форм NumPy согласует правилом **broadcasting**: формы выравниваются по правому краю, и ось размера $1$ (или отсутствующая) растягивается до нужной длины. Поэтому `X - X.mean(axis=0)` вычитает из каждой строки `(n, d)` строку средних `(d,)`: так центрируют признаки.

**Агрегаты** — `sum`, `mean`, `max` — сворачивают ось, указанную в `axis`: `X.mean(axis=0)` — среднее по объектам, форма `(d,)`; `X.sum(axis=1)` — сумма по признакам, форма `(n,)`; без `axis` — одно число на весь массив.

<Note label="По-английски">Матричное произведение — *matrix product*, поэлементные операции — *elementwise operations*, растяжение форм — *broadcasting*.</Note>

<Block kind="pitfall">

Смешать `(n,)` и `(n, 1)`. Например, ответы прочитали из файла столбцом. Broadcasting молча превращает разность в матрицу `n × n`:

```python
y_col = y.reshape(-1, 1)        # (n, 1)
residuals = X @ theta - y_col   # (n, n)!
```

Функция потерь посчитается — и будет неверной. Проверяйте формы: `residuals.shape` должен быть `(n,)`.

</Block>

## Векторизация

Формулу $J(\theta) = \tfrac12 \sum_i \bigl(\theta^\top x^{(i)} - y^{(i)}\bigr)^2$ можно перевести в код двумя циклами — по объектам и по признакам. А можно одной строкой, как матричную запись из урока 0.4: $J(\theta) = \tfrac12 \lVert X\theta - y \rVert^2$.

**Векторизация** — замена цикла по объектам операцией над всем массивом. Сумма по объектам становится произведением матриц или агрегатом, как в уроке 0.4: $\sum_i x_i y_i$ — `x @ y`, $\sum_i 1\{y^{(i)} = k\}$ — `(y == k).sum()`. Случайные числа в курсе берутся из генератора с явным seed: `rng = np.random.default_rng(0)`, затем `rng.normal(...)`, `rng.uniform(...)`. Тогда эксперимент повторяется, а функции не мешают друг другу.

<Note label="По-английски">Векторизация — *vectorization*, генератор случайных чисел — *random number generator*.</Note>

<Block kind="pitfall">

Писать `A * B` вместо `A @ B` и `np.random.seed(0)` вместо `np.random.default_rng(0)`. Первое считает другое произведение; второе меняет общее состояние генератора для всей программы, и любая функция, которая тоже берёт случайные числа, сдвигает результаты остальных.

</Block>

## Итог

- Форма — кортеж размеров: `X` — `(n, d)`, `y` и `theta` — одномерные. `(n,)`, `(n, 1)` и `(1, n)` — разные массивы.
- `@` — матричное умножение, `*` — поэлементное, `.T` — транспонирование. Broadcasting растягивает оси размера 1, выравнивая формы по правому краю; `axis` указывает ось, которую сворачивает агрегат.
- Цикл по объектам заменяют выражением над массивами: $\tfrac12 \lVert X\theta - y \rVert^2$ — `0.5 * r @ r`, где `r = X @ theta - y`. Случайные числа — из `np.random.default_rng(seed)`.
