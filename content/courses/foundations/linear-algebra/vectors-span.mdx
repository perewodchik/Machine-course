## Векторы

Квартира из урока 0.1 с площадью, этажом и годом постройки — это три числа, вектор $x \in \mathbb{R}^3$. Векторы складывают и умножают на числа. Начнём с плоскости, где это видно.

**Вектор** из $\mathbb{R}^d$ — упорядоченный набор из $d$ чисел; в курсе векторы пишут столбцами. Сумма векторов складывает координаты, произведение на число $c$ умножает каждую координату:

$$
a + b = \begin{pmatrix} a_1 + b_1 \\ \vdots \\ a_d + b_d \end{pmatrix}, \qquad c\, a = \begin{pmatrix} c\, a_1 \\ \vdots \\ c\, a_d \end{pmatrix} .
$$

На плоскости вектор — стрелка из начала координат. Сумма — диагональ параллелограмма, произведение на $c$ растягивает стрелку в $c$ раз; при $c < 0$ она разворачивается. В ML вектор — прежде всего набор признаков: объект $x^{(i)}$, веса $\theta$, градиент — все они живут в $\mathbb{R}^d$.

<Note label="По-английски">Вектор — *vector*, умножение на число — *scalar multiplication*.</Note>

## Комбинации и оболочка

Выражение $c_1 a + c_2 b$ с числами $c_1$, $c_2$ — **линейная комбинация** векторов $a$ и $b$. Какие точки можно получить такими комбинациями?

      { text: "Нет, только в точки на прямых через $a$ и через $b$", why: "Это комбинации с одним ненулевым коэффициентом. С двумя ненулевыми получается всё между этими прямыми." },

**Линейная оболочка** векторов $v_1, \ldots, v_k$ — множество всех их линейных комбинаций:

$$
\operatorname{span}(v_1, \ldots, v_k) = \bigl\{\, c_1 v_1 + \ldots + c_k v_k : c_1, \ldots, c_k \in \mathbb{R} \,\bigr\} .
$$

У двух непараллельных векторов плоскости оболочка — вся плоскость. У параллельных — прямая через начало координат: любая их комбинация кратна одному из них. У одного ненулевого вектора — тоже прямая, у нулевого — одна точка.

<Span n={1} initial="independent">Комбинация $c_1 a + c_2 b$: стрелки цветами коэффициентов. «Показать оболочку» рисует целые комбинации. Переключитесь на параллельные векторы: куда теперь можно попасть?</Span>

<Note label="Игра">«Попади в точку»: подберите коэффициенты при $a$ и $b$, чтобы попасть в цель, или докажите, что это невозможно. 3–5 минут. [Открыть игру](/games/span-hit/)</Note>

<Note label="По-английски">Линейная комбинация — *linear combination*, линейная оболочка — *span*.</Note>

<Block kind="pitfall">

Путать оболочку с самим набором векторов. Набор $\{a, b\}$ — две стрелки, а $\operatorname{span}(a, b)$ — бесконечное множество всех их комбинаций, например вся плоскость. Вопрос «лежит ли $t$ в оболочке» — это вопрос о коэффициентах: есть ли $c_1$, $c_2$ с $c_1 a + c_2 b = t$.

</Block>

## Линейная независимость

Если вектор можно получить из других, он ничего не добавляет к оболочке. Проверим это в $\mathbb{R}^3$.

<Exercise
  title="Предскажите"
  id="i1.predict-three"
  spec={{
    kind: "predict",
    prompt: "Любые ли три ненулевых вектора в $\\mathbb{R}^3$ порождают всё пространство $\\mathbb{R}^3$?",
    options: [
      { text: "Нет: если они лежат в одной плоскости, оболочка — эта плоскость", correct: true, why: "Например, $(1, 0, 0)$, $(0, 1, 0)$ и $(1, 1, 0)$: третий — сумма первых двух, и с третьей координатой ничего не сделать." },
      { text: "Да: векторов столько же, сколько координат", why: "Важно не число векторов, а то, не выражается ли один через другие. Три вектора одной плоскости порождают только её." },
      { text: "Да, если они попарно не параллельны", why: "Попарной непараллельности мало: $(1, 0, 0)$, $(0, 1, 0)$, $(1, 1, 0)$ попарно не параллельны, но лежат в одной плоскости." },
    ],
    reveal: "Нет. Если один вектор — комбинация остальных, он лишний: оболочка та же, что без него. Такие наборы называют зависимыми.",
  }}
/>

Векторы $v_1, \ldots, v_k$ **линейно независимы**, если нулевая комбинация бывает только с нулевыми коэффициентами:

$$
c_1 v_1 + \ldots + c_k v_k = 0 \;\Rightarrow\; c_1 = \ldots = c_k = 0 .
$$

Иначе набор **зависим**: найдётся ненулевой $c_j$, и тогда $v_j$ выражается через остальные. Два вектора зависимы, когда параллельны; три вектора $\mathbb{R}^3$ — когда лежат в одной плоскости.

На практике независимость проверяют рангом матрицы, составленной из векторов-столбцов: ранг — число независимых столбцов (урок I.6). Перед запуском предскажите оба ранга.

## Базис и размерность

Плоскость в $\mathbb{R}^3$, прямая на плоскости — тоже «пространства», только меньшие. Сколько векторов нужно, чтобы их описать?

<Exercise
  title="Предскажите"
  id="i1.predict-dim"
  spec={{
    kind: "predict",
    prompt: "Плоскость в $\\mathbb{R}^3$ проходит через начало координат. Сколько векторов нужно, чтобы их оболочка была ровно этой плоскостью?",
    options: [
      { text: "Два непараллельных вектора этой плоскости", correct: true, why: "Два непараллельных вектора плоскости порождают её всю, а один — только прямую." },
      { text: "Три: в $\\mathbb{R}^3$ всегда нужно три", why: "Три независимых вектора породят всё $\\mathbb{R}^3$, а не плоскость. Для плоскости хватает двух." },
      { text: "Один, лежащий в плоскости", why: "Оболочка одного ненулевого вектора — прямая." },
    ],
    reveal: "Два. Плоскость — двумерное подпространство: её базис состоит из двух векторов.",
  }}
/>

**Подпространство** — множество векторов, замкнутое относительно сложения и умножения на число: сумма двух его векторов и вектор, умноженный на число, снова в нём. Любая оболочка — подпространство, и любое подпространство содержит ноль. Прямая и плоскость через начало координат — подпространства, а прямая $y = 2x + 1$ — нет.

**Базис** подпространства — независимый набор векторов, оболочка которого — всё подпространство. Векторов в любом базисе поровну; их число — **размерность**. У $\mathbb{R}^d$ размерность $d$, стандартный базис — векторы $e_1, \ldots, e_d$ с единицей на одном месте. Каждый вектор подпространства раскладывается по базису единственным образом: коэффициенты — его координаты в этом базисе.

Зачем это в ML: признаки объектов — столбцы матрицы $X$. Если один признак — комбинация других, например цена в рублях и та же цена в долларах, столбцы зависимы. Тогда веса модели определяются неоднозначно — к этому вернёмся в уроке V.1.

<Note label="По-английски">Подпространство — *subspace*, базис — *basis*, размерность — *dimension*.</Note>

## Итог

- Векторы складывают покоординатно и умножают на число; $c_1 v_1 + \ldots + c_k v_k$ — линейная комбинация.
- $\operatorname{span}(v_1, \ldots, v_k)$ — все комбинации. Два непараллельных вектора плоскости порождают её всю, параллельные — только прямую.
- Векторы независимы, если $c_1 v_1 + \ldots + c_k v_k = 0$ только при нулевых $c$. Число векторов ничего не гарантирует: нужна независимость.
- Базис — независимый набор, порождающий подпространство; размерность — число векторов в базисе, у $\mathbb{R}^d$ это $d$.
