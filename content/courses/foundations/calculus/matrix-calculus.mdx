## Градиент по вектору

В уроке II.1 градиент считался по координатам: выписать $\partial f / \partial x_j$ для каждого $j$ и собрать столбец. Для выражений вроде $\tfrac12 \lVert X\theta - y \rVert^2$ с тысячами весов так не считают — пользуются правилами, выведенными один раз.

Первое правило — линейная функция. $b^\top x = \sum_i b_i x_i$, и $\partial / \partial x_k$ оставляет одно слагаемое $b_k$:

$$
\nabla_x\, b^\top x = b .
$$

Распишем по координатам: $x^\top A x = \sum_{i,j} A_{ij} x_i x_j$. Производная по $x_k$ собирает слагаемые, где $k$ стоит на месте $i$ ($\sum_j A_{kj} x_j = (Ax)_k$) и на месте $j$ ($\sum_i A_{ik} x_i = (A^\top x)_k$):

$$
\nabla_x\, x^\top A x = (A + A^\top)\, x .
$$

Для симметричной $A$ это $2Ax$ — аналог $(ax^2)' = 2ax$. Квадратичная форма видит только симметричную часть $A$ (урок I.5), и градиент — удвоенная симметричная часть, умноженная на $x$.

<Note label="По-английски">Градиент по вектору — *gradient with respect to a vector*, матричное дифференцирование — *matrix calculus*.</Note>

## Проверка размерностями и конечными разностями

Два способа поймать ошибку в матричном градиенте, не выводя его заново.

**Размерности.** Градиент по $\theta$ имеет форму $\theta$, и каждое слагаемое ответа — тоже. Для $J(\theta) = \tfrac12 \lVert X\theta - y \rVert^2$ с $X$ размера $n \times d$ кандидат $X^\top X\theta - X^\top y$ проходит: оба слагаемых — $d \times 1$. А $XX^\top \theta$ не определено, $X\theta - y$ имеет форму $n \times 1$ — их сразу можно отбросить.

**Конечные разности.** Численный градиент — центральная разность по каждой координате:

$$
\frac{\partial f}{\partial x_i} \approx \frac{f(x + h e_i) - f(x - h e_i)}{2h} .
$$

Для градиента по матрице то же делают по каждому элементу. Совпадение с формулой на случайной точке — сильное свидетельство; так проверяют все формулы этого курса и градиенты в библиотеках машинного обучения.

## Градиент по матрице

Градиент по матрице $A$ размера $m \times k$ — матрица той же формы из $\partial f / \partial A_{ij}$. Два правила нужны постоянно.

**След.** $\operatorname{tr}(AB) = \sum_{i,j} A_{ij} B_{ji}$, и $\partial / \partial A_{ij}$ оставляет $B_{ji}$ — индексы меняются местами:

$$
\nabla_A \operatorname{tr}(AB) = B^\top .
$$

**Логарифм определителя.** Для обратимой $A$

$$
\nabla_A \log\lvert\det A\rvert = A^{-\top} .
$$

Оба правила появляются в CS229 при выводе оценок максимального правдоподобия для гауссовского дискриминантного анализа («Generative learning algorithms»): $\log\lvert\Sigma\rvert$ из плотности нормального распределения (урок I.7) и квадратичная форма $(x - \mu)^\top \Sigma^{-1} (x - \mu) = \operatorname{tr}\bigl(\Sigma^{-1} (x - \mu)(x - \mu)^\top\bigr)$ дифференцируются по $\Sigma$ именно так.

<Block kind="pitfall">

Писать $\nabla_A \log\det A = A^{-\top}$ без модуля. Логарифм определён только при $\det A > 0$, и формула с модулем покрывает оба знака. Вторая тонкость: если $A$ обязана быть симметричной, как ковариация, «симметричная» производная выглядит иначе. CS229 это ограничение игнорирует — точка минимума от этого не меняется.

</Block>

## Итог

- $\nabla_x\, b^\top x = b$; $\nabla_x\, x^\top A x = (A + A^\top)x$, для симметричной $A$ — $2Ax$.
- Градиент имеет форму аргумента; каждое слагаемое — тоже. Конечные разности по каждой координате проверяют любую формулу.
- $\nabla_A \operatorname{tr}(AB) = B^\top$; $\nabla_A \log\lvert\det A\rvert = A^{-\top}$ — с модулем.
- $\nabla_\theta \tfrac12 \lVert X\theta - y \rVert^2 = X^\top X\theta - X^\top y = 0$ — нормальные уравнения.
