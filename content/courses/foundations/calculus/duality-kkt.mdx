## Ограничения-неравенства

Задача в общем виде: минимизировать $f(x)$ при $g_i(x) \le 0$, $i = 1, \ldots, k$. Простейший пример — ближайшая к $c$ точка полуплоскости: $f(x) = \tfrac12 \lVert x - c \rVert^2$, $g(x) = x_1 + x_2 - 1$.

Лагранжиан тот же, что в уроке II.8, но множители при неравенствах неотрицательны: $\mathcal{L}(x, \alpha) = f(x) + \sum_i \alpha_i g_i(x)$, $\alpha_i \ge 0$. В решении выпуклой задачи выполняются **условия Каруша — Куна — Таккера** (KKT):

1. стационарность: $\nabla f(x^\star) + \sum_i \alpha_i \nabla g_i(x^\star) = 0$;
2. допустимость: $g_i(x^\star) \le 0$;
3. неотрицательность множителей: $\alpha_i \ge 0$;
4. **дополняющая нежёсткость**: $\alpha_i\, g_i(x^\star) = 0$ для каждого $i$.

Последнее условие говорит: каждое ограничение либо **активно** ($g_i = 0$, точка на границе, $\alpha_i$ может быть положительным), либо неактивно ($g_i < 0$, и тогда $\alpha_i = 0$ — ограничение в этой точке ни на что не влияет).

<Note label="По-английски">Условия KKT — *Karush–Kuhn–Tucker conditions*, дополняющая нежёсткость — *complementary slackness*, активное ограничение — *active constraint*.</Note>

## Двойственная задача

При допустимом $x$ и $\alpha \ge 0$ добавка $\alpha_i g_i(x) \le 0$, поэтому $\mathcal{L}(x, \alpha) \le f(x)$. Возьмём минимум по всем $x$ — получится **двойственная функция** $d(\alpha) = \min_x \mathcal{L}(x, \alpha)$. Она не больше $f$ в любой допустимой точке, а значит, и минимума прямой задачи: $d(\alpha) \le p^\star$. Это **слабая двойственность**. Лучшая нижняя оценка — **двойственная задача** $d^\star = \max_{\alpha \ge 0} d(\alpha) \le p^\star$.

<Formula formula="f.dual-projection" n={1} />

Для проекции двойственная функция — парабола по $\alpha$. Её максимум при $\alpha \ge 0$ — $\alpha^\star = \max(0, g(c)/\lVert a \rVert^2)$, и в нём $d^\star = p^\star$: на рисунке 1 показания совпадают при любом $c$. Это **сильная двойственность**. Она выполняется для выпуклых задач, у которых есть строго допустимая точка, $g_i(x) < 0$ для всех $i$ (условие Слейтера). Тогда решить прямую задачу можно, решив двойственную.

Зачем это в ML. В методе опорных векторов (CS229, «Support vector machines», «Lagrange duality» и «Optimal margin classifiers») прямая задача — найти разделяющую гиперплоскость с наибольшим зазором, по ограничению на каждый объект. Двойственная задача записывается только через скалярные произведения $\langle x^{(i)}, x^{(j)} \rangle$, что открывает дорогу ядрам. По дополняющей нежёсткости $\alpha_i > 0$ только у объектов на границе зазора — это и есть **опорные векторы**. Подробно — в уроке V.5.

<Note label="По-английски">Двойственная задача — *dual problem*, слабая и сильная двойственность — *weak* и *strong duality*, условие Слейтера — *Slater's condition*.</Note>

## Итог

- Для $g_i(x) \le 0$ лагранжиан $f + \sum_i \alpha_i g_i$ с $\alpha_i \ge 0$; условия KKT: стационарность, допустимость, $\alpha_i \ge 0$ и $\alpha_i g_i = 0$.
- Неактивное ограничение ($g_i < 0$) имеет $\alpha_i = 0$; положительный множитель бывает только у активного.
- $d(\alpha) = \min_x \mathcal{L} \le p^\star$ — слабая двойственность; для выпуклых задач с условием Слейтера $d^\star = p^\star$. В SVM опорные векторы — объекты с $\alpha_i > 0$.
