## Экспоненциальное семейство

В&nbsp;уроке IV.5 математики распределения записывались в&nbsp;одной форме:

$$
p(y; \eta) = b(y) \exp\bigl(\eta^\top T(y) - a(\eta)\bigr).
$$

Здесь $\eta$&nbsp;— **естественный параметр**, $T(y)$&nbsp;— **достаточная статистика** (чаще всего $T(y) = y$), $a(\eta)$&nbsp;— логарифм нормировочной константы. Её&nbsp;производные дают моменты: $a'(\eta) = \mathbb{E}[T(y)]$, $a''(\eta) = \operatorname{Var}[T(y)]$.

- **Нормальное** с&nbsp;$\sigma^2 = 1$: $\eta = \mu$, $a(\eta) = \eta^2/2$, $b(y) = e^{-y^2/2}/\sqrt{2\pi}$.
- **Бернулли**: $\eta = \log\frac{\phi}{1 - \phi}$&nbsp;— логарифм шансов, $a(\eta) = \log(1 + e^{\eta})$, $b(y) = 1$.
- **Пуассон**: $\eta = \log\lambda$, $a(\eta) = e^{\eta}$, $b(y) = 1/y!$.
- **Категориальное** с&nbsp;$k$ классами: $T(y)_j = 1\{y = j\}$ для $j < k$, $\eta_j = \log(\phi_j/\phi_k)$, $a(\eta) = \log\bigl(1 + \sum_{j<k} e^{\eta_j}\bigr)$.

Выберите в&nbsp;виджете распределение и&nbsp;сравните строки таблицы. Перед этим предскажите: что общего у&nbsp;градиента потерь на&nbsp;объекте во&nbsp;всех четырёх случаях?

<GlmBuilder n={1}>Выбор распределения ответа заполняет таблицу экспоненциального семейства. Слева&nbsp;— данные с&nbsp;одним признаком и&nbsp;прогноз $\mathbb{E}[y \mid x]$ при $\eta = \theta_0 + \theta_1 x$, справа&nbsp;— распределение ответа $p(y \mid x)$ в&nbsp;точке запроса. У&nbsp;Пуассона отклик можно подменить тождественным.</GlmBuilder>

Меняются только $a(\eta)$ и&nbsp;отклик; градиент на&nbsp;объекте всегда $(h_\theta(x) - y)\,x$. Включите у&nbsp;Пуассона тождественный отклик $\lambda = \theta^\top x$: при малом числе фото $\lambda$ уходит в&nbsp;минус, а&nbsp;отрицательного среднего у&nbsp;пуассоновского распределения не&nbsp;бывает.

<Note label="По-английски">Экспоненциальное семейство&nbsp;— *exponential family*, естественный параметр&nbsp;— *natural parameter*, достаточная статистика&nbsp;— *sufficient statistic*, логарифм нормировочной константы&nbsp;— *log-partition function*.</Note>

## Три допущения

**Обобщённая линейная модель** (GLM) строится из&nbsp;трёх допущений:

1. $y \mid x; \theta$ имеет распределение из&nbsp;экспоненциального семейства с&nbsp;параметром $\eta$;
2. прогноз&nbsp;— среднее: $h_\theta(x) = \mathbb{E}[T(y) \mid x]$;
3. естественный параметр линеен по&nbsp;признакам: $\eta = \theta^\top x$ (для векторного $\eta$&nbsp;— $\eta_j = \theta_j^\top x$).

Нормальное распределение даёт линейную регрессию, Бернулли&nbsp;— логистическую: отклик $\mathbb{E}[y] = \phi = 1/(1 + e^{-\eta})$ и&nbsp;есть сигмоида, поэтому CS229 обозначает отклик той&nbsp;же буквой $g$. Категориальное даёт softmax из&nbsp;урока 1.5 с&nbsp;$\theta_k = 0$. А&nbsp;для счётчиков&nbsp;— просмотров, звонков, страховых случаев&nbsp;— берём Пуассона.

## Канонический случай: один градиент на всех

При $T(y) = y$ логарифм правдоподобия собирается из&nbsp;$y\,\eta - a(\eta)$, а&nbsp;производная $a'$&nbsp;— это и&nbsp;есть отклик. Поэтому градиент у&nbsp;всех таких моделей одинаков по&nbsp;форме, а&nbsp;гессиан задаётся дисперсией ответа.

<Formula formula="f.glm-gradient" n={2} />

Это объясняет, почему правило LMS, градиент логистической регрессии и&nbsp;градиент softmax выглядели одинаково: $(y - h_\theta(x))\,x$, менялась только $h_\theta$. Дисперсия $a''$ неотрицательна, поэтому $\ell$ любой канонической GLM вогнута, и&nbsp;метод Ньютона из&nbsp;урока 1.4 работает для всех: шаг&nbsp;— взвешенный МНК с&nbsp;весами $a''(\eta_i)$.

Ньютону хватило 6 итераций, градиент $X^\top(y - \lambda)$ в&nbsp;максимуме&nbsp;— ноль. Веса читаются через множители: ещё одно фото умножает ожидаемые просмотры на&nbsp;$e^{0.122} \approx 1.13$, то&nbsp;есть добавляет 13&nbsp;%; цена на&nbsp;10&nbsp;% выше медианы района умножает их&nbsp;на&nbsp;$e^{-0.242} \approx 0.79$. Линейная регрессия у&nbsp;7.8&nbsp;% объявлений предсказывает отрицательные просмотры, и&nbsp;пуассоновская девиация `mean_poisson_deviance` на&nbsp;таких прогнозах даже не&nbsp;считается. Тесты курса сверяют веса с&nbsp;`PoissonRegressor(alpha=0)` из&nbsp;scikit-learn до&nbsp;$10^{-3}$; по&nbsp;умолчанию там штраф `alpha=1`, и&nbsp;веса меньше.

<Block kind="pitfall">

Обучать линейную регрессию на&nbsp;$\log y$ вместо пуассоновской. У&nbsp;объявлений без просмотров $\log 0$ не&nbsp;определён, а&nbsp;прогноз $\exp \mathbb{E}[\log y]$ занижен: по&nbsp;неравенству Йенсена $\exp \mathbb{E}[\log y] \le \mathbb{E}[y]$. Линейная регрессия на&nbsp;самих счётчиках даёт отрицательные прогнозы. Пуассоновская регрессия моделирует среднее счётчика прямо и&nbsp;всегда положительно.

</Block>

## Итог

- GLM: ответ из&nbsp;экспоненциального семейства, прогноз&nbsp;— среднее $\mathbb{E}[T(y) \mid x]$, $\eta = \theta^\top x$. Нормальное даёт линейную регрессию, Бернулли&nbsp;— логистическую, категориальное&nbsp;— softmax, Пуассон&nbsp;— пуассоновскую.
- Отклик $h = a'(\eta)$ переводит $\eta$ в&nbsp;среднее, связь&nbsp;— обратно; у&nbsp;Пуассона отклик&nbsp;— экспонента, связь&nbsp;— логарифм.
- У&nbsp;канонической GLM $\nabla_\theta \ell = X^\top(y - h_\theta(X))$, гессиан $-X^\top \operatorname{diag}(a'') X \preceq 0$: правдоподобие вогнуто, и&nbsp;метод Ньютона общий для всех.
