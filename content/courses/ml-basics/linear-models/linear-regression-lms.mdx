## Правило LMS

В&nbsp;уроке 1.1 веса линейной модели нашлись из&nbsp;нормальных уравнений $X^\top X\theta = X^\top y$. Это одно решение системы $d \times d$, но&nbsp;его не&nbsp;построить, если данные не&nbsp;помещаются в&nbsp;память или приходят потоком, и&nbsp;оно есть только у&nbsp;квадратичных потерь. Градиентный спуск из&nbsp;урока II.6 математики работает всегда: шаг против градиента, пока $J$ убывает.

Градиент потерь на&nbsp;одном объекте&nbsp;— ошибка, умноженная на&nbsp;признаки: $\nabla_\theta J^{(i)} = \bigl(h_\theta(x^{(i)}) - y^{(i)}\bigr)\,x^{(i)}$. Шаг против него

$$
\theta_j := \theta_j + \alpha\,\bigl(y^{(i)} - h_\theta(x^{(i)})\bigr)\,x^{(i)}_j \qquad \text{для всех } j \text{ одновременно}
$$

называют **правилом LMS** (*least mean squares*, или правилом Уидроу — Хоффа). Поправка пропорциональна ошибке: объект, который модель уже предсказывает верно, веса почти не&nbsp;двигает. Усреднив по&nbsp;всем объектам, получим пакетный шаг.

CS229 пишет $J$ суммой без&nbsp;$\frac1n$; тогда градиент в&nbsp;$n$ раз больше, и&nbsp;допустимый шаг уменьшается с&nbsp;ростом выборки.</Note>

## Шаг и сходимость

Где сходится пакетный спуск? Минимум $\theta^*$&nbsp;— решение нормальных уравнений, и&nbsp;$\nabla_\theta J = H(\theta - \theta^*)$ с&nbsp;матрицей $H = \frac1n X^\top X$&nbsp;— гессианом $J$. Поэтому один шаг умножает отклонение на&nbsp;матрицу:

$$
\theta - \theta^* \;\mapsto\; (I - \alpha H)(\theta - \theta^*) .
$$

Вдоль собственного вектора $H$ с&nbsp;числом $\lambda$ отклонение умножается на&nbsp;$1 - \alpha\lambda$, как в&nbsp;игре «Порог расходимости». Спуск сходится, если все множители по&nbsp;модулю меньше единицы, то&nbsp;есть при $0 < \alpha < 2/\lambda_{\max}$. Скорость задаёт самое медленное направление: при лучшем шаге нужно порядка $\kappa \log(1/\varepsilon)$ итераций, где $\kappa = \lambda_{\max}/\lambda_{\min}$&nbsp;— **число обусловленности**.

Перед тем как двигать бегунок, предскажите: какую форму будут иметь линии уровня $J(\theta_0, \theta_1)$ для цены от&nbsp;площади в&nbsp;квадратных метрах?

Эллипсы&nbsp;— линии уровня $J(\theta_0, \theta_1)$, кружок в&nbsp;центре&nbsp;— минимум $\theta^*$ из&nbsp;нормальных уравнений, ломаная&nbsp;— путь весов. Шаг задаётся долей порога $2/\lambda_{\max}$; признак, режим спуска, число эпох и&nbsp;старт меняются кнопками.</LmsPath>

Эллипсы вытянуты в&nbsp;узкую долину. Шаг ограничен крутым направлением, поперёк долины, и&nbsp;за&nbsp;сотню эпох путь едва сдвигается вдоль неё: $J$ остаётся на&nbsp;40&nbsp;% выше минимума, а&nbsp;$\theta_0$ почти не&nbsp;отходит от&nbsp;нуля при $\theta_0^* \approx 1.15$.

## Стандартизация признаков

Вытянутость линий уровня&nbsp;— следствие масштаба, а&nbsp;не&nbsp;данных. **Стандартизация** заменяет каждый признак на&nbsp;$x_j := (x_j - \mu_j)/s_j$, где $\mu_j$ и&nbsp;$s_j$&nbsp;— среднее и&nbsp;стандартное отклонение по&nbsp;обучающей выборке. После неё матрица $H$ состоит из&nbsp;единицы для свободного члена и&nbsp;корреляционной матрицы признаков: все диагональные элементы равны единице, $\lambda_{\max} \le d$.

Переключите в&nbsp;виджете признак на&nbsp;стандартизованный. Порог шага вырастает до&nbsp;$2$, линии уровня становятся окружностями ($\kappa = 1$ для одного признака), и&nbsp;пакетный спуск с&nbsp;шагом в&nbsp;половину порога приходит в&nbsp;минимум за&nbsp;один шаг. С&nbsp;несколькими признаками $\kappa$ остаётся больше единицы, если признаки коррелируют: площадь и&nbsp;число комнат связаны, и&nbsp;у&nbsp;пяти признаков «Квартир» $\kappa \approx 12.7$.

## Стохастический спуск и мини-батч

Пакетный шаг проходит по&nbsp;всем $n$ объектам. **Стохастический спуск** (SGD) делает шаг LMS по&nbsp;одному объекту, **мини-батч**&nbsp;— по&nbsp;среднему по&nbsp;группе $B$:

$$
\theta := \theta + \frac{\alpha}{\lvert B\rvert} \sum_{i \in B} \bigl(y^{(i)} - h_\theta(x^{(i)})\bigr)\, x^{(i)} .
$$

Проход по&nbsp;всем объектам называют **эпохой**; перед каждой эпохой объекты перемешивают. Градиент по&nbsp;группе&nbsp;— несмещённая, но&nbsp;шумная оценка полного. Поэтому с&nbsp;постоянным шагом SGD не&nbsp;останавливается в&nbsp;минимуме: в&nbsp;самом минимуме градиенты отдельных объектов не&nbsp;равны нулю, и&nbsp;веса бродят в&nbsp;облаке вокруг $\theta^*$. Облако сжимается, если уменьшать шаг, например $\alpha_t = \alpha/(1 + t/t_0)$, или увеличивать пакет.

## Итог

- Правило LMS: $\theta := \theta + \alpha\,(y^{(i)} - h_\theta(x^{(i)}))\,x^{(i)}$; пакетная форма $\theta := \theta + \frac{\alpha}{n} X^\top(y - X\theta)$, мини-батч&nbsp;— среднее по&nbsp;группе.
- Пакетный спуск сходится при $0 < \alpha < 2/\lambda_{\max}$, $H = \frac1n X^\top X$; число итераций растёт с&nbsp;$\kappa = \lambda_{\max}/\lambda_{\min}$.
- Стандартизация по&nbsp;обучающей выборке выравнивает линии уровня и&nbsp;поднимает порог шага; веса пересчитывают на&nbsp;исходные признаки: $\theta_j = \theta'_j/s_j$, $\theta_0 = \theta'_0 - \sum_j \theta'_j\mu_j/s_j$.
- SGD с&nbsp;постоянным шагом приходит в&nbsp;облако вокруг минимума; сжимают его убывающий шаг и&nbsp;больший пакет.
