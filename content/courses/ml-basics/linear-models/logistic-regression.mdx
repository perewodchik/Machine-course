## Вероятность вместо ответа

Задача: по&nbsp;площади и&nbsp;пути до&nbsp;метро понять, дороже ли квартира медианы. Метка $y \in \{0, 1\}$, и&nbsp;модель должна выдать не&nbsp;метку, а&nbsp;вероятность. Линейная оценка $\theta^\top x$ принимает любые значения; **сигмоида** $g(z) = 1/(1 + e^{-z})$ из&nbsp;урока 0.5 переводит её в&nbsp;$(0, 1)$:

$$
h_\theta(x) = g(\theta^\top x) = P(y = 1 \mid x; \theta), \qquad p(y \mid x; \theta) = h_\theta(x)^{y}\,\bigl(1 - h_\theta(x)\bigr)^{1 - y} .
$$

**Граница решений**&nbsp;— множество, где $h_\theta(x) = 0.5$, то&nbsp;есть гиперплоскость $\theta^\top x = 0$. Сигмоида&nbsp;— это не&nbsp;граница, а&nbsp;профиль вероятности поперёк неё: длина $\lVert w\rVert$ вектора весов при признаках задаёт, как круто вероятность меняется от&nbsp;0 до&nbsp;1. Перед тем как двигать ручки, предскажите: как изменится картина, если крутизну увеличить в&nbsp;10 раз?

<LogisticPlane n={1}>Двести квартир на&nbsp;плоскости «площадь&nbsp;— путь до&nbsp;метро». Закрашенные дороже медианы, полые дешевле. Фон&nbsp;— вероятность класса «дороже», линия&nbsp;— граница решений, кольцо вокруг точки&nbsp;— её потери $-\log p(y \mid x; \theta)$. Ручки задают направление границы, сдвиг и&nbsp;крутизну; «К&nbsp;максимуму» находит веса методом Ньютона.</LogisticPlane>

## Правдоподобие и его вогнутость

Веса выбираем по&nbsp;максимуму правдоподобия (урок IV.3): объекты независимы, поэтому

$$
\ell(\theta) = \sum_{i=1}^{n} \Bigl[y^{(i)} \log h_\theta(x^{(i)}) + \bigl(1 - y^{(i)}\bigr) \log\bigl(1 - h_\theta(x^{(i)})\bigr)\Bigr].
$$

Среднее со&nbsp;знаком минус $J(\theta) = -\ell(\theta)/n$ называют **логистическими потерями**. Градиент получается из&nbsp;$g' = g(1 - g)$ и&nbsp;правила цепочки.

<Formula formula="f.logistic-gradient" n={1} />

Стохастический подъём по&nbsp;одному объекту&nbsp;— $\theta := \theta + \alpha\,(y^{(i)} - h_\theta(x^{(i)}))\,x^{(i)}$&nbsp;— внешне то&nbsp;же правило LMS из&nbsp;урока 1.2, но&nbsp;$h_\theta$ теперь другая. Чтобы узнать, сколько у&nbsp;$\ell$ максимумов, нужен гессиан.

<Formula formula="f.logistic-hessian" n={2} />

Квадратичная форма гессиана неположительна при любом $v$, поэтому $\ell$ вогнута, а&nbsp;при полном ранге $X$&nbsp;— строго вогнута: найденный максимум единственный.

<Note label="На полях">Для меток $\tilde y = 2y - 1 \in \{-1, 1\}$ те&nbsp;же потери записываются одной формулой: $-\log p(y \mid x; \theta) = \log\bigl(1 + e^{-\tilde y\,\theta^\top x}\bigr)$. Так их&nbsp;пишут в&nbsp;курсах про SVM и&nbsp;бустинг.</Note>

<Block kind="pitfall">

Писать `np.log(1 - g(z))`: при $z \approx 40$ значение $g(z)$ округляется до&nbsp;единицы, и&nbsp;логарифм нуля даёт $-\infty$. Потери считают через запись с&nbsp;метками $\pm 1$ и&nbsp;`np.logaddexp(0, -ỹ z)`, а&nbsp;сигмоиду&nbsp;— через $\tfrac12(1 + \tanh(z/2))$.

</Block>

Что, если классы разделяет прямая без ошибок? Тогда чем круче сигмоида, тем ближе все $p(y^{(i)} \mid x^{(i)})$ к&nbsp;единице: $\ell$ растёт к&nbsp;нулю, но&nbsp;не&nbsp;достигает его. Максимума нет, и&nbsp;$\lVert\theta\rVert \to \infty$. Проверьте это в&nbsp;игре на&nbsp;последнем уровне.

<Note label="Игра">«Честная вероятность»: сначала отметьте, где, по-вашему, лучшая граница, потом подберите границу и&nbsp;крутизну. Очки&nbsp;— средний $\log p(y \mid x)$ против максимума правдоподобия. Четыре уровня: перекрытые классы, выброс, редкий класс и&nbsp;разделимые данные. 2–4&nbsp;минуты. [Открыть игру](/games/honest-probability/)</Note>

<Note label="По-английски">Логистические потери&nbsp;— *log loss*, *binary cross-entropy*; линейная разделимость&nbsp;— *linear separability*.</Note>

## Метод Ньютона

У&nbsp;логистической регрессии нет формулы для максимума, как у&nbsp;нормальных уравнений: уравнение $X^\top(y - g(X\theta)) = 0$ нелинейно. Метод Ньютона (урок II.7) заменяет $\ell$ квадратичным приближением и&nbsp;прыгает в&nbsp;его максимум: $\theta := \theta - H^{-1}\nabla_\theta \ell$. Для логистической регрессии этот шаг&nbsp;— взвешенный МНК из&nbsp;урока 1.3.

<Formula formula="f.logistic-newton-irls" n={3} />

Веса $D_{ii} = h(1 - h)$ велики у&nbsp;объектов вблизи границы и&nbsp;малы у&nbsp;уверенно классифицированных: каждая итерация&nbsp;— регрессия, сосредоточенная на&nbsp;спорных квартирах. Отсюда название **IRLS**&nbsp;— *iteratively reweighted least squares*.

<AscentNewton n={2}>Линии уровня $\ell(\theta_1, \theta_2)$ для двух стандартизованных признаков без свободного члена. Штриховая&nbsp;— путь градиентного подъёма, сплошная с&nbsp;точками&nbsp;— метод Ньютона, кружок&nbsp;— максимум. Кнопка «площадь&nbsp;÷&nbsp;3» меняет масштаб одного признака.</AscentNewton>

Ньютону хватает 8 итераций, подъёму с&nbsp;безопасным шагом&nbsp;— 1445. Поделите площадь на&nbsp;3: линии уровня вытянутся, подъёму понадобится 11&nbsp;261 итерация, а&nbsp;Ньютону&nbsp;— по-прежнему 8. Зато итерация Ньютона решает систему $d \times d$: при тысячах признаков это дорого, и&nbsp;тогда выбирают подъём или квазиньютоновские методы.

## Итог

- Логистическая регрессия: $h_\theta(x) = g(\theta^\top x)$ — вероятность класса; граница решений&nbsp;— гиперплоскость $\theta^\top x = 0$, крутизну задаёт длина весов.
- $\nabla_\theta\ell = X^\top(y - g(X\theta))$, гессиан $-X^\top D X \preceq 0$: $\ell$ вогнута, максимум один. На&nbsp;разделимых данных максимума нет.
- Метод Ньютона&nbsp;— взвешенный МНК на&nbsp;каждой итерации (IRLS): несколько итераций против тысяч у&nbsp;подъёма, не&nbsp;зависит от&nbsp;масштаба признаков, но&nbsp;каждая итерация решает систему $d \times d$.
- Потери считают устойчиво (`logaddexp`), а&nbsp;веса сверяют с&nbsp;`LogisticRegression` без штрафа.
