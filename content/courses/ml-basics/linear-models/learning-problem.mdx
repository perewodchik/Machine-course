## Постановка задачи

Есть $n$ пар «объект — ответ»: $x^{(i)}$&nbsp;— признаки $i$-й квартиры (площадь, число комнат, этаж, время до&nbsp;метро, возраст дома), $y^{(i)}$&nbsp;— её цена. **Обучение с учителем**&nbsp;— подобрать функцию $h_\theta$, которая по&nbsp;признакам предсказывает ответ. Если $y$&nbsp;— число, задача называется **регрессией**; если $y$ из&nbsp;конечного набора классов («продастся за&nbsp;неделю или нет»)&nbsp;— **классификацией**.

Начнём с&nbsp;линейной модели: $h_\theta(x) = \theta^\top x$, где к&nbsp;признакам добавлен $x_0 = 1$, чтобы был свободный член. Качество измеряет функция потерь; в&nbsp;регрессии на&nbsp;одном объекте это $J^{(i)}(\theta) = \tfrac12 \bigl(h_\theta(x^{(i)}) - y^{(i)}\bigr)^2$, а&nbsp;на&nbsp;выборке&nbsp;— среднее

$$
J(\theta) = \frac1n \sum_{i=1}^{n} J^{(i)}(\theta) .
$$

Это эмпирический риск из&nbsp;урока IV.7 математики. Обучение минимизирует $J$ на&nbsp;обучающей выборке, а&nbsp;судить о&nbsp;модели надо по&nbsp;новым объектам.

<Note label="По-английски">Обучение с&nbsp;учителем&nbsp;— *supervised learning*, признак&nbsp;— *feature*, целевая переменная&nbsp;— *target*, функция потерь&nbsp;— *loss function*.</Note>

## Цикл: разбиение, бейзлайн, модель, метрика

Отложим 20&nbsp;% квартир в&nbsp;**тестовую выборку** и&nbsp;не&nbsp;будем на&nbsp;них смотреть, пока не&nbsp;выберем модель. Первая модель&nbsp;— **бейзлайн**: одна константа для всех. Какая константа лучшая, зависит от&nbsp;потерь.

<Exercise gen="ml.best-constant" n={2} variants={6} />

Ошибку на&nbsp;тесте меряют в&nbsp;единицах ответа:

$$
\operatorname{RMSE} = \sqrt{\frac{1}{n_{\text{test}}} \sum_i \bigl(y^{(i)} - \hat y^{(i)}\bigr)^2}, \qquad \operatorname{MAE} = \frac{1}{n_{\text{test}}} \sum_i \bigl\lvert y^{(i)} - \hat y^{(i)} \bigr\rvert .
$$

Всегда $\operatorname{RMSE} \ge \operatorname{MAE}$: квадрат сильнее наказывает большие ошибки. Равны они, только когда все ошибки одинаковы по&nbsp;модулю. Ещё одна метрика&nbsp;— $R^2 = 1 - \sum_i (y^{(i)} - \hat y^{(i)})^2 / \sum_i (y^{(i)} - \bar y)^2$: доля разброса цен, которую объяснила модель.

Бейзлайн ошибается на&nbsp;3.5&nbsp;млн&nbsp;₽ (RMSE), модель по&nbsp;одной площади&nbsp;— на&nbsp;1.2, по&nbsp;всем пяти признакам&nbsp;— на&nbsp;0.82: в&nbsp;четыре с&nbsp;лишним раза точнее. Ошибка на&nbsp;обучении 0.795 чуть меньше тестовой: модель немного подстроилась под&nbsp;свои данные.

<Note label="По-английски">Обучающая и&nbsp;тестовая выборки&nbsp;— *training* и&nbsp;*test sets*, бейзлайн&nbsp;— *baseline*, корень из&nbsp;среднего квадрата ошибки&nbsp;— *root mean squared error*, средняя абсолютная ошибка&nbsp;— *mean absolute error*.</Note>

## Обобщение

Ошибка на&nbsp;обучающей выборке занижает ошибку на&nbsp;новых данных: модель видела эти точки и&nbsp;подогнана под&nbsp;них. Насколько занижает, зависит от&nbsp;гибкости модели и&nbsp;размера выборки. Подвигайте степень полинома и&nbsp;сравните 20 и&nbsp;200 обучающих квартир.

<TrainTest n={1}>Цена от&nbsp;площади. Слева&nbsp;— обучающие квартиры (крупные точки), тестовые (мелкие) и&nbsp;полином выбранной степени; справа&nbsp;— RMSE на&nbsp;обучении и&nbsp;на&nbsp;тесте для степеней 0–12.</TrainTest>

С&nbsp;ростом степени ошибка на&nbsp;обучении только падает, а&nbsp;на&nbsp;тесте сначала падает, потом растёт: на&nbsp;20 точках полином двенадцатой степени гонится за&nbsp;шумом. На&nbsp;200 точках разрыв между обучением и&nbsp;тестом меньше&nbsp;— данных хватает, чтобы гибкость не&nbsp;навредила.

<Block kind="pitfall">

Подглядывать в&nbsp;тест. Если выбирать модель, признаки или их&nbsp;масштаб по&nbsp;тестовой выборке, она перестаёт быть честной оценкой. Частый незаметный случай&nbsp;— считать средние и&nbsp;разбросы признаков для стандартизации по&nbsp;всем данным до&nbsp;разбиения: тест подсказывает обучению. Статистики считают только по&nbsp;обучающей части и&nbsp;применяют к&nbsp;тесту.

</Block>

<Block kind="pitfall">

Отрицательный $R^2$ на&nbsp;тесте&nbsp;— не&nbsp;ошибка вычисления. На&nbsp;обучающей выборке $R^2 \ge 0$ для модели со&nbsp;свободным членом, а&nbsp;на&nbsp;тесте он&nbsp;отрицателен, если модель хуже константы&nbsp;— например, сильно переобучена.

## Итог

- Обучение с&nbsp;учителем: по&nbsp;парам $(x^{(i)}, y^{(i)})$ подобрать $h_\theta$; качество&nbsp;— на&nbsp;отложенной тестовой выборке, а&nbsp;не&nbsp;на&nbsp;обучающей.
- Порядок работы: разбиение → бейзлайн-константа (среднее для MSE, медиана для MAE) → линейная модель → RMSE и&nbsp;MAE на&nbsp;тесте.
- Ошибка на&nbsp;обучении с&nbsp;ростом гибкости только падает; на&nbsp;тесте&nbsp;— сначала падает, потом растёт. Статистики признаков считают по&nbsp;обучающей части.
