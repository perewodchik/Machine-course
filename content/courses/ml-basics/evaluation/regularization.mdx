## Гребневая регрессия

В&nbsp;уроке 2.2 лишние веса стоили разброса. Штраф за&nbsp;их&nbsp;величину сдвигает баланс к&nbsp;смещению: модель становится менее гибкой. **Гребневая регрессия** добавляет к&nbsp;сумме квадратов $\frac\lambda2 \lVert\theta\rVert_2^2$, и&nbsp;решение по-прежнему записывается формулой.

<Formula formula="f.ridge-closed-form" n={1} />

Обратимость&nbsp;— главный практический выигрыш: при $d > n$ или при сильно коррелированных признаках $X^\top X$ вырождена, а&nbsp;$X^\top X + \lambda I$&nbsp;— нет. Связь с&nbsp;байесовской оценкой при нормальном априорном распределении весов выведена в&nbsp;уроке IV.6: гребневая&nbsp;— это MAP.

Две технические детали. Свободный член не&nbsp;штрафуют: столбцы $X$ и&nbsp;$y$ центрируют, а&nbsp;$\theta_0 = \bar y - \bar x^\top\theta$ находят отдельно&nbsp;— так делает `Ridge(alpha=λ)`. И&nbsp;признаки стандартизуют по&nbsp;обучающей части: иначе штраф зависит от&nbsp;единиц измерения.

## Лассо и мягкий порог

**Лассо** штрафует сумму модулей: $\lambda\lVert\theta\rVert_1$. Модуль имеет излом в&nbsp;нуле, и&nbsp;это меняет всё. Проще всего увидеть при ортонормированных признаках, $X^\top X = I$: задача распадается по&nbsp;координатам.

<Formula formula="f.lasso-soft-threshold" n={2} />

Гребневая при тех&nbsp;же условиях даёт $\hat\theta_j / (1 + \lambda)$: все веса сжимаются в&nbsp;одно и&nbsp;то&nbsp;же число раз и&nbsp;никогда не&nbsp;становятся нулём. Лассо вычитает $\lambda$ из&nbsp;модуля, а&nbsp;веса меньше $\lambda$ зануляет: модель сама отбирает признаки.

<Exercise gen="ml.shrink-orth" n={2} variants={6} />

Штраф и&nbsp;ограничение&nbsp;— две записи одной задачи (урок II.8): решение со&nbsp;штрафом $\lambda$ минимизирует $J$ на&nbsp;шаре $R(\theta) \le t$ для подходящего $t$. Для L2 шар&nbsp;— круг, для L1&nbsp;— ромб. Перед тем как двигать ручки, предскажите: где эллипс линий уровня чаще касается ромба&nbsp;— на&nbsp;стороне или в&nbsp;вершине?

<RegPath n={1}>Слева&nbsp;— плоскость весов площади и&nbsp;комнат: эллипсы уровня $J$ и&nbsp;ромб (L1) или круг (L2) ограничения. Сжимайте ограничение: точка решения ползёт к&nbsp;нулю, её&nbsp;след&nbsp;— штриховая линия. Справа&nbsp;— путь пяти весов «Квартир» от&nbsp;$\lg\lambda$ и&nbsp;ошибки на&nbsp;обучении и&nbsp;валидации.</RegPath>

У&nbsp;ромба решение выходит на&nbsp;вершину&nbsp;— вес комнат становится нулём&nbsp;— и&nbsp;дальше ползёт по&nbsp;оси. У&nbsp;круга оно идёт к&nbsp;нулю по&nbsp;гладкой кривой, и&nbsp;оба веса остаются ненулевыми. Справа лассо зануляет веса по&nbsp;одному, а&nbsp;гребневая только сжимает. Включите «площадь в&nbsp;см² без стандартизации»: путь меняется, хотя данные те&nbsp;же.

<Block kind="pitfall">

Верить, что лассо устойчиво выбирает один из&nbsp;двух коррелированных признаков. Площадь и&nbsp;число комнат несут почти одно и&nbsp;то&nbsp;же; какой из&nbsp;них лассо оставит, решает случай, и&nbsp;на&nbsp;другой выборке выбор может смениться. Интерпретировать занулённый вес как «признак не&nbsp;важен» нельзя.

</Block>

<Note label="По-английски">Лассо&nbsp;— *lasso* (*least absolute shrinkage and selection operator*), путь регуляризации&nbsp;— *regularization path*, мягкий порог&nbsp;— *soft thresholding*.</Note>

## Покоординатный спуск

Без ортонормированности у&nbsp;лассо нет формулы, но&nbsp;мягкий порог работает по&nbsp;одной координате: зафиксируем все веса, кроме $\theta_j$, и&nbsp;решим одномерную задачу.

<Formula formula="f.lasso-coordinate-step" n={3} />

Обходя координаты по&nbsp;кругу, получаем **покоординатный спуск**: каждый шаг не&nbsp;увеличивает потери, и&nbsp;он&nbsp;сходится к&nbsp;минимуму выпуклой функции. Путь по&nbsp;сетке $\lambda$ считают от&nbsp;больших значений к&nbsp;малым с&nbsp;**тёплым стартом**: решение при предыдущем $\lambda$&nbsp;— начальная точка для следующего.

При $\lambda = 0.2$ веса сжаты слишком сильно, и&nbsp;ошибка растёт. Гребневая при любом $\lambda$ оставляет все 25 весов ненулевыми. ## λ, смещение и разброс

$\lambda$&nbsp;— та&nbsp;же ручка сложности, что степень полинома в&nbsp;уроке 2.2, только непрерывная: при $\lambda \to 0$&nbsp;— МНК с&nbsp;полным разбросом, при $\lambda \to \infty$ все веса нули, и&nbsp;модель вырождается в&nbsp;константу $\bar y$&nbsp;— чистое смещение. Выбирают $\lambda$ по&nbsp;валидации или кросс-валидацией (урок 2.4).

<Block kind="pitfall">

Путать нормировки $\lambda$. В&nbsp;`Ridge` потери&nbsp;— сумма квадратов, и&nbsp;`alpha` совпадает с&nbsp;$\lambda$ формулы 1; в&nbsp;`Lasso`&nbsp;— среднее с&nbsp;множителем $\tfrac1{2n}$, как в&nbsp;формуле 3; а&nbsp;`C` в&nbsp;`LogisticRegression`&nbsp;— обратная величина: $C = 1/(n\lambda)$, если $J$&nbsp;— средний log-loss, а&nbsp;$R(\theta) = \tfrac12\lVert\theta\rVert^2$. Один и&nbsp;тот&nbsp;же $\lambda$ в&nbsp;разных классах означает разную силу штрафа.

</Block>

## Итог

- Гребневая: $\theta = (X^\top X + \lambda I)^{-1} X^\top y$ на&nbsp;центрированных данных; матрица обратима при любом $\lambda > 0$, веса сжимаются, но&nbsp;не&nbsp;зануляются.
- Лассо: при ортонормированных признаках&nbsp;— мягкий порог $S_\lambda(\hat\theta_j)$, в&nbsp;общем случае&nbsp;— покоординатный спуск; зануляет веса и&nbsp;отбирает признаки. Геометрия: ромб касается эллипсов в&nbsp;вершинах.
- Признаки стандартизуют по&nbsp;обучающей части, свободный член не&nbsp;штрафуют; нормировки $\lambda$ в&nbsp;библиотеках разные.
- $\lambda$&nbsp;— ручка между смещением и&nbsp;разбросом; выбирают её&nbsp;по&nbsp;валидации.
