# content — учебный контент

Здесь нет кода: только данные курса. Авторы правят этот каталог, сайт строится из него.

| Путь | Что | Формат |
|---|---|---|
| `courses/foundations/course.yaml` | Курс: порядок модулей, издание CS229, сквозной кейс | YAML |
| `courses/foundations/<модуль>/module.yaml` | Модуль: порядок уроков, номера, часы | YAML |
| `courses/foundations/<модуль>/<slug>.mdx` | Урок (появятся на этапе 2) | MDX |
| `concepts/*.yaml` | Граф понятий: ID, пререквизиты, где вводится, ссылки на CS229 | YAML |
| `formulas/rules/*.yaml` | Атомарные тождества с численной проверкой | YAML |
| `formulas/<раздел>/*.yaml` | Формулы с выводами; каждый шаг проверяется в CI | YAML |
| `exercises/` | Банки упражнений и генераторы параметрических задач | YAML |
| `glossary.yaml` | Термины RU ↔ EN | YAML |
| `redirects.yaml` | Переименования ID и URL (для редиректов и миграции прогресса) | YAML |

Правила (полностью — `docs/conventions/`):

- **YAML только в блочном стиле.** TeX — в одинарных кавычках `'…'` или в блоке `|`. В двойных кавычках `"\theta"` превращается в табуляцию и `heta`, а двоеточие с пробелом в тексте без кавычек ломает разбор.
- **Символы в формулах — через `\sym{name}{tex}`**, где `name` объявлен в `symbols`. Голые `\theta`, `X`, `y` в формуле с ролями запрещены: цвет и подсветка берутся из `symbols`.
- **Порядок задаётся в `module.yaml`**, а не префиксами имён файлов. Номера уроков в URL и ID не попадают.
- **ID стабильны.** Переименовали — добавьте строку в `redirects.yaml`.
- **Проверка:** `cd code && pytest` прогоняет все формулы и выводы численно.
