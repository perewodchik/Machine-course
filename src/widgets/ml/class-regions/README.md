# Области классов

Виджет урока 1.5 «Перцептрон и многоклассовая классификация» курса «Основы ML». 300 «Квартир» на плоскости стандартизованных площади и пути до метро, классы — эконом, комфорт, бизнес по терцилям цены (`data.json` — ячейка урока). Плоскость делится на области $\arg\max_j \theta_j^\top x$, насыщенность — $\max_j p_j(x)$. Ручки — направление, длина и сдвиг стрелки выбранного класса. «Сдвинуть все θ» прибавляет один вектор ко всем $\theta_j$ — ничего не меняется; «Резкость ×2» меняет только насыщенность; «К оптимуму» — спуск по кросс-энтропии, как в ячейке. Форма точки повторяет класс, чтобы цвет не был единственным носителем смысла.

Модель — `model.ts` и `src/lib/math/softmax.ts`; тесты: оптимум как в ячейке, инвариантность к сдвигу, множитель меняет только резкость.
