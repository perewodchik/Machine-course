# Порог классификатора

Виджет урока 2.1 «Метрики классификации» курса «Основы ML». 300 заявок на кредит на оси оценки модели $p$: дефолты сверху, вернувшие кредит снизу. Порог $t$ (ползунок) делит их на отказы ($p \ge t$) и выдачи. Ошибки — крупные точки цвета ответа. Справа — матрица ошибок, точность, полнота, FPR, доля верных и точка на ROC-кривой; с пропом `cost` — цена ошибок.

Данные — `data.json` из `scripts/export_widget_data.py` (генератор `code/snippets/ml_basics/threshold.py#data`); модель повторяет функции сниппета, `model.test.ts` сверяет числа урока с Python (`code/tests/test_threshold.py`).
