# Подъём против Ньютона

Второй виджет урока 1.4 «Основ ML». Логарифм правдоподобия для двух стандартизованных признаков «Квартир» (площадь, до метро) без свободного члена: линии уровня $\ell(\theta_1, \theta_2)$ (поиск по лучам из максимума — $\ell$ вогнута), пути градиентного подъёма (шаг — половина безопасной границы $8/\lambda_{\max}(X^\top X/n)$) и метода Ньютона, счётчики итераций до $\lVert\nabla\ell\rVert < 10^{-6}$. Кнопка «площадь ÷ 3» меняет масштаб признака: Ньютону всё равно (8 итераций), подъём замедляется в разы.

Модель — `model.ts` и `src/lib/math/logistic.ts`; данные — `data.json` из ячейки урока.
