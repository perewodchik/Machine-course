# Фолды

Виджет урока 2.4 «Выбор модели и кросс-валидация» курса «Основы ML». 60 «Квартир» (площадь → цена, `data.json`), полиномы степени 0–8. Полоса из 60 объектов, по строке на прогон, валидационный фолд выделен ($k = 2, 5, 10, n$). Справа — ошибки фолдов, среднее ± SE и ошибка одной отложенной части 70/30; «Новое разбиение» показывает, что выбор по отложенной части прыгает, а по 10-кратной кросс-валидации стабильнее. Флажок «стратифицировать» раскладывает 60 звонков банка с пятью откликами по фолдам.

Модель — `model.ts`; тесты: каждый объект в одном фолде, CV стабильнее отложенной части, стратификация ровная, правило одной SE не сложнее минимума.
