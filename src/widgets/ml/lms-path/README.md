# Спуск по линиям уровня

Виджет урока 1.2 «Линейная регрессия и LMS» курса «Основы ML». 60 квартир, цена от площади (как `mlf.datasets`); потеря $J(\theta) = \lVert Z\theta - y\rVert^2/(2n)$, $Z = [1, x]$ или $[1, (x - \mu)/s]$. Линии уровня — эллипсы с матрицей $H = Z^\top Z/n$; путь — пакетный спуск, SGD или мини-батч ($\lvert B\rvert$ от 2 до $n$) с перемешиванием по эпохам. Шаг задаётся долей порога $2/\lambda_{\max}$; есть убывающий шаг $\alpha/(1 + t/t_0)$ и два старта.

Модель — `model.ts`; тесты: $\theta^*$ — минимум, 0.95 порога сходится и 1.05 расходится, стандартизация поднимает порог и сводит $\kappa$ к единице, убывающий шаг SGD ближе к минимуму.
