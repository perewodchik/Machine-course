# Путь регуляризации

Виджет урока 2.3 «Регуляризация: L2 и L1» курса «Основы ML». Первые 300 «Квартир» (`data.json`), 200 — обучение, 100 — валидация. Слева — плоскость весов площади и комнат (стандартизованных): эллипсы уровня $J$, круг (L2) или ромб (L1) ограничения радиуса $t$, решение и его след при сжатии ограничения — у ромба оно выходит на вершину. Справа — путь пяти весов от $\lg\lambda$ и RMSE на обучении и валидации; флажок «площадь в см² без стандартизации» показывает, что путь зависит от единиц.

Модель — `model.ts` (гребневая решением системы, лассо покоординатным спуском с тёплым стартом, как `Lasso`); тесты: L1 зануляет по одному, L2 — нет, ромб даёт вершину, без стандартизации прогнозы гребневой меняются, а МНК — нет.
