# Облако моделей

Виджет урока 2.2 «Смещение и разброс» курса «Основы ML». Истина $h^\star(x) = \sin 2.5x + 0.3x$ на $[-1, 1]$, шум $\sigma$. На 100 выборках по $n$ точек обучаются полиномы степени $k$: облако моделей, истина и средняя модель $\bar h$, точка $x_0$ с гистограммой $\hat h_S(x_0)$; столбик $\sigma^2 + \text{смещение}^2 + \text{разброс}$ и ожидаемая ошибка по степени 0–12. Точка $x_0$ двигается ползунком.

Модель — `model.ts`; тесты: степень уменьшает смещение и раздувает разброс, рост $n$ сжимает разброс, ошибка по степени — U с минимумом в середине.
