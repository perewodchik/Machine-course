# Обучение и тест

Виджет урока 1.1 «Задача обучения» курса «Основы ML». Квартиры: цена от площади (цена ≈ 1.5 + 0.11 · площадь + шум 0.8, как в `mlf.datasets`). Полином степени 0–12 подгоняется по обучающей выборке из 20 или 200 объектов (крошечный гребневой штраф — для устойчивости), ошибка RMSE — на обучении и на 200 тестовых. «Новая выборка» меняет seed.

Модель — `model.ts` и `src/lib/math/poly.ts`; тесты: ошибка на обучении не растёт со степенью, на 20 точках степень 12 переобучается, на 200 — слабее.
