# Кривые обучения

Виджет урока 2.5 «Кривые обучения, анализ ошибок и утечки» курса «Основы ML». Истина $\sin 2.5x + 0.3x$, шум $\sigma = 0.3$, полином степени $k$ со штрафом $\lambda$. MSE на обучении и на 400 свежих точках от $n$ (логарифмическая шкала) с полосами 10–90 % по 20 повторам, линии $\sigma^2$ и цели. Сначала диагноз кнопкой — смещение, разброс, всё в порядке, — потом лечение: удвоить $n$, степень +2, $\lambda \times 10$. При $\lg\lambda = -6$ штрафа нет.

Модель — `model.ts`; тесты: прямая — смещение, степень 10 на малых $n$ — разброс, степень 3 на большом $n$ — цель; кривые сходятся к $\sigma^2$ с двух сторон; удвоение $n$ не лечит смещение.
