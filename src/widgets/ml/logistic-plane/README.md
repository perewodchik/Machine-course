# Сигмоида над плоскостью

Виджет урока 1.4 «Логистическая регрессия и метод Ньютона» курса «Основы ML». 200 «Квартир» на плоскости «площадь — до метро», класс — дороже медианы (`data.json` выгружает `scripts/export_widget_data.py` из ячейки урока). Фон — вероятность $g(\theta^\top x)$, линия — граница $\theta^\top x = 0$, кольцо — потери точки. Ручки: направление нормали, сдвиг, крутизна $\lVert w\rVert$; «К максимуму» — метод Ньютона; «Выброс у метро» добавляет дешёвую большую квартиру. Вместо перетаскивания границы и точек — ползунки и кнопка выброса: так всё доступно с клавиатуры.

Модель — `model.ts` и `src/lib/math/logistic.ts`; тесты: максимум как в ячейке, крутизна не двигает границу, выброс двигает.
