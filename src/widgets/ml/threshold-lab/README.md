# Порог: кривые и цена

Виджет урока 2.1 «Метрики классификации» курса «Основы ML» (развёрнутая версия «Порога классификатора» из S7.04). Два гауссовых класса признака $z \sim \mathcal N(\pm d/2, 1)$ с долей положительных $\phi$; оценка — апостериорная вероятность, откалибрована по построению. Сверху — гистограммы оценок по классам, порог $t$ и $t^\star$; ниже — ROC и PR с точкой порога, кривая стоимости на объект с минимумом, кривая надёжности. Ручки: порог, разделимость, $\phi$ от 1 до 50 %, цены ошибок, «исказить оценки» ($s \mapsto s^3$), новая выборка; матрица ошибок и метрики.

Модель — `model.ts` и `src/lib/math/classification.ts`; тесты: калибровка, ROC не зависит от $\phi$ (AP падает), минимум стоимости около $t^\star$, после куба AUC та же, Брайер хуже, минимум около $(t^\star)^3$.
