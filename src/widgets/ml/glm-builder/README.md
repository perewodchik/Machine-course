# Конструктор GLM

Виджет урока 1.6 «Обобщённые линейные модели» курса «Основы ML». Выбор распределения ответа — нормальное, Бернулли, Пуассон, категориальное с $k = 3$ — заполняет таблицу: $T(y)$, $\eta$, $a(\eta)$, $b(y)$, отклик и градиент на объекте. Ниже — данные с одним признаком (`data.json` — `mlf.datasets`: цена, «дороже медианы» и сегмент от площади; просмотры от числа фото) и кривая $\mathbb{E}[y \mid x]$ при $\eta = \theta_0 + \theta_1 x$, справа — распределение $p(y \mid x)$ в точке запроса. У Пуассона отклик можно подменить тождественным: $\lambda$ уходит в минус, правдоподобие не определено. У категориального веса оптимальные (ползунков нет — их шесть).

Модель — `model.ts`; тесты: оптимальные веса — максимум $\ell$, градиент Пуассона в оптимуме — ноль, распределения нормированы.
