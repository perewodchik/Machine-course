# widgets/_kit — набор для рисунков

Свой SVG-слой на `d3-scale` для виджетов. Виджеты импортируют только `src/widgets/_kit` (не d3 и не Mafs напрямую). Витрина — `/lab`, раздел «Набор для рисунков» (`KitDemo.tsx`).

| Элемент | Что | Главные пропсы |
|---|---|---|
| `Plane` | Плоскость: клетка совпадает с делениями осей, `viewBox` по ширине контейнера, `clipPath` области графика | `x`, `y`, `xStep`, `yStep`, `height`, `equal` (одинаковый масштаб осей — для геометрии: круг, прямой угол), `bare` (без клетки и осей — для проекции трёхмерной сцены), `label` (для скринридера), `xLabel`, `yLabel` |
| `Axis` | Оси с делениями (рисует `Plane`); через ноль или по краю | — |
| `Point` | Точка данных | `x`, `y`, `role`, `sym`, `label` |
| `Line` | Прямая `intercept` + `slope` или отрезок `from` → `to`; подпись у видимого конца, нет подписи — если линия вне графика | `role`, `sym`, `label`, `labelAbove`, `dashed` |
| `Ellipse` | Эллипс: `radii` + `angle` (градусы) или `cov` (2×2) и `k` | `center`, `role`, `filled` |
| `Vector` | Стрелка из `from` (по умолчанию 0) в `to` | `role`, `label` |
| `Polygon` | Многоугольник: цель пунктиром карандашом (`tone="aux"`) или фигура ученика синей ручкой (`tone="pen"`) | `points`, `tone` |
| `Polyline` | Ломаная по точкам — кривая (ветвь гиперболы, линия уровня) цветом роли | `points`, `role`, `dashed` |
| `MathText` | Подпись шрифтом формул, индексы через `_`: `θ_0`, `x_{12}`; имена функций (`cos`, `log`, `det`, `rank` …) — прямым шрифтом | `label`, `role`, `anchor` |
| `ParamSlider` | Ползунок, бегунок цвета роли, `aria-valuetext` | `name`, `value`, `min`, `max`, `step`, `onChange` |
| `Readout` | Показание `J = 5.23`, шкала до минимума | `name`, `value`, `meter` |
| `Scrub` | «Живое число» в тексте: тянуть вбок, стрелки, Shift + стрелка — 10 шагов, Home/End | `label`, `value`, `min`, `max`, `step`, `onChange` |

Правила:

- **Роли** (`data`, `param`, `target`, `aux`) — те же, что у символов в формулах; `aux` — карандаш пунктиром.
- **`sym`** связывает элемент с символом формул: наведение подсвечивает символ везде (`$activeSym`), подсветка из формул утолщает элемент.
- **Обрезка:** всё внутри `Plane` лежит в группе с `clipPath`; видимую часть линии для подписи считает `clipLine` (`clip.ts`).
- **SSR:** до первого измерения ширина — `initialWidth` (660), поэтому разметка сервера и клиента совпадает; без `Math.random` и `Date`.
- **Логика без DOM** — `layout.ts`, `clip.ts`, `format.ts`, `scrub.ts` с тестами в `kit.test.ts`; отрисовка на сервере — `render.test.tsx`.
