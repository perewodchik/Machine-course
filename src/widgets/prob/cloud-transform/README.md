# Линейное преобразование облака

Виджет урока III.10. Облако $X \sim \mathcal{N}(0, I)$ из $300$ точек и его образ $Y = AX + b$. Элементы $A$ и сдвиг $b$ задают бегунки, кнопки — заготовки:
- растяжение;
- поворот;
- сдвиг (shear);
- вырожденная матрица.

Эллипсы уровня $2\sigma$: пунктир — у $X$, сплошной — у $Y$ по формуле $AA^\top$. Показания — элементы $AA^\top$ и выборочная ковариация, $\det A$.

Тесты (`model.test.ts`):
- выборочная ковариация $AX + b$ близка к $AA^\top$, а сдвиг её не меняет;
- $A\Sigma A^\top$ симметрична и $\det(A\Sigma A^\top) = (\det A)^2 \det\Sigma \ge 0$;
- ошибка $A\Sigma$ несимметрична; у вырожденной $A$ облако лежит на прямой.
