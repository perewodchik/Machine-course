# KL между двумя распределениями

Виджет урока III.13. Два распределения на исходах 0–3 задаются весами:
- $p$ — «данные»;
- $q$ — «модель».

На рисунке — столбики $p$ и $q$ рядом. Показания в натах (натуральный логарифм, как в CS229):
- $H(p)$;
- $H(p, q)$;
- $D_{KL}(p \,\Vert\, q)$ и $D_{KL}(q \,\Vert\, p)$ — видно, что они разные.

Если у $q$ нулевой вес там, где у $p$ нет, KL и кросс-энтропия показывают $\infty$.

Тесты (`model.test.ts`):
- $H(p, q) = H(p) + D_{KL}(p \,\Vert\, q)$;
- $D_{KL} \ge 0$ и равна нулю при $p = q$;
- $0 \le H(p) \le \log 4$;
- несимметричность и бесконечность при $q(x) = 0 < p(x)$.
