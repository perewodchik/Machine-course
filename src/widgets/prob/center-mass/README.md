# Матожидание как центр масс

Виджет урока III.5. Бегунки задают веса значений $0, \ldots, 4$; вероятности — веса, делённые на сумму. Сверху столбики $p(x)$ стоят на рычаге, опора — в $\mathbb{E}X$: моменты сил по обе стороны равны. Снизу — парабола $f(x) = x^2$, точки $(x, x^2)$, а также $f(\mathbb{E}X)$ на параболе и $\mathbb{E}f(X)$ над ней. Разрыв Йенсена для $x^2$ равен $\operatorname{Var} X$.

Тесты (`model.test.ts`, fast-check) для любых весов проверяют:
- $\operatorname{Var} X = \mathbb{E}X^2 - (\mathbb{E}X)^2$;
- нулевой момент сил относительно $\mathbb{E}X$;
- неравенство Йенсена;
- $\operatorname{Var}(aX + b) = a^2 \operatorname{Var} X$.
