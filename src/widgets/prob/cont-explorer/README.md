# Обозреватель непрерывных распределений

Виджет урока III.7. Семейства:
- равномерное;
- показательное;
- нормальное;
- Лапласа;
- логистическое;
- бета.

Бегунки задают параметры семейства. На рисунках — плотность с вертикалью в $\mathbb{E}X$ и функция распределения. У нормального отмечены $\mu \pm \sigma$ и $\mu \pm 2\sigma$ и показана доля внутри $\mu \pm \sigma$ (правило 68–95–99.7).

Формулы — `src/lib/math/continuous.ts`: $\operatorname{erf}$ по Абрамовицу — Стегану, $\log\Gamma$ по Ланцошу. Тесты (`continuous.test.ts`):
- $\int p = 1$;
- $F' = p$;
- моменты совпадают с интегралами;
- выполняется правило 68–95–99.7;
- функция распределения логистического — сигмоида.
