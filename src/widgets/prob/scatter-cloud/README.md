# Облако точек

Виджет урока III.9. Сорок точек одной из трёх форм:
- линейное облако с бегунком $\rho$;
- парабола $y = x^2 + \text{шум}$ — зависимость без корреляции;
- кольцо — тоже зависимость без корреляции.

Кнопка «выброс» добавляет точку, которую двигают бегунками $x_0$, $y_0$ — с клавиатуры, как и всё остальное. Показания — ковариация и корреляция облака с выбросом и без него; пунктиры — средние $\bar x$ и $\bar y$.

Модель — `src/lib/math/correlation.ts`. Тесты (`correlation.test.ts`):
- $\lvert \rho \rvert \le 1$;
- корреляция не меняется при сдвиге и положительном масштабе;
- облака дают заданную $\rho$, а у параболы и кольца она около нуля.
