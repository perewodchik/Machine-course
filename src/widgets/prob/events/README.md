# События как области

Виджет урока III.1. Пространство исходов — 36 пар очков двух кубиков, сетка 6 × 6: строка — первый кубик, столбец — второй. Событие $A$ — залитые клетки, $B$ — обведённые; в каждой клетке есть и буквы, поэтому цвет — не единственный носитель смысла. Точка отмечает результат операции $A \cup B$, $A \cap B$ или «не $A$». Показания — $\lvert A \rvert$, $\lvert B \rvert$, $\lvert A \cap B \rvert$ и вероятность результата с проверкой включений-исключений.

Тест (`model.test.ts`) проверяет $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ и $P(\bar A) = 1 - P(A)$ для всех пар заготовок.
