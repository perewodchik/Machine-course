# Плотность и CDF при перетаскивании порога

Виджет урока III.4. Сверху — функция вероятности (столбики) или плотность; часть слева от порога $t$ выделена. Снизу — функция распределения $F(x) = P(X \le x)$ и точка $(t, F(t))$: площадь сверху равна высоте снизу.

Распределения:
- число орлов в четырёх бросках (ступеньки $F$);
- равномерное на $[0, 0.5]$: плотность $2 > 1$, значение плотности — не вероятность;
- показательное с $\lambda = 1$;
- стандартное нормальное.

Тесты (`model.test.ts`) сверяют $F$ с формулами и проверяют, что $F$ не убывает от $0$ до $1$.
