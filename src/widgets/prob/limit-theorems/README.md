# Бегущее среднее и гистограмма суммы

Два виджета урока III.8 на общей модели `model.ts`. Базовые распределения:
- равномерное на $[0, 1]$;
- показательное с $\lambda = 1$;
- Бернулли с $\varphi = 0.2$;
- кубик.

**«Бегущее среднее»** (`RunningMean`) — закон больших чисел. Три независимые выборки длины $n$, бегущее среднее каждой, горизонталь $\mu$ и коридор $\mu \pm 2\sigma/\sqrt{k}$. Кнопка «Новые выборки» меняет seed.

**«Гистограмма суммы»** (`SumHistogram`) — центральная предельная теорема. $4000$ повторов суммы $n$ величин, гистограмма-плотность $Z = (S_n - n\mu)/(\sigma\sqrt{n})$ и плотность $\mathcal{N}(0, 1)$. Показание — доля $\lvert Z \rvert \le 1$ против $0.683$.

Тесты (`model.test.ts`):
- среднее $4000$ значений в пределах $4\sigma/\sqrt{n}$ от $\mu$ для любого seed;
- стандартизованная сумма имеет среднее $0$ и дисперсию $1$;
- при $n = 50$ гистограмма близка к $\varphi$, а одна показательная величина — нет.
