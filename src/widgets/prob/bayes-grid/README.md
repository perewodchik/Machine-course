# Сетка из 1000 человек (урок III.3)

Медицинский тест на популяции из 1000 человек: каждый квадрат — человек. Пурпур — болен (роль «ответ»),
карандаш — здоров; заливка — тест положителен, контур — отрицателен. Порядок «по результату теста» собирает
положительных вместе: среди них больных меньшинство, хотя тест «точный» — так видна ошибка игнорирования базовой частоты.

| Пропс | Что |
|---|---|
| `initial` | `{ prevalence, sensitivity, falsePositive }`; по умолчанию 1 %, 90 %, 9 % |
| `controls` | какие бегунки показать |
| `order` | `disease` или `test` — начальный порядок |

Модель — `model.ts` (`counts`, `evidence` — формула полной вероятности, `posterior` — Байес, `arrange`, `describe`);
эталонные числа — `model.test.ts` и `code/tests/test_bayes.py`. В уроке: `<BayesGrid n={1}>Подпись…</BayesGrid>`.
