# Смесь двух гауссиан и ответственности

Виджет урока III.12. Бегунки задают вес $\phi$ первой компоненты, средние $\mu_1$, $\mu_2$, стандартные отклонения $\sigma_1$, $\sigma_2$ и точку $x_0$.

На рисунках:
- сверху — плотность смеси $p(x) = \phi\, \mathcal{N}(x; \mu_1, \sigma_1^2) + (1 - \phi)\, \mathcal{N}(x; \mu_2, \sigma_2^2)$ и пунктиром взвешенные компоненты;
- снизу — ответственность $w_1(x) = P(z = 1 \mid x)$.

Показания — $p(x_0)$, $w_1(x_0)$, $w_2(x_0)$.

Ответственность считается через логарифмы со сдвигом на максимум: при далёких $x$ обе плотности уходят в ноль, а $w_1$ остаётся числом.

Тесты (`model.test.ts`):
- плотность интегрируется в $1$, моменты по формуле совпадают с интегралами;
- дисперсия смеси больше дисперсии взвешенной суммы;
- ответственность равна прямой формуле Байеса и устойчива при $x = 200$.
