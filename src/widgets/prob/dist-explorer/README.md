# Обозреватель распределений

Виджет урока III.6. Семейства:
- Бернулли;
- биномиальное;
- геометрическое — номер первого успеха;
- Пуассона.

Бегунки задают $\varphi$, $n$ или $\lambda$. На рисунке — столбики $P(X = k)$ и вертикаль в $\mathbb{E}X$. Показания — $\mathbb{E}X$ и $\operatorname{Var}X$ с формулами семейства.

Формулы — `src/lib/math/distributions.ts`. Тесты (`distributions.test.ts`):
- функция вероятности суммируется в $1$;
- моменты по формулам совпадают с суммами по PMF;
- биномиальное с большим $n$ и малым $\varphi$ приближается к Пуассону.
