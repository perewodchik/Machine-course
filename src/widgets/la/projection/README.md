# Проекция с подвижным углом

Виджет урока I.2: $a = (3, 0)$ закреплён, $b$ поворачивается бегунком угла $\varphi$ и меняет длину. Видны проекция $p = \frac{a^\top b}{a^\top a} a$ и перпендикулярный остаток $b - p$; показания — $a^\top b$, $\cos\varphi$ и длина проекции со знаком. При $\varphi > 90°$ скалярное произведение отрицательно и проекция смотрит в обратную сторону.
