# Ax = b: нет решений, одно, бесконечно много

Виджет урока I.6: система $2 \times 2$ как две прямые на плоскости. Первое уравнение $x_1 + 2x_2 = 2$ закреплено, второе меняют бегунки $a_{21}$, $a_{22}$, $b_2$ или заготовки «пересекаются», «параллельны», «совпадают». Показания — ранги $A$ и $[A \mid b]$, вывод — число решений и само решение, если оно одно (теорема Кронекера — Капелли). Проверки — `model.test.ts`.
