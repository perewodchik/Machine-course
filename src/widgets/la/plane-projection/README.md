# Проекция y на плоскость столбцов

Показания — $\hat\theta$, $X^\top(y - \hat y) = 0$ и длина остатка. Что остаток перпендикулярен столбцам и $\hat y$ ближе к $y$ любой точки плоскости, проверяет `model.test.ts` (fast-check).
