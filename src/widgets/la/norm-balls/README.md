# Единичные шары норм

Виджет урока I.2: точки плоскости, где норма равна единице, — ромб у $\ell_1$, круг у $\ell_2$, квадрат у $\ell_\infty$, цветами трёх ролей. Бегунки $x_1$, $x_2$ двигают точку $x$; показания — три нормы и внутри какого «шара» точка. Вложенность $\lVert x\rVert_\infty \le \lVert x\rVert_2 \le \lVert x\rVert_1$ проверяет `model.test.ts` (fast-check).
