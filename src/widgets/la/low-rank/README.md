# Сжать картинку SVD

Виджет урока I.11: картинка $48 \times 48$ (домик, солнце, земля; яркость от $0$ до $1$) и её приближение ранга $k$ рядом. Бегунок $k$ — от $1$ до численного ранга картинки; столбики — сингулярные числа, оставленные выделены цветом данных. Итог под бегунком: сколько чисел хранить, $k(m + n + 1)$ против $mn$, и относительная ошибка $\lVert A - A_k \rVert_F / \lVert A \rVert_F = \sqrt{\sum_{i > k} \sigma_i^2 / \sum_i \sigma_i^2}$.

SVD считается в браузере через собственное разложение $A^\top A$ методом Якоби (`symEig`), приближение — $A_k = A V_k V_k^\top$. Что ошибка совпадает с хвостом сингулярных чисел и при $k$, равном рангу, картинка восстанавливается точно, проверяет `model.test.ts`. Картинки — `<canvas>` $48 \times 48$, растянутые CSS без сглаживания; цвета — токены `--ink` и `--paper`, при смене темы картинки перерисовываются. Тысячи прямоугольников SVG замедляли страницу и проверку axe.

```mdx
<LowRank n={2} k={5}>Подпись рисунка.</LowRank>
```
