# Линии уровня xᵀAx

Виджет урока I.10: симметричная $A = \left(\begin{smallmatrix} a & b \\ b & c \end{smallmatrix}\right)$ задаётся бегунками $a$, $b$, $c$ или заготовками «эллипсы», «полосы», «гиперболы». На плоскости — уровни $x^\top A x = 1$ и $4$ (сплошные) и $-1$, $-4$ (длинный пунктир) цветом данных — это множества точек $x$; собственные оси — карандашными штрихами. Показания — $\lambda_1 \ge \lambda_2$ и вывод о знакоопределённости. Кривые строятся в собственных осях (`levelCurves`): эллипсы с полуосями $\sqrt{k/\lambda_i}$, пары прямых при $\lambda_2 = 0$, гиперболы при разных знаках; что каждая точка лежит на своём уровне, проверяет `model.test.ts` (fast-check).
