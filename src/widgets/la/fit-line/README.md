# Подгонка прямой (`fit-line`)

Урок V.1. Ученик двигает веса θ₀ и θ₁ и видит, как меняются остатки и J(θ) = ½‖Xθ − y‖²; «Показать минимум» ведёт прямую к θ* — решению нормальных уравнений.

- **Данные:** `data.json` — экспорт `code/snippets/la/normal_equations.py#data` (`python scripts/export_widget_data.py`); `code/tests/test_normal_equations.py` проверяет, что экспорт не разошёлся.
- **Числа:** θ* = (0.798, 0.548), J(2.5, 0.25) = 5.23, J(θ*) = 1.466 — `model.test.ts` и pytest.
- **Пропсы:** `initial` ({ t0, t1 }), `lock` (["t0"] — двигать только наклон), `show` ({ residuals, loss, solve }).
- **Символы:** прямая и ползунки — `theta` (оранжевый), точки — `X` (бирюза); подсветка общая с формулами урока.
