# Оболочка двух векторов

Виджет урока I.1: бегунки $c_1$, $c_2$ двигают комбинацию $c_1 a + c_2 b$ (стрелки цветами коэффициентов), кнопки выбирают векторы — не параллельные, параллельные, $b = 0$. «Показать оболочку» рисует узлы целых комбинаций: у независимых векторов — косую решётку на всей плоскости, у параллельных — точки одной прямой и саму прямую.
