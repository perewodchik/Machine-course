# Касательные Ньютона

Виджет урока II.7. Метод Ньютона ищет ноль производной $g = f'$: касательная к графику $g$ в точке $\theta_k$ пересекает ось в $\theta_{k+1} = \theta_k - g(\theta_k)/g'(\theta_k)$. Бегунок $\theta_0$, кнопки «Шаг Ньютона» (до шести) и «Сначала», выбор функции. Таблица итераций показывает, как растёт число верных знаков.

Функции (`FNS` в `model.ts`):
- логистическая потеря с одним признаком (восемь объектов): из $\theta_0 = 0$ сходится за пять шагов, из $\theta_0 = 3$ расходится;
- $\theta^4/4 - \theta^2 - 5\theta$: $g = \theta^3 - 2\theta - 5$, пример самого Ньютона;
- $\theta \operatorname{arctg} \theta - \tfrac12 \log(1 + \theta^2)$: выпукла, но без контроля шага метод расходится при $\lvert \theta_0 \rvert > 1.39$.

Тесты (`model.test.ts`): $g'$ сверяется с конечными разностями, корни — с бисекцией, ошибка проверяется на квадратичную сходимость.
