# Активное и неактивное ограничение

Виджет урока II.9. Минимум $f(x) = \tfrac12 \lVert x - c \rVert^2$ при $g(x) = x_1 + x_2 - 1 \le 0$ — проекция $c$ на полуплоскость. Бегунки двигают $c$. Если $c$ допустима, ограничение неактивно: $x^\star = c$, $\alpha^\star = 0$. Иначе $x^\star$ лежит на границе и $\alpha^\star = g(c)/\lVert a \rVert^2 > 0$. Произведение $\alpha^\star g(x^\star)$ всегда равно нулю — это дополняющая нежёсткость. Значение двойственной функции $d(\alpha^\star)$ совпадает с $p^\star$ — это сильная двойственность.

Тесты (`model.test.ts`):
- перебор сетки допустимых точек не находит точки лучше $x^\star$;
- на случайных $c$ (fast-check) выполняются $d(\alpha) \le p^\star$ при любом $\alpha \ge 0$ и $d(\alpha^\star) = p^\star$.
