# Хорда над графиком

Виджет урока II.5: выпуклость по определению. Хорда соединяет $(a, f(a))$ и $(b, f(b))$; бегунок $t$ двигает точку $t a + (1 - t) b$, и рисунок показывает значение хорды, значение графика и их зазор. Если хорда где-то проходит под графиком (перебор $t$ в `minGap`), виджет пишет, где именно. Показание $f''$ в той же точке — критерий второго порядка.

Функции (`FNS` в `model.ts`): $x^2$, $x^4$ (строго выпукла, хотя $f''(0) = 0$), $\log(1 + e^z)$ (логистическая потеря как функция $z = \theta^\top x$), $x^3$ и двойная яма $(x^2 - 1)^2 + 0.3x$ с локальным минимумом выше глобального. Флаг `convex` сверен перебором хорд, $f''$ — конечными разностями (`model.test.ts`).
