# Сумма прямоугольников → площадь

Виджет урока 0.7: площадь под графиком на отрезке приближается суммой $n$ прямоугольников равной ширины. Высота прямоугольника — значение функции в левой, средней или правой точке его основания. Бегунок $n$ (1–64), кнопки точки и функции; показания — сумма $S_n$, интеграл и ошибка.

Функции (`FNS` в `model.ts`): $x^2$ на $[0, 2]$ (интеграл $8/3$), $e^{-x}$ на $[0, 3]$ ($1 - e^{-3}$), $e^{-x^2/2}$ на $[-4, 4]$ (почти $\sqrt{2\pi}$; эталон — формула Симпсона). Эталоны сверены с Python, порядок ошибки — $1/n$ у левых и правых сумм и $1/n^2$ у средних — в `model.test.ts`.

```mdx
<Riemann n={1} initial={{ fn: "square", n: 4, rule: "left" }} fns={["square"]}>Подпись рисунка.</Riemann>
```

Пропсы: `initial` (`fn`, `n`, `rule`), `fns` — какие функции можно выбрать, `show.exact` — показывать ли интеграл и ошибку.
