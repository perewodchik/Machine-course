# Поле градиентов над линиями уровня

Виджет урока II.1: $f(x) = \tfrac12 x^\top A x$ с заготовками «чаша», «вытянутая чаша», «седло». Карандашом — линии уровня $f = \pm 0.5, \pm 2$ (пунктир) и отрезки $\nabla f$ на сетке; длина стрелки растёт с $\lVert \nabla f \rVert$ до предела. Точка $x_0$ (бегунки $x_1$, $x_2$) — цветом данных вместе с линией уровня через неё; $\nabla f(x_0)$ — цветом ответа, направление $u$ (бегунок $\varphi$, градусы) — цветом параметра. Показания — $f(x_0)$, $\lVert \nabla f \rVert$ и $D_u f = \nabla f^\top u$.

Линии уровня строит `lib/math/conics.ts`, общий с виджетом урока I.10. Что $\nabla f$ совпадает с численным, перпендикулярен линии уровня и что $D_u f \le \lVert \nabla f \rVert$, проверяет `model.test.ts` (fast-check).
