# src — код сайта

Сайт ещё не собран: каталоги задают будущую структуру (этап 1 плана, `docs/analysis.md` §10). Контракты, которые уже можно читать:

- [`lib/content/types.ts`](lib/content/types.ts) — модель контента: понятия, правила, формулы, выводы, проверки;
- [`games/_engine/types.ts`](games/_engine/types.ts) — контракт мини-игры.

Стек (версии сверены 14.10.2026): Astro 7.3 + MDX, React 19 только в островах, Tailwind CSS 4.3, Base UI 1.9 через shadcn/ui, KaTeX 0.19, nanostores, Pyodide 314. Почему так — `docs/analysis.md` §3 и `docs/adr/`.

## Правила зависимостей

Проверяются ESLint (`eslint-plugin-boundaries`).

| Слой | Может импортировать |
|---|---|
| `content/*.mdx` | ничего: компоненты передаются через `<Content components={…}>` |
| `components/*` | `design-system`, `lib/*` (кроме сборочных), `client/` |
| `widgets/*` | `widgets/_kit`, `lib/math`, `lib/state`, `design-system/primitives`. Не импортирует другие виджеты |
| `games/*` | `games/_engine`, `widgets/*/model.ts` (только модели), `widgets/_kit`, `lib/math`, `lib/state` |
| `python/` | `lib/state`, `design-system/primitives` |
| `lib/math` | ничего из проекта |
| `lib/content`, `lib/katex`, `markdown/` | только для сборки: импорт из `*.tsx` и `client/` запрещён, иначе KaTeX и граф уедут в браузер |
| `design-system` | ничего из проекта |

## Обязательные свойства виджетов и игр

1. **Детерминизм.** Начальное состояние строится из `seed`, без `Math.random` и `Date`: иначе разметка сервера и клиента не совпадёт.
2. **SVG с фиксированным `viewBox`**, который пересчитывается по ширине контейнера. Деления осей совпадают с клеткой.
3. **Клавиатура и альтернатива перетаскиванию** (WCAG 2.5.7): стрелки и числовые поля.
4. **Текстовое описание состояния** в `aria-live`, с задержкой во время перетаскивания.
5. **Кнопка сброса и сериализуемое состояние**: ссылка «посмотри на эту конфигурацию».
6. **Цвета только из токенов**, роли символов — из урока.
