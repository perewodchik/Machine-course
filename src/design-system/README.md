# Дизайн-система «Тетрадь в клетку»

Единственный источник правил внешнего вида курса. Токены: [`tokens/tokens.css`](tokens/tokens.css), подключение к Tailwind: [`tokens/theme.css`](tokens/theme.css). Живая витрина: `prototype/design-system.html` (на этапе 1 переедет на страницу `/lab`).

## Концепция

Курс выглядит как аккуратная рабочая тетрадь человека, который учит математику: белая бумага в клетку, поля с красной линией и три ручки. Образ взят из предмета и из привычной русскоязычному ученику тетради, а не из шаблона веб-интерфейса.

| Предмет тетради | Что это в интерфейсе |
|---|---|
| Клетка | Сетка внутри рисунков и виджетов: там у неё есть смысл (координаты). На странице её нет |
| Поля с красной линией | Правая колонка урока: заметки, английские термины, ссылки на CS229, пояснения символов |
| Синяя ручка | Всё, что делает ученик: ссылки, кнопки, ползунки, ввод, фокус, упражнения |
| Красная ручка | Ошибки и поправки: «типичная ошибка» оформлена как правка учителя (неверное зачёркнуто, исправление вписано, пометка на полях) |
| Зелёная ручка | «Верно» и галочка «знаю» |
| Маркер | Полоса под нижней частью строки: изменившаяся часть формулы, ключевая мысль |
| Карандаш | Вспомогательное: подписи осей, остатки и шум на рисунках, интуиция, необязательные выводы |

**Тёмная тема — «грифельная доска»**: графит с зеленцой (оттенок ≈195°, низкая насыщенность) и меловой текст. Значения подобраны отдельно, не инверсией.

## Почему не «кремовая бумага с засечками»

Первая версия (v0.1 в `docs/analysis.md`) предлагала тёплый кремовый фон, заголовки с засечками и метки капителью. Скилл `frontend-design` прямо называет это сочетание самым узнаваемым признаком сгенерированного дизайна. Поэтому в v0.2:

- фон холодный белый (`--paper: #fcfdfe`), без крема;
- заголовки набраны гротеском (IBM Plex Sans), засечки (Literata) остались только для текста;
- метки блоков — заголовки в начале абзаца в обычном регистре («Определение 4.1.»), без капители и надписей над заголовками;
- запоминающийся элемент один — поля тетради с красной линией и правки красной ручкой на них.

Дизайн-критика по скиллу `design-critique` (v0.2) нашла ещё одну системную ошибку: цвета символов совпадали с ручками ($y$ был цвета «верно», $X$ — цвета ссылки, $\theta$ — цвета ошибки). В v0.3 символы и ручки разведены: расстояние в OKLab между ними ≥ 10, а символов стало три.

## Принципы

1. **Текст важнее интерфейса.** Урок прежде всего читают. Интерфейс спокойный и не спорит с формулами.
2. **Цвет символа закреплён за ролью** и совпадает в формуле, на рисунке и в коде. В одной формуле не больше трёх цветных ролей.
3. **Структура несёт смысл.** Нумерация — только у настоящих последовательностей (шаги вывода, уроки). Рамки и линейки отделяют разные по смыслу вещи, а не украшают.
4. **Движение объясняет.** Анимация есть только там, где показывает математику (интерполяция преобразования, сходимость). При `prefers-reduced-motion` её нет.
5. **Доступность — по умолчанию.** Контраст текста ≥ 4.5:1, рамок ≥ 3:1; всё управляется с клавиатуры; у перетаскивания есть альтернатива (WCAG 2.5.7).

### Палитра символов

Три слота и карандаш. У каждого слота два значения: `--sym-N` для линий и точек на рисунке и `--sym-N-text` для символа в формуле (контраст ≥ 4.5:1).

| Слот | Роль по умолчанию (ML) | В уроках ЛА | В уроках про гауссианы | Рисунок, светл. / тёмн. | Текст, светл. / тёмн. |
|---|---|---|---|---|---|
| `sym-1` бирюза | данные $x, X$ | $e_1$, первый вектор | точки $x$ | `#0d9eab` / `#02a5b3` | `#02717a` / `#44d4e2` |
| `sym-2` оранжевый | параметры $\theta, w$ | $e_2$, второй вектор | среднее $\mu$ | `#bf7101` / `#c77609` | `#8f5301` / `#f4ad67` |
| `sym-3` пурпур | ответы $y$ | результат $Av$ | ковариация $\Sigma$ | `#823bae` / `#9b56c2` | `#7b38a3` / `#e0a4ee` |
| карандаш `--ink-3` | остатки $\varepsilon$, шум | построения | — | пунктир | `--ink-3` |

Как выбирали:

- **Валидатор палитр `dataviz`** (симуляция дальтонизма по Machado 2009): три слота попарно различимы для дальтоников и при обычном зрении в обеих темах. Худшая пара светлой темы ΔE 16.6, тёмной 10.6, при пороге 8.
- **Расстояние до ручек** в OKLab (×100) не меньше 10.7. В v0.2 было 1.5: $y$ совпадал с зелёной «верно».
- **Контраст** меток на рисунке ≥ 3:1 к фону рисунка, текстовых вариантов ≥ 4.5:1 к бумаге.

Правила:

- **Цветных ролей не больше трёх.** Всё вспомогательное рисуется карандашом, пунктиром.
- **Ручки никогда не красят символы.** Синий, красный и зелёный закреплены за интерфейсом и обратной связью.
- **Цвет — не единственный носитель смысла.** У символа всегда есть подпись или легенда, а у линии на рисунке — прямая подпись.

### Отступы, формы, движение

- Отступы: шаг 4 px, шкала `--space-1…9` = 4, 8, 12, 16, 24, 32, 48, 64, 96 px.
- Скругление растёт с размером: `--radius-inline` 3 px (код в строке, маркер), `--radius-control` 6 px (кнопки, поля), `--radius-panel` 10 px (рисунки, карточка формулы).
- Теней нет. Исключение — всплывающие слои (`--shadow-popover`).
- `--duration-ui` 160 мс для интерфейса, `--duration-math` 600 мс для анимации математики.
- Клетка `--cell` = 20 px; деления осей на рисунках совпадают с клеткой.

## Раскладка урока

```
┌ шапка: «Курсы ML / курс», прогресс курса, тема ────────────────────────────────┐
│ оглавление 272 │ текст 640                       ┃ поля 240                     │
│  части курса ✓ │ хлебные крошки   [Скрыть поля]  ┃                              │
│  уроки ✓       │ H1, лид                         ┃ заметка: раздел CS229        │
│                │ «Опирается на»                  ┃                              │
│                │ текст, формулы                  ┃ заметка рядом с абзацем      │
│                │ ┌ рисунок, карточка формулы ┐   ┃                              │
│                │ └───────────────────────────┘   ┃                              │
└────────────────┴─────────────────────────────────┸──────────────────────────────┘
```

- **Обычный режим (≥ 1260 px):** три колонки; красная линия полей между текстом и заметками. Рисунки, карточки формул и код **не заходят за линию полей**: всё в колонке текста.
- **Режим «Поля скрыты»** (кнопка «Скрыть поля» над текстом, состояние запоминается): контент по центру; текст — `--measure`, рисунки и карточки формул (`.wide`) расширяются симметрично до `--wide-measure` (54rem). Заметки сворачиваются в строки-заголовки («В CS229», «По-английски») и раскрываются по клику или клавишей Enter. Шаги вывода получают колонку обоснований справа.
- **900–1260 px:** заметки встают в текст с тонкой красной линией слева; кнопка «Скрыть поля» сворачивает их так же.
- **< 900 px:** оглавление — выдвижная панель по кнопке в шапке; рисунки пересчитывают `viewBox` по ширине.

Каждая заметка обязана иметь подпись (`.label`) — по ней заметка узнаётся в свёрнутом виде.

### Рисунки

- Всё, что зависит от параметров (прямые, остатки, подписи), обрезается областью графика (`clipPath`): при крайних значениях ползунков ничего не вылетает за оси.
- Подпись линии ставится у её видимого конца; если линия целиком вне графика, подпись скрывается.

### Педагогические блоки

Цвет несут только линейка слева и заголовок в начале абзаца. Синий, красный и зелёный сохраняют свой смысл и здесь.

| Блок | Цвет и линейка | Заголовок |
|---|---|---|
| Определение | чернила, 2 px | «Определение 4.1.» |
| Теорема, ключевой результат | чернила, двойная 4 px | «Теорема 4.3.» |
| Интуиция, «попробуйте сами» | карандаш, 2 px | «Интуиция.» |
| Вывод, необязательное | карандаш, пунктир | «Вывод.» |
| Типичная ошибка | красная ручка; правка с зачёркиванием и пометкой на полях | «Типичная ошибка.» |
| Упражнение, проверка | синяя ручка (действие ученика) | «Упражнение 3.», «Проверка.» |

Нумерация формул, рисунков и упражнений — внутри урока («Формула 4»). Ссылка из другого урока — «формула 4 урока V.1».

### Галочка «знаю»

Одна булева отметка на урок — чекбокс: **пустая клетка** 12 px карандашом (`--control-border`, 3:1 к фону) или **зелёная галочка** 16 px (`--green-pen`); при наведении клетка обводится синей ручкой. Цель нажатия 24 px, на сенсорных экранах строка оглавления — `--target-touch`. У чекбокса без текста имя — «Знаю: IV.1 Выборка и описательная статистика».

- **Оглавление:** чекбокс в левой колонке, перед номером урока; в той же колонке у модуля — шеврон раскрытия. Модуль, где отмечены все обязательные уроки, — галочкой справа вместо счётчика `n/m` (уроки ★ не считаются). Текущий урок выделен фоном `--pen-wash`. Открыт модуль текущего урока; остальные ученик раскрывает сам, состояние запоминается (в прототипе для наглядности раскрыт и IV).
- **Урок:** «Знаю эту тему» — чекбокс с текстом под строкой о длительности урока; в «Опирается на» — чекбоксы у пререквизитов.
- **Главная:** чекбоксы в списках уроков; на карте курса — галочка на углу рамки модуля.
- **Шапка:** «Курсы ML / Название курса» (знак и «Курсы ML» ведут в каталог), справа — «Знаю 47 из 52 уроков курса» и полоска по текущему курсу; на узком экране — знак, название курса, галочка и «47 из 52». Отметка урока другого курса (например, математики из «Опирается на» в уроке ML) счётчик текущего курса не меняет.
- **Каталог курсов:** карта курсов на клетке (сплошная стрелка — нужно до начала, пунктир — рекомендуется), выбранный маршрут — синей ручкой, остальное бледнее; ниже — оглавление курсов строками, без одинаковых карточек.
- Все чекбоксы одного урока синхронны.

## Чего не делаем

Проверяется линтерами там, где это возможно (⚙).

1. ⚙ Сырые цвета в компонентах; дефолтная палитра Tailwind (отключена в `theme.css`: `bg-indigo-500` не существует).
2. ⚙ Градиенты, `backdrop-filter`, тени вне `--shadow-popover` (stylelint + `eslint-plugin-better-tailwindcss` для классов в разметке).
3. Кремовый фон с контрастными засечками и терракотовым акцентом.
4. Метки капслоком над заголовками, строки через средние точки, стрелка «→» в конце ссылок.
5. Одинаковые карточки вместо текста; иконки у каждого пункта; эмодзи.
6. Анимация при прокрутке и «въезжающие» блоки.
7. Моноширинный шрифт для подписей и цифр интерфейса.
8. Центрирование текста (кроме выключных формул).
9. Цвета ручек (синий, красный, зелёный) для символов и линий на графиках; цветной код в листингах (код почти монохромный).

## Как расширять

1. Новый цвет или размер — сначала токен в `tokens.css` (обе темы), затем в `theme.css`. Контраст посчитать и записать в комментарий.
2. Новая палитра для графиков — прогнать валидатор `dataviz` (`validate_palette.js`) в обеих темах и проверить расстояние до ручек (≥ 10).
3. Новый компонент — сначала на витрине (`/lab`) во всех состояниях: обычное, наведение, фокус, нажатие, недоступно, ошибка. Затем скриншот-тест.
4. Перед ревью интерфейса — скиллы `design-critique` и `accessibility-review` из `.claude/skills/`.
