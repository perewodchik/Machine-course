# Переобучи, если сможешь: λ

Режим «λ» игры «Переобучи, если сможешь», урок 2.3 «Основ ML». Данные: $d = 20$ признаков $x_j \sim \mathcal{N}(0, 1)$, $y = 1 + \theta^{*\top} x + \varepsilon$, $\sigma = 1$; валидационная часть — 40 объектов, скрытый тест — 400. Игрок выбирает штраф — L2, $(X^\top X + \lambda I)\theta = X^\top y$, или L1, $\tfrac12\lVert y - X\theta\rVert^2 + \lambda\lVert\theta\rVert_1$ (покоординатный спуск), — и $\log_{10}\lambda$ от $-1$ до $4$ с шагом $0.5$; свободный член не штрафуется. Уровень пройден, если тестовая ошибка не больше чем на $3\,\%$ выше, чем у модели с наименьшей валидационной ошибкой на той же сетке. Очки — лучшая на сетке тестовая ошибка, делённая на ошибку игрока, минус $0.25$ за каждую повторную сдачу.

Уровни:
1. «Все признаки понемногу» — $\theta^*_j = \pm 0.3$, $n = 60$: L2 не хуже L1.
2. «Два полезных из двадцати» — $\theta^* = (2, -1.5, 0, \dots, 0)$, $n = 60$: выигрывает L1.
3. «Мало данных» — та же истина, $n = 28$.
4. «Только шум» — $\theta^* = 0$: лучшая модель — константа $\bar y$ ($\lambda \to \infty$).
5. «Решите сами» — случайный из первых трёх.

Тесты (`model.test.ts`): L2 — нулевой градиент в решении; L1 — условия KKT; при $\lambda \to \infty$ — константа $\bar y$; на разреженной истине по тесту выигрывает L1, на плотной — L2; бот по валидации проходит любой уровень.
