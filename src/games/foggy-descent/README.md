# Спуск в тумане

Игра урока II.6. Поверхность $f(x) = \pm\tfrac12 (x - m)^\top A (x - m)$ скрыта. В текущей точке видны только значение $f$ и стрелка градиента. Игрок шагает в одном из восьми направлений на $0.5$ или, у дна, на $0.2$. Цель — оказаться не дальше $0.45$ от оптимума. Очки — отношение наименьшего возможного числа шагов к сделанному; на шаги есть лимит, 30.

Уровни (`LEVEL_KINDS` в `model.ts`):
1. Круглая чаша.
2. Вытянутая повёрнутая чаша: стрелка смотрит не на минимум.
3. Подъём к максимуму: идти по стрелке.
4. Шумный градиент: стрелка — оценка, как в SGD; шум детерминирован seed и номером шага.
5. Смешанный.

Тесты (`model.test.ts`):
- градиент сверяется с конечными разностями;
- оракул решает каждый уровень не дольше чем за наименьшее число шагов плюс два;
- бот «против стрелки» решает все уровни без шума и большинство шумных.
