# Угадай корреляцию

Игра урока III.9. По облаку точек выбрать его выборочную корреляцию из трёх-четырёх вариантов. Оси стандартизованы: наклон не подсказывает, видна только форма облака.

Уровни по пять облаков:
1. «Знак» — $-0.8$, $0$, $0.8$.
2. «Сила связи» — четыре варианта из $-0.9, -0.6, \ldots, 0.9$.
3. «Тонкие различия» — $0.2$, $0.5$, $0.8$ одного знака.
4. «Ловушки» — парабола и кольцо (зависимость без корреляции), облако с одним выбросом.
5. «Малая выборка» — двенадцать точек.

Верный вариант — ближайший к выборочной корреляции; облако перегенерируется, пока до него не больше $0.08$. Тесты (`model.test.ts`): однозначность ответа на любом seed, ловушки, бот проходит уровень.
