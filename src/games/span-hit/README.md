# Попади в точку

Игра к урокам I.1 и I.6: подобрать коэффициенты $c_1$, $c_2$ так, чтобы $c_1 a + c_2 b$ попала в цель, или заявить «невозможно», если цель вне линейной оболочки $a$ и $b$. Ход — изменить один коэффициент на шаг; счёт — доля минимума ходов, каждое неверное «невозможно» делит счёт.

Уровни (`KINDS`): векторы вдоль осей; косые векторы; половинки (шаг 0.5); параллельные векторы, цель на их прямой (решений бесконечно много); цель вне прямой (ответ — «невозможно», граничный случай); смешанный. Решаемость каждого уровня ботом `solve` за минимум ходов проверяет `model.test.ts` (fast-check по seed).
