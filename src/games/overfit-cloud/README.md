# Переобучи, если сможешь: облако

Режим «Облако» игры «Переобучи, если сможешь» (базовый режим — урок IV.7 математики), урок 2.2 «Смещение и разброс» курса «Основы ML». По $n$ и $\sigma$ игрок предсказывает степень полинома с наименьшей ожидаемой ошибкой на свежих данных ($\sigma^2 + \text{смещение}^2 + \text{разброс}$ по 100 выборкам), затем видит облако из 100 моделей выбранной степени. Очки — ошибка лучшей степени, делённая на ошибку выбранной; уровень пройден при 0.85. Уровни: много данных и мало шума; средняя выборка; сильный шум; десять точек и шум, где выигрывает прямая или константа.

Отдельная игра, а не режим существующей: модель и уровни другие, движок общий.
