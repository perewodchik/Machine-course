# Порог расходимости

Игра урока II.6. Градиентный спуск $x := x - \eta A x$ на $f(x) = \tfrac12 x^\top A x$ умножает координату вдоль собственного вектора на $1 - \eta\lambda$ и сходится ровно при $0 < \eta < 2/\lambda_{\max}$. Игрок двигает бегунок $\eta$, запускает 30 шагов и видит траекторию на линиях уровня. Сдать можно только шаг, проверенный запуском и сходящийся. Очки — доля сданного $\eta$ от порога $2/\lambda_{\max}$.

Уровни (`LEVEL_KINDS` в `model.ts`):
1. Одна переменная, $f = \tfrac12 a x^2$.
2. Диагональная $A$.
3. Повёрнутые оси — порог считается по собственным значениям.
4. Вытянутая чаша: число обусловленности $\ge 16$.
5. Решите сами.
6. «Квартиры»: $H = Z^\top Z/n$ для признаков $1$ и площади в десятках м² (урок 1.2 «Основ ML»), порог $\approx 0.033$, шаг бегунка $0.001$.
7. «Квартиры» после стандартизации: корреляционная матрица площади и комнат, порог $\approx 1.08$. Матрицы закреплены в `code/tests/test_lms.py`.

Тесты (`model.test.ts`) сверяют порог с траекторией: при $0.95$ порога спуск приближается к минимуму, при $1.05$ — уходит. Бот сдаёт шаг сетки чуть ниже порога.
