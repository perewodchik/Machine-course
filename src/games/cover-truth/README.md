# Покрой истину

Игра урока IV.8★. Доверительный интервал $\bar x \pm z\,\mathrm{se}$ для среднего $\mu$, где $\mathrm{se} = \sigma/\sqrt n$ при известной $\sigma$ и $s/\sqrt n$ при оценённой. Залп — $100$ выборок и $100$ интервалов; видно, сколько накрыли $\mu$. Игрок подбирает $z$ и сдаёт его. Настоящее покрытие считается по $4000$ скрытым выборкам; уровень пройден, если оно отличается от заданного уровня доверия не больше чем на $1.5$ процентного пункта. Непринятая сдача не закрывает уровень, но снижает балл.

Уровни:
1. «σ известна» — нормальные данные, $n = 20$–$25$, $95\,\%$: $z \approx 1.96$.
2. «Уровень 90 %» — то же, $z \approx 1.645$.
3. «Пять наблюдений» — $\sigma$ оценивается, $z \approx t_{0.975}(4) = 2.78$.
4. «Скошенные данные» — экспоненциальные, $n = 8$: табличного $t$ мало.
5. «Решите сами».

Тесты (`model.test.ts`):
- $1.96$ и $1.645$ при известной $\sigma$ дают около $95$ и $90\,\%$;
- при пяти наблюдениях $1.96$ не проходит, $2.78$ — проходит;
- на скошенных данных $t$-интервал накрывает реже $95\,\%$;
- доля накрывших в залпах согласована с покрытием;
- бот проходит любой уровень, плохая сдача уровень не закрывает.
