# Минимум, максимум или седло

Игра урока II.4. В критической точке функция ведёт себя как $\tfrac12 h^\top H h$; на каждом из пяти уровней — четыре карточки с гессианом $H$, нужно назвать тип точки: минимум, максимум, седло или «по гессиану не определить».

| Уровень | Что видно | Граничный случай |
|---|---|---|
| по картинке | линии уровня, диагональная $H$ | эллипсы против гипербол |
| повёрнутые оси | линии уровня, $b \ne 0$ | тип не зависит от поворота осей |
| только числа | матрица $H$ | $\det H$ и $\operatorname{tr} H$ |
| вырожденный гессиан | матрица $H$ | $\det H = 0$ — решают старшие члены |
| решите сами | матрица $H$ | всё вместе |

Очки — доля карточек, распознанных с первого раза. После ответа — разбор: $\det H$, $\operatorname{tr} H$ и собственные значения. Модель — `model.ts` (`classify`, `explain`, бот `solve`), тесты — `model.test.ts`; линии уровня — `lib/math/conics.ts`.
