# Приор против монеты

Игра урока IV.6. Двенадцать монет из одной партии; по каждой видно $n$ бросков. Игрок выбирает априорное $\operatorname{Beta}(\alpha, \beta)$ и предсказывает вероятность орла апостериорным средним $(k + \alpha)/(n + \alpha + \beta)$. MLE-бот предсказывает $k/n$, обрезанное до $[0.01, 0.99]$. Обе стратегии оцениваются средней кросс-энтропией на $30$ следующих бросках каждой монеты. Уровень пройден, если потеря игрока не больше, чем у бота; при большом $n$ засчитывается ничья.

Уровни:
1. Почти честные монеты, по $3$ броска.
2. Кривые монеты (Beta(16, 4)), по $4$ броска — нужен несимметричный приор.
3. По $2$ броска.
4. Монеты какие угодно — сглаживание Лапласа, Beta(1, 1).
5. По $40$ бросков — приор почти не важен.

Монеты разыгрываются заново, если даже приор, совпадающий с партией, проигрывает боту по случайности будущих бросков: уровень всегда проходим. Тесты (`model.test.ts`):
- приор партии обыгрывает бота на любом seed;
- сильный неверный приор проигрывает.
