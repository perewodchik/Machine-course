# Переобучи, если сможешь

Игра урока IV.7. Данные — $y = h^*(x) + \varepsilon$, $\varepsilon \sim \mathcal{N}(0, \sigma^2)$, $x$ равномерно на $[-1, 1]$: обучающая часть — $12$ точек почти равномерно по отрезку (на уровне «восемь точек» — $8$), валидационная — $30$ случайных точек, и скрытая тестовая из $200$. Игрок выбирает степень полинома $0$–$10$ и $\log_{10}\lambda$ от $-6$ до $2$; модель — гребневая регрессия $\theta = (\Phi^\top\Phi + \lambda I)^{-1}\Phi^\top y$ по обучающей части. Видны ошибки на обучении и валидации. «Сдать модель» открывает ошибку на тесте; уровень пройден, если она не больше чем на $2\,\%$ выше тестовой ошибки модели, выбранной по минимуму валидационной ошибки на той же сетке. Каждая повторная сдача (подсмотренный тест) снижает балл на $0.25$.

Уровни:
1. «Синусоида» — $\sin \pi x$, $\sigma = 0.25$.
2. «Парабола» — $1.5x^2 - 0.5$, $\sigma = 0.2$.
3. «Шумная прямая» — $0.8x$, $\sigma = 0.5$.
4. «Восемь точек» — синусоида по восьми точкам.
5. «Решите сами» — случайная из первых четырёх.

Тесты (`model.test.ts`):
- подгонка прямой совпадает с МНК, при большом $\lambda$ веса почти нули;
- ошибка на обучении не растёт со степенью, степень 10 на синусоиде переобучается;
- бот, выбирающий по валидации, проходит любой уровень; степень 10 без штрафа почти всегда не проходит.
