# Скульптор Σ

Игра урока III.11. Подогнать эллипс $\mathcal{N}(\mu, \Sigma)$ под облако из $150$ точек: бегунки $\sigma_1$, $\sigma_2$, $\rho$, на поздних уровнях и $\mu$. «Проверить» считает $\mathrm{KL}$ между гауссианой с выборочными $\hat\mu$, $\hat\Sigma$ и гауссианой игрока; уровень пройден при $\mathrm{KL} \le 0.05$.

Уровни:
1. «Оси вдоль координат» — $\rho = 0$, только $\sigma_1$ и $\sigma_2$.
2. «Наклон» — добавляется $\rho$.
3. «Сильная связь» — $\lvert\rho\rvert \approx 0.9$.
4. «Сдвинутый центр» — добавляется $\mu$.
5. «Решите сами».

Подсказка называет параметр, который сильнее всего портит подгонку. Тесты (`model.test.ts`): бот с выборочными оценками проходит любой уровень на любом seed, а начальная догадка — нет.
