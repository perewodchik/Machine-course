# Тир оценок

Игра урока IV.2. Оценка $\hat\theta = c\bar x$ среднего $\theta$ нормальной выборки размера $n$ с разбросом $\sigma$. Залп — $200$ выборок и $200$ оценок вокруг мишени $\theta$; после залпа видны эмпирические смещение², дисперсия и MSE. Игрок подбирает $c$ и сдаёт его. Уровень пройден, если $\mathrm{MSE}(c) = (c - 1)^2\theta^2 + c^2\sigma^2/n$ не больше чем на $5\,\%$ выше минимума при $c^\star = \theta^2/(\theta^2 + \sigma^2/n)$. Непринятая сдача не закрывает уровень, но снижает балл.

Уровни:
1. «Много данных» — $c^\star \approx 1$, несмещённая оценка почти лучшая.
2. «Пять наблюдений» — выгодно сжатие.
3. «Шумная выборка».
4. «Мишень у нуля» — сжатие как регуляризация.
5. «Решите сами».

Тесты (`model.test.ts`):
- бот с $c^\star$ проходит любой уровень;
- эмпирическая MSE залпа близка к теоретической;
- $c = 1$ не проходит уровни «пять наблюдений» и «мишень у нуля»;
- плохая сдача не закрывает уровень.
