# Тетрис размерностей

Игра уроков I.3 и II.3. Из блоков-матриц собрать произведение нужной формы: соседние блоки стыкуются, когда число столбцов левого равно числу строк правого, а форма произведения — строки первого × столбцы последнего. Блоки нарисованы клетками цветом роли (данные, параметры, ответы); на поздних уровнях их можно транспонировать.

| Уровень | Что собрать | Чему учит |
|---|---|---|
| 1. Матрица на вектор | $Av$ | порядок множителей: $vA$ не определено |
| 2. Цепочка из трёх | $ABC$ | форма зависит только от крайних размеров |
| 3. Внешнее произведение | $uw^\top$ формы $k \times k$ | $u^\top w$ — число, $uw^\top$ — матрица ранга 1 |
| 4. Градиент МНК | $X^\top y$ формы $d \times 1$ | градиент той же формы, что $\theta$ |
| 5. Нормальные уравнения | $X^\top X \theta$ | $X^\top X$ — квадратная $d \times d$ |
| 6. Решите сами | четыре блока, часть выдана транспонированной | собирать с краёв |

Ходы: добавить блок в конец цепочки, убрать, сдвинуть влево или вправо, транспонировать. Счёт — доля минимума ходов (`optimalMoves`: по ходу на блок и на каждое нужное транспонирование). Бот `solve` для тестов собирает решение с наименьшим числом транспонирований.

Страница: `/games/dim-tetris/?seed=&level=`.
