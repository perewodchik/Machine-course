# Зоопарк распределений

Игра урока III.6. По сюжету («число звонков в колл-центр за минуту») или по форме функции вероятности нужно узнать семейство:
- Бернулли;
- биномиальное;
- геометрическое;
- Пуассона;
- категориальное;
- мультиномиальное.

Пять уровней по пять карточек; очки — доля верных с первого раза.

Уровни (`LEVEL_KINDS` в `model.ts`):
1. Успехи и неудачи: Бернулли, биномиальное, геометрическое.
2. Редкие события: добавляется Пуассон.
3. Много классов: категориальное и мультиномиальное.
4. По форме: столбики и описание значений.
5. Смешанный.

Функции вероятности — `src/lib/math/distributions.ts`. Тесты (`model.test.ts`):
- на каждом уровне встречаются все его семейства;
- у карточек «по форме» вероятности суммируются в $1$;
- бот проходит все уровни.
