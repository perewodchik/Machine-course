# Байес-детектив (урок III.3)

Улики приходят по одной; после каждой ученик называет вероятность гипотезы (бегунок 0–100 %).

- **Понятие:** апостериорные шансы = априорные шансы × отношение правдоподобия $P(e \mid H) / P(e \mid \neg H)$; улики условно независимы.
- **Счёт — логарифмическое правило:** потеря шага — $\mathrm{KL}(p \,\|\, q)$ в битах между байесовским ответом $p$ и ответом $q$, очки — $100 \cdot 2^{-\mathrm{KL}}$. Максимум даёт только честный байесовский ответ.
- **Уровни:** одна улика → редкая гипотеза (базовая частота) → две улики → улика против → три улики, одна слабая. Истории: медицина, спам, детектив.
