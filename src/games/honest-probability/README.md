# Честная вероятность

Игра урока 1.4 «Логистическая регрессия и метод Ньютона» курса «Основы ML». Объекты на прямой с метками 0 и 1, модель $p(x) = g(k(x - b))$. Игрок сначала отмечает догадку о лучшей границе, потом подбирает границу $b$ и крутизну $k$. Очки — логарифмическое правило: средний $\log p(y \mid x)$ против максимума $\ell(\hat\theta)/n$; уровень пройден при отставании не больше 0.02.

Уровни (`LEVEL_KINDS`): перекрытые классы; выброс у границы; редкий класс (граница уходит к нему); разделимые данные — максимума нет, нужно $\ell/n \ge -0.05$, разбор про штраф $\lambda\lVert\theta\rVert^2$.

Тесты (`model.test.ts`): бот проходит все уровни, без догадки ручки не двигаются, на разделимых $\ell$ растёт с крутизной, редкий класс сдвигает границу, выброс смягчает крутизну.
