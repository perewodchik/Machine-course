# Переводчик сумм

Игра к уроку 0.4: собрать матричную запись из индексной. Ученик ставит множители в цепочку (векторы — столбцы, матрицы, вектор из единиц), транспонирует их кнопкой ⊤ и сразу видит размер произведения и его индексную запись — перевод обратно. Где множители не стыкуются, игра называет место: «у xᵀ столбцов 3, а у A строк 4».

Уровни (`KINDS`): скалярное произведение $x^\top y$, сумма элементов $\mathbf 1^\top y$, матрица на вектор $Ax$, строка — матрица — столбец $x^\top A y$, внешнее произведение $x y^\top$ (суммы нет — граничный случай), $X^\top y$ и $X^\top X$ (сумма по номеру объекта, как в CS229). Размеры — из `rng` уровня, у каждого уровня есть лишняя плитка.

Проверка — на двух наборах случайных целых чисел: равные записи принимаются обе ($x^\top y$ и $y^\top x$, $x^\top A y$ и $y^\top A^\top x$). Что «верно» не бывает ложным, проверяет `model.test.ts`: все цепочки до трёх множителей, принятые игрой, совпадают с ответом и на свежих числах (fast-check по seed). Счёт — точность перевода: $1/k$, где $k$ — число проверок.

Индексы назначаются по порядку появления: элемент $(p, q)$ матрицы $A^\top$ — это $A_{qp}$, поэтому у $X^\top y$ сумма идёт по первому индексу $X$: $\sum_i X_{ij} y_i$.
