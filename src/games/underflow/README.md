# Underflow

Игра к уроку 0.5: правдоподобие — произведение вероятностей, и во float64 оно быстро становится нулём. Уровни 1–3 («монетка» — все $p_i = 0.5$, «обычная модель» — $p_i$ от 0.05 до 0.95, «уверенная модель» — от 0.4 до 0.99): предсказать, на каком объекте произведение обратится в ноль. Уровень 4: предсказать сумму натуральных логарифмов для 2000 объектов — обычное число без нуля. Уровень 5 (граничный случай): у обеих моделей произведение — ноль, а суммы логарифмов различают, какая лучше.

Ноль находится честным перемножением в числах JavaScript (это float64): $0.5^{1075} = 0$, потому что $2^{-1074}$ — наименьшее положительное число. Произведение чисел больше 0.5 застревает на $2^{-1074}$ (округление), поэтому у «уверенной модели» есть и вероятности до 0.4. Счёт — точность прогноза: отношение меньшего числа к большему; в «сравнении» — $1/k$, где $k$ — число выборов.

Что ноль наступает внутри оси, сумма логарифмов — в пределах прогноза, а в «сравнении» обе модели обнуляются и логарифмы их различают, проверяет `model.test.ts` (fast-check по seed).
