# Машина правдоподобия

Игра урока IV.3. По выборке найти параметр с наибольшим логарифмом правдоподобия $\ell(\theta)$. Кривая $\ell$ скрыта. Игрок делает до шести замеров — видит $\ell$ в выбранных точках — и сдаёт $\theta$. Сдача принимается, если $\ell(\theta) \ge \ell(\hat\theta) - 0.5$. После сдачи кривая показывается целиком.

Уровни:
1. Монета, Бернулли.
2. Звонки за минуту, Пуассон.
3. Среднее нормального.
4. Время ожидания, показательное.
5. Разброс нормального.

Максимум можно найти и без замеров — по формуле оценки: доля, $\bar x$, $1/\bar x$, $\sqrt{\sum x_i^2/n}$. Балл тем выше, чем меньше замеров и промахов.

Тесты (`model.test.ts`):
- MLE по формуле не хуже ни одной точки сетки;
- бот проходит любой уровень;
- край диапазона не принимается.
