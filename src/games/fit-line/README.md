# Подгони прямую

Игра к урокам 0.1 и V.1: провести прямую «цена = θ₀ + θ₁ · площадь» через «Квартиры» (`code/mlf/datasets.py`, экспорт — `scripts/export_widget_data.py`) и сдать её. Принимается прямая, у которой функция потерь $J = \tfrac12\sum_i (y^{(i)} - \hat y^{(i)})^2$ не больше минимума на 5 %; счёт — $J_{\min} / J$.

Уровни: «наклон» (прямая через ноль, двигается только θ₁), «наклон и сдвиг» (цена с ремонтом, +3 млн), «выброс» (одна дорогая квартира тянет прямую). У каждого seed — своя выборка из 12 квартир; решаемость на сетке шагов бегунков проверяет `model.test.ts` (fast-check).
