# Найди утечку

Игра урока 2.5 «Кривые обучения, анализ ошибок и утечки» курса «Основы ML». Уровень — описание задачи, признаки с моментом, когда каждый становится известен, шаги конвейера и схема разбиения, а валидация подозрительно хороша. Игрок указывает источник утечки или говорит, что её нет; каждый вариант после выбора разобран. Очки: 1 за верный выбор с первого раза, минус 0.25 за каждый неверный.

Уровни: длительность звонка (целевая утечка); кодирование района средней ценой по всей выборке (утечка через предобработку); случайное разбиение продаж по дням (временная утечка); копии объявлений по обе стороны разбиения; честная модель — лучший ход ничего не убирать.

Числовых «результатов переобучения» в игре нет: исходы описаны словами, чтобы не выдумывать чисел.
