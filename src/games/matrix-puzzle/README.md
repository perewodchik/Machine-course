# Матрица-пазл (урок I.4)

Подобрать матрицу $A$ 2 × 2, которая переводит букву F в пунктирный контур. Ход — изменить один элемент на шаг.

- **Понятие:** столбцы матрицы — образы базисных векторов: первый столбец — куда уходит $e_1$, второй — $e_2$.
- **Счёт:** ходы против минимума (`score` — доля оптимума). Без таймера.
- **Уровни** (`generate(rng, difficulty)`): растяжение → сдвиг → поворот → отражение ($\det A = -1$) → сжатие в линию ($\det A = 0$, шаг 0.5); дальше — любая невырожденная целая матрица.
- **Разбор после уровня** — `DEBRIEF`: вопрос про определитель как коэффициент площади и знак ориентации.
- **Доступность:** счётчики «− значение +» с именами `a₁₁…a₂₂`; `describe` даёт столбцы, `det A` и опорные точки цели — замену рисунку.
- **Тесты:** `model.test.ts` (fast-check: детерминизм, решаемость каждого уровня ботом за оптимум), `tests/e2e/matrix-puzzle.spec.ts` (уровень проходится с клавиатуры, axe).
- Страница — `src/pages/games/matrix-puzzle.astro`; партия по ссылке — `?seed=7&level=3`.
