# Пилот среза: инструкция

Пилот проверяет три урока среза на 6–10 участниках: понятно ли объяснение, где ученики спотыкаются и сколько урок добавляет к знаниям. Сервера нет: всё хранится в браузере участника, а результаты он присылает файлом.

## Для участника

1. Откройте ссылку, которую прислал организатор, — в ней есть `?pilot=1`. Так включаются задания «до урока»; браузер запомнит режим.
2. Пройдите уроки по порядку, в одном браузере:
   - I.4. Матрица как линейное отображение — `/foundations/linear-algebra/matrix-as-map/?pilot=1` — около 40 минут;
   - III.3. Формула полной вероятности и Байес — `/foundations/probability/bayes/?pilot=1` — около 45 минут;
   - V.1. Линейная регрессия тремя способами — `/foundations/bridge/linear-regression/?pilot=1` — около 50 минут.
3. В начале урока решите задание «До урока» — честно, без подсказок урока. Ошибиться не страшно: так видно, сколько урок добавил.
4. Проходите урок как обычно: упражнения, рисунки, ячейки кода, итоговая проверка.
5. В конце урока ответьте на три вопроса блока «Как прошёл урок?» и нажмите «Сохранить ответ».
6. После всех трёх уроков нажмите «Скачать отчёт» (в конце любого урока) и пришлите файл `mlf-otchet-….json` организатору.

В отчёте — ваши попытки упражнений, открытые шаги выводов, ответы опроса и отметки «знаю». Имени и почты в нём нет: участника отличает случайный номер браузера.

Выключить режим пилота — открыть любую страницу с `?pilot=0`.

## Для организатора

1. Разошлите участникам ссылку на урок I.4 с `?pilot=1` и эту инструкцию.
2. Сложите присланные файлы в одну папку и постройте сводку:

   ```bash
   npm run pilot:report -- отчёты/ --out сводка.md
   ```

3. В сводке:
   - **Тест до и после урока** — доля верных с первой попытки в задании «До урока» (`pre.<урок>`) и в итоговой проверке (`post.<урок>`);
   - **Задания** — по каждому упражнению: сколько участников пробовали, верно с первой попытки, решили, попыток и подсказок;
   - **Выводы** — сколько участников дошли до каждого шага вывода: где обрыв, там трудный шаг;
   - **Опрос** — средняя понятность (1–5), где споткнулись, комментарии.
4. Решение «продолжаем / нет» и правки уроков — по итогам сводки (задача S2.12 плана).
