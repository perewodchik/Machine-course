# Стартовые промпты

Скопируйте один из промптов в новую сессию Claude Code, открытую в этом репозитории.

## 1. Продолжить работу (основной)

```text
Продолжи реализацию курса «Математика для ML» по плану. Запусти скилл continue-plan и выполни следующую задачу из docs/implementation/PLAN.md.
После задачи: проверки из её поля «Проверка», обнови статус, «Итог» и блок «Сейчас» в PLAN.md, добавь запись в docs/implementation/LOG.md, закоммить и запушь в ветку этапа. Затем коротко отчитайся: что сделано, как проверено, что дальше.
Читай только то, что указано в задаче и в пакете контекста. Если нужна моя помощь (доступ, решение) — отметь задачу [u] или [!] и спроси.
```

## 2. Несколько задач подряд

```text
Продолжи реализацию по плану (скилл continue-plan). Выполни задачи подряд до конца этапа 1 или пока не упрёшься в задачу, которой нужен я. После каждой задачи — проверки, отметка в PLAN.md, запись в LOG.md, коммит и пуш. В конце — сводка по всем задачам.
```

## 3. Конкретная задача

```text
Выполни задачу S2.06 из docs/implementation/PLAN.md по скиллу continue-plan (её зависимости проверь по плану). Остальное — как обычно: проверки, отметка, журнал, коммит, пуш, короткий отчёт.
```

## 4. Урок

```text
Напиши следующий неотмеченный урок из этапа, указанного в блоке «Сейчас» docs/implementation/PLAN.md. Используй скилл continue-plan, пакет context/content-authoring.md и скиллы new-lesson, new-formula, content-review. Урок готов только по «Определению готовности урока».
```

## Если скиллы не подхватились

```text
Ты агент реализации курса «Математика для ML». Прочитай docs/implementation/context/00-project.md, затем блок «Сейчас» в docs/implementation/PLAN.md и верхнюю запись docs/implementation/LOG.md. Возьми первую задачу [~] или первую [ ] с выполненными зависимостями. Прочитай только пакеты из её поля «Контекст». Сделай задачу, проверь командами из «Проверка», обнови статус и «Итог» в PLAN.md, блок «Сейчас», добавь запись в LOG.md (шаблон в начале файла), закоммить с ID задачи и запушь в ветку impl/stage-N. Не читай целиком docs/analysis.md, docs/program и docs/conventions — только разделы по ссылкам из пакетов.
```

## Перед первым запуском

- Ветка этапа создаётся от ветки, где лежит `docs/implementation/` (сейчас `docs/course-analysis`). Если вы влили её в `main`, агент возьмёт `main`.
- Открытые вопросы (`docs/analysis.md` §9) этап 1 не блокируют.
