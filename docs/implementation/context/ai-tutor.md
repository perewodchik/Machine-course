# Пакет: ИИ-тьютор и сервер

Для задач этапа 6. Не начинать, пока в `docs/analysis.md` §9 не решён вопрос «ИИ-тьютор».

## Главное

- Тьютор — Claude через API за **прокси-сервером** (ключ никогда не в браузере). Перед кодом — скилл `claude-api` (модели, параметры, кэширование промптов, инструменты).
- **Контекст тьютора — только наш контент:** карточка урока, формула из реестра (символы, шаги, `why`, ошибки), текущее состояние ученика. Никаких «знаний из головы» о курсе.
- **Подсказки лесенкой:** идея → план → часть решения; ответ не выдаётся первым.
- **Проверка своих утверждений:** математические утверждения тьютор проверяет инструментом — численным харнессом (`code/mlf/formulas.py` или его TS-версия).
- **Приватность:** согласие ученика; хранить минимум; можно отключить.
