# Пакет: педагогические компоненты и урок

Для задач S1.07, S1.09, S2.03, S2.06, S5.01 и уроков этапов 2–5.

## Главное

- **Компоненты — `.astro` без React** (`src/components/pedagogy/`), поведение — небольшие скрипты в `src/client/`:
  - `Note` (заметка на полях): обязательная подпись `label`; в режиме «поля скрыты» сворачивается в строку и раскрывается по клику или Enter;
  - `Block`: `definition` (чернила), `theorem` (чернила, двойная линейка), `intuition` (карандаш), `derivation` (карандаш, пунктир), `pitfall` (красная ручка; неверное зачёркнуто, исправление рядом, пометка учителя на полях), `exercise` (синяя ручка);
  - `Prereqs`: строка «Опирается на» — ссылки на уроки-пререквизиты; у каждого — чекбокс «знаю» (отмечен — зелёная галочка);
  - `Formula formula="f.…"`: утверждение из реестра, легенда символов **кнопками** (KaTeX прячет HTML от скринридеров, поэтому фокус — на легенде), «Опирается на», условия, вкладки «Вывод / Размерности / Где используется»;
  - `Derivation`: план из подцелей (без номеров), шаги с обоснованием-ссылкой, `\changed{}` подсвечивает изменение, режим «Сначала предсказать шаг», раскрытие правила не глубже двух уровней.
- **Подсветка символов:** атом `$activeSym` (nanostores, `src/lib/state/highlight.ts`); делегирование `pointerover`/`focusin` на `[data-sym]` и кнопки легенды `[data-sym-key]` (`src/client/symbols.ts`); класс `is-lit` у всех вхождений; Escape снимает; виджеты подписываются через `@nanostores/react`. Легенда — `src/components/pedagogy/SymbolLegend.astro`; TeX в компонентах — `renderTex(tex, { symbols })` из `src/markdown/core/katex.ts` (те же роли, что в MDX). Демо — `/demo/math/`.
- **Нумерация** внутри урока: «Формула 4», «Рисунок 1», «Упражнение 3». Номер задаёт автор: `<Formula formula="f.…" n={4} />`, `<Block kind="definition" n={2}>`.
- **Где что (S1.09):** `src/components/pedagogy/` — `Note` (`label`, `teacher`), `Block` (`kind`, `n`, `title`; заголовок вставляется в первый абзац), `Prereqs` (`lessons` — ключи уроков), `Formula` (`formula`, `n`, `start`), `Derivation` (`formula`, `start`, `predict`), `SymbolLegend`, `Tex`; карта для MDX — `lessonComponents` из `src/components/pedagogy/index.ts`, её передаёт маршрут урока. Поведение — `src/client/{tabs,derivation,symbols,scrollable}.ts`. Демо — `/demo/lesson/`, тесты — `tests/e2e/pedagogy.spec.ts`.
- **Без JS видно всё:** инлайн-скрипт в `<head>` ставит класс `.js` на `<html>`; скрытие будущих шагов вывода и неактивных вкладок — только под `.js`, поэтому нет мигания и нет потерянного текста без JS.
- **TeX в атрибутах `.astro`** — только `tex={String.raw`\theta`}`: в `tex="\theta"` Astro превращает `\t` в табуляцию (`<Tex>` падает с подсказкой). В MDX — `$…$`.
- **Правка красной ручкой в TeX:** `\struck{неверно}\;\fix{исправление}`; пометка учителя — `<Note label="Учитель" teacher>`.
- **Урок в MDX** — по скиллу `new-lesson`: frontmatter (`id`, `title`, `number`, `concepts`, `minutes`, `cs229`), 2–4 цикла, проверка в каждом цикле, без импортов (компоненты передаёт сайт).
- **Упражнения:** числовой ответ с допуском (точка и запятая на вводе, вывод — с точкой), выбор с разбором каждого варианта, матрица сеткой, порядок шагов (кнопки «выше/ниже»), «предскажи, потом проверь», формула (`kind: "formula"`, S3.03). Генератор с seed. Ответ проверяет код, не автор.
- **Формула-ответ:** `answer` — эталон в TeX, `symbols` — имена в MathJSON (`theta`, `X`, `x^(i)`), формы (`["n", "d"]`, размеры как в `code/mlf/formulas.py`), `positive` для символов под логарифмом. Ввод — MathLive (`src/client/formula-input.ts`, грузится только на таких страницах; без JS — поле TeX); разбор — `latex-syntax` Compute Engine; проверка — `src/lib/symbolic` (значение на 4 наборах случайных матриц). Ошибка формы объясняется («произведение 3 × 7 на 1 × 3…»), непонятная запись — не попытка. Эталон проверяется при сборке. Функция без скобок берёт аргументом всё произведение (`\det A \det B` = det(A det B)) — в эталонах и подсказках писать со скобками.
- **Вывод по шагам** (`kind: "steps"`, S3.04, идея A1): `start` — первая строка (дана), `goal` — выражение или решение «`\theta = …`», `symbols`, `lines` (видны три, «Добавить строку»). Вид строки — по записи: «= …» равна строке выше; «`\nabla_\theta … = …`» — градиент строки выше (конечные разности); «A = B» — уравнение, равносильное строке выше (невязки пропорциональны); «`\theta = …`» — решение (подстановка обнуляет невязку). Харнесс — `src/lib/symbolic/derivation.ts` (TS-версия `code/mlf/formulas.py`), первая неверная строка получает сообщение под полем. Цель-выражение: значение и не больше скобок, чем в цели.
- **Движок (S2.03):** `<Exercise gen="la.det2" n={3} confidence final />` или `<Exercise spec={…} id="…" />`; `<ExerciseSet items={[{ lesson, gen }]} seed={…} />` — итоговая проверка модуля. Типы задач — `src/lib/exercises/types.ts`, проверки — `check.ts`, разбор чисел — `parse.ts`, генераторы — `src/lib/exercises/generators/` (регистрируются в `index.ts`, `version` растёт при правке). Варианты параметрической задачи собираются при сборке (`variants`, по умолчанию 8): KaTeX в браузер не попадает. Тексты задач — с `$…$` (`renderInline`); у вариантов и подписей из одной формулы доступное имя — `inlineText`. Поведение — `src/client/exercise.ts`; попытки пишутся в журнал (`src/lib/state/journal.ts`); верный ответ в итоговой проверке урока (`final`) шлёт событие `exercise:final-correct` — его ловит прогресс (S2.04). Примеры всех типов — `/lab`, тесты — `src/lib/exercises/exercises.test.ts`, `tests/e2e/exercise.spec.ts`.
- **Эталон вида и поведения** — `prototype/lesson.html` и `prototype/assets/proto.css`.

## Не делать

- Девять обязательных слоёв урока (устарело): только циклы.
- Проверку в конце урока вместо проверки в каждом цикле.
- Тексты «очевидно», «легко видеть»; маркетинговый тон.
