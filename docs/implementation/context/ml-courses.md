# Пакет: курсы ML

Для задач этапов 7–9 (курсы направления ML). Вместе с ним — пакеты из поля «Контекст» задачи (уроки — `content-authoring.md`, виджеты — `widgets-games.md`, Python — `python-runtime.md`).

## Главное

- **Каталог** (`docs/program/catalog.md`, ADR 0004): восемь курсов по 20–45 часов. «Основы ML» (`ml-basics`) обязательны; после них независимы «Классические методы» (`ml-classic`), «Табличные данные» (`ml-tabular`), «Глубокое обучение» (`deep-learning`), «Без учителя» (`unsupervised`), RL (`rl`); LLM (`llm`) — после глубокого обучения; «Практикум» (`ml-project`). Математика (`foundations`) — предисловие.
- **Структура:** `content/courses/<курс>/course.yaml` (поле `requires`) и `<модуль>/module.yaml`; уроки — `<курс>/<модуль>/<slug>.mdx`. Номера уроков локальны в курсе («1.4»), ключ — `<курс>/<модуль>/<slug>` (`LessonKey` в `src/lib/content/types.ts`).
- **Программа курса:** `docs/program/<курс>/README.md` — уроки (идея, главный интерактив, Python), игры, проект, выходные критерии. Полные карточки — `docs/program/<курс>/0N-<модуль>.md`; сейчас они есть только у «Основ ML». Для остальных курсов карточки пишет первая задача этапа курса — по шаблону из каталога («Карточка урока ML»).
- **«Опирается на» между курсами:** «математика — II.3; основы ML — 1.4» в карточке; на сайте — чекбоксы «знаю» с названием курса; отметка общая для всех курсов.
- **Урок ML** — как урок математики (циклы, проверки) плюс три правила: алгоритм дважды (с нуля на NumPy, потом библиотека и сравнение); эксперимент с предсказанием до запуска; проект в конце курса.
- **Нотация:** `docs/conventions/notation.md`, раздел «Курсы ML» и конфликты символов ($\gamma$, $\alpha$, $\sigma$, $k$, $K$/$Q$/$V$, $A$, $\pi$).
- **Код:** в уроке — Pyodide (NumPy, scikit-learn; до 10⁴ объектов, до 10 секунд обучения); PyTorch и LLM — только Colab. Числа, которые урок показывает, закреплены тестом в `code/tests/` (правило 7 `CLAUDE.md`); данные виджетов генерирует сниппет урока с seed (`code/snippets/<курс>/…`), экспорт для виджета — `scripts/export_widget_data.py`; тест сверяет экспорт с генератором (образец — `code/tests/test_threshold.py`).
- **Версии библиотек:** API scikit-learn в Pyodide и в Colab сверять с их версиями (например, как отключить регуляризацию в `LogisticRegression`); записывать в карточку урока.
- **Данные:** таблица в каталоге. Набор публикуем только после проверки лицензии (ADR); пометки «[проверить лицензию]» снимает задача этапа.
- **Проекты:** этапы с автопроверкой в Colab — скрытые тесты функций (`mlf.check`) и пороги метрики на закрытой выборке; пороги «[уточнить по бейзлайну]» задаёт задача проекта, прогнав бейзлайн; отчёт по шаблону; рубрика «зачтено / хорошо / отлично».

## Источники (только если нужно)

## Не делать

- Повторять в курсе ML то, что есть в «Основах» или в математике: ссылаться через «Опирается на».
- Копировать текст и задачи CS229 и других курсов; ссылаться на разделы конспекта по названию.
- Публиковать наборы данных и предобученные модели без подтверждённой лицензии.
- Тяжёлое обучение в браузере.
