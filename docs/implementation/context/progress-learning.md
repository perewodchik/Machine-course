# Пакет: прогресс и аналитика

Для задач S2.03, S2.04, S2.10, S3.01, S3.02, S4.01, S5.02, S6.04.

## Главное

- **Прогресс — одна булева галочка «знаю» на урок** (решение заказчика 14.10.2026): `LessonMark` / `LessonMarks` из `src/lib/content/types.ts`. Статуса «начат», уровней усвоения, интервальных повторений и поиска нет.
- **Ставит и снимает ученик:** чекбокс в оглавлении слева (левая колонка, перед номером), на главной, в «Опирается на», «Знаю эту тему» под заголовком урока. Все чекбоксы одного урока синхронны.
- **Курс ставит сам** (`by: "lesson-check"`), когда верно решена итоговая проверка урока, и в диагностике 0.2 (`by: "diagnostic"`). Снять можно всегда.
- **Вид:** пустая клетка — карандашом (`--control-border`), отметка — зелёная галочка (`--green-pen`); цель нажатия 24 px. Модуль, где отмечены все обязательные уроки, — галочка вместо счётчика `n/m`; уроки `optional` (★) в счётчики не входят; шапка — «Знаю 47 из 59 уроков». Эталон — `prototype/lesson.html` (`initKnow` в `prototype/assets/proto.js`), раздел витрины «Галочка „знаю“».
- **Итоговая проверка модуля** показывает расхождения мягко: «отмечено „знаю“, но задачи по уроку неверны — открыть урок?»; галочку не снимает.
- **Дополнительная практика** — по желанию: кнопка «Ещё задача» генерирует новую параметрическую задачу.
- **Хранилище:** nanostores + localStorage; `schemaVersion` и миграции; `navigator.storage.persist()`; экспорт и импорт прогресса файлом (Safari стирает localStorage через 7 дней без визитов). Переименования уроков применяются из `content/redirects.yaml`.
- **Журнал событий** (без бэкенда): `{lesson, item, seed, attempt, correct, hints, ms, confidence?, generatorVersion}` и смены галочки `{lesson, known, by}` (`confidence` — необязательная отметка уверенности перед ответом, идея B6; из неё S4.01 строит график калибровки); кнопка «Отправить отчёт» (файл); микроопрос в конце урока «понятно 1–5, где споткнулись».

## Источники (только если нужно)

- `docs/conventions/pedagogy.md` — разделы «Прогресс: галочка „знаю“» и «Учебная аналитика».

## Не делать

- Очереди повторений, уровни усвоения, статус «начат», поиск — сняты решением заказчика.
- Отправку данных на сервер без согласия (сервера пока нет).
- Очки, серии дней, бейджи.
