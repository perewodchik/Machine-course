# Пакет: прогресс и аналитика

Для задач S2.03, S2.04, S2.10, S3.01, S3.02, S4.01, S5.02, S6.04.

## Главное

- **Прогресс — по урокам** (решение заказчика 14.10.2026): статусы `LessonStatus` из `src/lib/content/types.ts` — не начат, начат, **пройден**. Уровней усвоения и интервальных повторений нет; поиска по сайту нет.
- **Урок пройден**, когда верно решены (с любой попытки) все проверки урока и его итоговые упражнения. Подсказки не мешают.
- **Зелёная галочка** (`--green-pen`) у пройденного урока — в оглавлении слева (левая колонка, перед номером), на главной, в строке «Опирается на»; модуль, где пройдены все уроки, — галочка вместо счётчика `n/m`. Начатый урок — полукруг карандашом. У разделов текущего урока — галочка, когда решена проверка цикла. Эталон — `prototype/lesson.html`, раздел дизайн-системы «Пройденные уроки».
- **Тест-аут** (диагностика в уроке 0.2): верно решил итоговые задания урока — урок отмечается пройденным.
- **Дополнительная практика** — по желанию: кнопка «Ещё задача» генерирует новую параметрическую задачу; на статус не влияет.
- **Хранилище:** nanostores + localStorage; `schemaVersion` и миграции; `navigator.storage.persist()`; экспорт и импорт прогресса файлом (Safari стирает localStorage через 7 дней без визитов). Переименования уроков применяются из `content/redirects.yaml`.
- **Журнал событий** (без бэкенда): `{lesson, item, seed, attempt, correct, hints, ms, confidence?, generatorVersion}` (`confidence` — необязательная отметка уверенности перед ответом, идея B6; из неё S4.01 строит график калибровки); кнопка «Отправить отчёт» (файл); микроопрос в конце урока «понятно 1–5, где споткнулись».

## Источники (только если нужно)

## Не делать

- Очереди повторений, уровни усвоения, поиск — сняты решением заказчика.
- Отправку данных на сервер без согласия (сервера пока нет).
- Очки, серии дней, бейджи.
