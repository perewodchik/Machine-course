# Пакет: прогресс, повторения, аналитика

Для задач S2.04, S2.05, S2.11, S3.01, S3.02.

## Главное

- **Прогресс — по понятиям** (`ConceptId`), не по страницам. Уровни (`Mastery` в `src/lib/content/types.ts`):
  - знаком — ≥ 2 верных ответа на узнавание или тест-аут;
  - умею — ≥ 3 верных с первой попытки на разных seed, в ≥ 2 типах заданий, без подсказок;
  - устойчиво — верно в отложенном повторении (≥ 3 дня) или перемешанном наборе;
  - пора повторить — наступил срок; ошибка понижает уровень на один.
- **Неявное повторение:** задача на понятие частично засчитывается его пререквизитам по графу.
- **Подсказки** уменьшают зачёт; игры не поднимают выше «знаком»; тест-аут даёт только «знаком» и ставит раннее повторение (≥ 3 вопроса на понятие).
- **Повторение на сегодня:** 5–10 минут, задачи из параметрических банков; интервалы растут после верных ответов (алгоритм вроде FSRS).
- **Хранилище:** nanostores + localStorage; `schemaVersion` и миграции; `navigator.storage.persist()`; экспорт и импорт прогресса файлом (Safari стирает localStorage через 7 дней без визитов).
- **Журнал событий** (без бэкенда): `{concept, item, seed, attempt, correct, hints, ms, confidence, generatorVersion}`; кнопка «Отправить отчёт» (файл); микроопрос в конце урока «понятно 1–5, где споткнулись».
- **Диагностика (урок 0.2):** адаптивная по графу, ≤ 25 минут.

## Источники (только если нужно)

- `docs/conventions/pedagogy.md` — разделы «Уровни усвоения», «Повторение», «Учебная аналитика».
- `content/redirects.yaml` — переименования ID, их применяет миграция прогресса.

## Не делать

- Отправку данных на сервер без согласия (сервера пока нет).
- Очки, серии дней, бейджи.
