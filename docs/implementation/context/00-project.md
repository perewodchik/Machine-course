# Проект на одной странице

Читать **каждый раз** в начале работы. Остальные пакеты — только те, что указаны в задаче.

## Что строим

Интерактивные курсы на русском на одной платформе (ADR 0004, `docs/program/catalog.md`):

- **«Математика для машинного обучения»** — предисловие: линейная алгебра, анализ, вероятность, статистика и мост к Stanford CS229; 6 модулей, 54 урока, ≈ 115 часов. Строится первой (этапы 1–5).
- **Направление ML — восемь курсов** по 20–45 часов: «Основы ML» (этап 7), затем «Табличные данные», «Глубокое обучение», «Практикум» (этап 8), затем LLM, «Без учителя», RL, «Классические методы» (этап 9). У каждого курса — проект.

Персона — **рефрешер**: разработчик или аналитик, который когда-то учил вузовскую математику и хочет понимать и применять ML на уровне CS229; 4–8 часов в неделю.

## Главные идеи (не нарушать)

1. **Формулы — данные.** Формулы и выводы лежат в `content/formulas/*.yaml`; каждый шаг вывода проверяется численно (`code/mlf/formulas.py`, `cd code && pytest`). Ошибка в выводе роняет тесты.
2. **Урок = 2–4 цикла по 7–12 минут:** попытка → исследование → название → вывод → проверка. Не больше 5 минут чтения без вопроса.
3. **Прогресс — булева галочка «знаю» на урок:** ставит и снимает ученик (чекбокс в оглавлении слева и в уроке), курс ставит её сам после итоговой проверки урока. Интервальных повторений, уровней усвоения и поиска нет (решение заказчика).
4. **Дизайн «Тетрадь в клетку»:** только токены `src/design-system/tokens/tokens.css`. Ручки (синяя — действие ученика, красная — ошибка, зелёная — «верно») никогда не красят символы. Символы: бирюза — данные, оранжевый — параметры, пурпур — ответы, карандаш — вспомогательное.
5. **Нотация CS229:** $n$ объектов, $d$ признаков, $x^{(i)}$, $\theta$, векторы-столбцы, градиент той же формы, что аргумент, **десятичная точка**.
6. **Ничего не копировать** из материалов Stanford и других курсов: свой текст и рисунки.
7. **Числа в уроке закреплены тестом** (`code/tests/`).

## Где что лежит

| Путь | Что |
|---|---|
| `docs/implementation/PLAN.md` | План, статусы задач, блок «Сейчас» |
| `docs/implementation/LOG.md` | Журнал: что сделано, где остановились (новые записи сверху) |
| `docs/implementation/context/` | Пакеты контекста по областям |
| `docs/program/<модуль>.md` | Карточки уроков математики (искать Grep'ом по номеру, например `### II.3`) |
| `docs/program/catalog.md`, `docs/program/<курс>/` | Каталог курсов ML; программа и карточки каждого курса |
| `docs/conventions/` | Полные соглашения (читать только раздел, на который ссылается пакет) |
| `src/design-system/` | Токены и правила внешнего вида |
| `prototype/` | Эталон внешнего вида и поведения (HTML + CSS + JS) |
| `content/` | Курс, модули, понятия, формулы (YAML) |
| `code/` | Python: `mlf`, сниппеты, тесты |
| `notebooks/` | Лабораторные (Jupytext → ipynb) |
