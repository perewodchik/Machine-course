# Проект на одной странице

Читать **каждый раз** в начале работы. Остальные пакеты — только те, что указаны в задаче.

## Что строим

Интерактивный курс на русском «Математика для машинного обучения»: линейная алгебра, анализ, вероятность, статистика и мост к Stanford CS229. 6 модулей, 61 урок, ≈ 130 часов. Персона — **рефрешер**: разработчик или аналитик, который когда-то учил вузовскую математику и хочет пройти CS229; 4–6 часов в неделю.

## Главные идеи (не нарушать)

1. **Формулы — данные.** Формулы и выводы лежат в `content/formulas/*.yaml`; каждый шаг вывода проверяется численно (`code/mlf/formulas.py`, `cd code && pytest`). Ошибка в выводе роняет тесты.
2. **Урок = 2–4 цикла по 7–12 минут:** попытка → исследование → название → вывод → проверка. Не больше 5 минут чтения без вопроса.
3. **Прогресс — по урокам:** пройденный урок отмечается зелёной галочкой в оглавлении слева. Интервальных повторений, уровней усвоения и поиска нет (решение заказчика).
4. **Дизайн «Тетрадь в клетку»:** только токены `src/design-system/tokens/tokens.css`. Ручки (синяя — действие ученика, красная — ошибка, зелёная — «верно») никогда не красят символы. Символы: бирюза — данные, оранжевый — параметры, пурпур — ответы, карандаш — вспомогательное.
5. **Нотация CS229:** $n$ объектов, $d$ признаков, $x^{(i)}$, $\theta$, векторы-столбцы, градиент той же формы, что аргумент, **десятичная точка**.
6. **Ничего не копировать** из материалов Stanford и других курсов: свой текст и рисунки.
7. **Числа в уроке закреплены тестом** (`code/tests/`).

## Где что лежит

| Путь | Что |

| `docs/implementation/LOG.md` | Журнал: что сделано, где остановились (новые записи сверху) |
| `docs/implementation/context/` | Пакеты контекста по областям |
| `docs/program/<модуль>.md` | Карточки уроков (искать Grep'ом по номеру, например `### II.3`) |

| `prototype/` | Эталон внешнего вида и поведения (HTML + CSS + JS) |
| `content/` | Курс, модули, понятия, формулы (YAML) |
