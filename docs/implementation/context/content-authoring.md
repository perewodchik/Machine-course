# Пакет: написание урока

Для задач-уроков `L-*` этапов 2–5.

## Порядок

1. Найди карточку урока: Grep `### <номер>.` в `docs/program/` (например `### III.11.`) и прочитай **только её**: цели, понятия, формулы, ошибки, практика.
2. Проверь граф: понятия урока есть в `content/concepts/`, пререквизиты существуют. Нет — добавь (скилл `new-formula` для формул, запись в `content/concepts/*.yaml` для понятий).
3. Напиши урок по скиллу `new-lesson`: 2–4 цикла по 7–12 минут; в каждом — попытка или предсказание, исследование, название, вывод, проверка.
4. Формулы с выводом — через реестр и скилл `new-formula`; `cd code && pytest`.
5. Код — сниппет в `code/snippets`, числа в тексте — тест в `code/tests`.
6. Виджет или игра из карточки — по пакету `widgets-games.md`; если их ещё нет — сначала задача на виджет.
7. Проверь скиллом `content-review`; сними скриншоты урока (1440 и 390 px).

## Определение готовности урока

- [ ] Все цели карточки проверяются заданиями.
- [ ] 2–4 цикла, проверка в каждом; не больше 5 минут чтения без вопроса.
- [ ] Формулы с выводом — в реестре, `pytest` зелёный.
- [ ] Упражнения параметрические (seed), неверные варианты — типичные ошибки с разбором.
- [ ] Заметки: английский термин при первом появлении (и в `content/glossary.yaml`), раздел CS229 (издание + название).
- [ ] Нотация CS229, десятичная точка, русская типографика.
- [ ] Числа в тексте закреплены тестом.
- [ ] `npm run validate`, `npm run build`, скриншоты без горизонтальной прокрутки.
- [ ] `content-review` без критичных замечаний.

## Источники (только если нужно)

- `docs/program/interactives.md` — какие виджеты, игры и лабораторные у каждого урока; читать только раздел своего модуля.
- `docs/conventions/authoring.md`, `docs/conventions/notation.md`, `docs/conventions/sources.md` (иерархия источников).
