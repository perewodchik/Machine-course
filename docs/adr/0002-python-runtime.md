# 0002. Где выполняется Python

- Статус: принято (уточнено 2026-10-14: аудитория из РФ не нужна)
- Дата: 2026-10-14

## Контекст

CS229 требует Python и NumPy. Ученик должен запускать код без установки. Аудитория из РФ не нужна (решение заказчика), поэтому ограничения Google-аккаунтов не важны. Pyodide 314 (Python 3.14, NumPy 2.4) поставляется как ES-модуль, ядро — около 6.5 MB.

## Решение

1. **В уроке — Pyodide в Web Worker.** Создаётся по кнопке «Запустить»; ядро и пакеты со своего домена с постоянным кэшем; заголовки COOP/COEP дают `SharedArrayBuffer` для прерывания. Графики рисует курс.
2. **Лабораторные — Jupytext-исходники** (`notebooks/src`), из которых собираются ученические `.ipynb` и версии с решениями для CI (`pytest --nbmake`). Основная кнопка — «Открыть в Colab» (по ссылке на тег релиза публичного репозитория), рядом — JupyterLite без аккаунта.
3. **Единый источник кода** — `code/snippets` с регионами; числа в уроках закреплены тестами.

## Последствия

- CI проверяет код на CPython и в Pyodide; раз в неделю — на свежих версиях пакетов (обновления Colab).
- Для Colab нужен публичный репозиторий с ноутбуками (или его публичное зеркало, которое собирает CI).

## Отвергнутые варианты

- Colab для коротких ячеек в уроке: переход в другую вкладку ломает поток урока; для лабораторных — основной.
- Binder: урезанные мощности, холодный старт — минуты.
- Thebe: не развивается.
- marimo: сильный вариант (реактивные ноутбуки, WASM), но третий формат интерфейса; вернуться после MVP.
