# 0003. Хостинг

- Статус: принято
- Дата: 2026-10-14

## Контекст

Сайт статический. Pyodide нужен `SharedArrayBuffer` для прерывания выполнения, а значит — заголовки `Cross-Origin-Opener-Policy: same-origin` и `Cross-Origin-Embedder-Policy: require-corp`. Нужны превью на каждый pull request. Аудитория из РФ не нужна (решение заказчика), поэтому ограничения Cloudflare в РФ не учитываем.

## Решение

Cloudflare Pages: сборка из GitHub, превью для каждой ветки, файл `_headers` с COOP/COEP и долгим кэшем для `/py/*` (Pyodide) и шрифтов.

## Последствия

- Встраивать сторонние iframe и ресурсы без CORP нельзя из-за COEP; ссылки на Colab — обычные ссылки, они не затронуты.
- Домен и переменные окружения настраиваются в Cloudflare; секретов в репозитории нет.

## Отвергнутые варианты

- GitHub Pages: нельзя задать заголовки COOP/COEP.
- Vercel, Netlify: тоже подходят; Cloudflare выбран за бесплатный лимит трафика и `_headers` без конфигурации сборки.
