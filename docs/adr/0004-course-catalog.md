# 0004. Каталог курсов вместо одного курса

- Статус: принято
- Дата: 2026-10-14

## Контекст

Заказчик: курс математики — это предисловие, машинное обучение должно быть отдельным и качественным: с интерактивами, пояснениями и проектами. Один курс ML в объёме CS229 с практикой — около 200–270 часов и 60 уроков: такой курс редко доходят до конца, а его части нужны разным людям (табличные данные — аналитику, LLM — разработчику). Модуль V курса математики (девять моделей CS229) дублировал бы курс ML.

## Решение

1. **Направление ML — восемь курсов** по 20–45 часов (`docs/program/catalog.md`): «Основы ML» (обязательная база), затем независимые «Классические методы», «Табличные данные», «Глубокое обучение», «Без учителя», «Обучение с подкреплением»; «LLM» — после глубокого обучения; «Практикум» — свой проект. У каждого курса — свой проект P1–P9.
2. **Курс математики — предисловие.** Модуль V сокращён до двух уроков: V.1 «Линейная регрессия тремя способами» и V.2 «Итоговая проверка: математика в выводах ML». Модели CS229 переехали в курсы ML; старые адреса — в `content/redirects.yaml`.
3. **Модель данных — несколько курсов.** `content/courses/<курс>/course.yaml` и `<модуль>/module.yaml`; поле `requires` у курса. Ключ урока — `<курс>/<модуль>/<slug>`: в прогрессе, в «Опирается на», в редиректах.
4. **Сайт:** главная — каталог курсов и маршруты; страница курса `/<курс>`; урок `/<курс>/<модуль>/<slug>`. В шапке — текущий курс и прогресс по нему («Знаю N из M уроков»), переключение курсов — через каталог. Галочка «знаю» общая: урок математики, отмеченный в курсе ML, отмечен и в курсе математики.
5. **Порядок разработки:** математика (этапы 1–5) → «Основы ML» (этап 7) → «Табличные данные», «Глубокое обучение», «Практикум» (этап 8) → остальные (этап 9). Полные карточки уроков сейчас есть только у «Основ ML»; у остальных курсов — программа, карточки пишутся первой задачей этапа.

## Последствия

- Маршруты и коллекции с уровнем курса закладываются на этапе 1 (S1.05, S1.06), чтобы потом не переделывать.
- Номера уроков локальны в курсе («1.4»); в ссылках между курсами указывается курс: «математика — II.3; основы ML — 1.4».
- Наборы данных курсов ML публикуются только после проверки лицензии (ADR при реализации курса).
- Тяжёлый код (PyTorch, LLM) — в Colab; в браузере — NumPy и scikit-learn (Pyodide).

## Отвергнутые варианты

- **Один курс ML на 9 модулей:** слишком длинный, разным ученикам нужны разные части.
- **Оставить модели CS229 в модуле V математики:** дублирование и путаница, где их изучать.
- **Мелкие курсы по одной главе CS229 (15+ курсов):** слишком дробно; общая база повторялась бы в каждом.
