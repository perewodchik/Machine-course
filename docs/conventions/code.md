# Код сайта

## Слои

Структура и правила зависимостей — в [`src/README.md`](../../src/README.md). Главное:

- React — только в островах (виджеты, игры, Python). Урок без виджетов отдаёт 0 KB React.
- Сборочный код (`lib/content`, `lib/katex`, `markdown/`) не импортируется в браузерный.
- Виджеты не импортируют друг друга; игры берут из виджетов только модели.

## Имена

- Файлы и каталоги — `kebab-case`; React-компоненты — `PascalCase.tsx`; модели — `model.ts`.
- ID контента — `раздел.понятие` (`la.rank`), правила — `rule.*`, формулы — `f.*`, игры и виджеты — `раздел.имя`.
- Идентификаторы в коде — английские; комментарии, тексты интерфейса и сообщения об ошибках — русские.

## Версии (сверено 14.10.2026)

Astro 7.3 (Node ≥ 22.12, Zod 4, Vite 8), React 19, Tailwind CSS 4.3, Base UI 1.9, KaTeX 0.19 (не ниже 0.16.21 из-за CVE-2025-23207), Pyodide 314. Обновление мажорной версии — через ADR в `docs/adr/`.

## Тесты

| Что | Чем |
|---|---|
| Математика (`lib/math`, модели виджетов и игр) | Vitest, эталоны из NumPy |
| Формулы и выводы | pytest (`code/`) |
| Детерминизм и решаемость игр | fast-check |
| Страницы и виджеты | Playwright: скриншоты `/lab` в обеих темах, прохождение с клавиатуры |
| Доступность | axe-core на каждой странице |
| Контент | валидатор: граф без циклов, ID существуют, KaTeX компилируется, `\sym` у всех символов с ролями |
| Стиль | stylelint (токены, без градиентов и теней), `eslint-plugin-better-tailwindcss`, `eslint-plugin-boundaries` |

## Ветки и коммиты

- В `main` — только через pull request; CI зелёный.
- Сообщение коммита — по-английски, в повелительном наклонении, первая строка до 72 знаков.
- Сгенерированное (`notebooks/*.ipynb`, сборка сайта) в ревью не правится руками.
