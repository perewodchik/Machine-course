# Обозначения

Оба курса — «Математика для ML» и «Машинное обучение» — готовят к чтению CS229, поэтому основная нотация — как в его конспекте. Где русская традиция другая, на полях стоит пометка-«переводчик». Сводная таблица — в уроке 0.9.

## Основное

| Объект | Пишем | Комментарий |
|---|---|---|
| Число объектов / признаков | $n$ / $d$ | В старых конспектах Ng — $m$ / $n$; у Воронцова — $\ell$ / $n$ |
| Объект, признак | $x^{(i)}$, $x_j$, $x^{(i)}_j$ | Верхний индекс в скобках — номер объекта, не степень |
| Матрица признаков | $X \in \mathbb{R}^{n \times d}$, строки — объекты | $d$ уже включает свободный член, если добавлен столбец единиц: $x_0 = 1$ |
| Ответы | $y \in \mathbb{R}^{n}$, $y^{(i)}$ | Метки $\{0, 1\}$ в логистической регрессии, $\{-1, 1\}$ в SVM — разбирать эквивалентность явно |
| Параметры, модель, потери | $\theta$, $h_\theta(x)$, $J(\theta)$, $\ell(\theta)$ | $w, b$ — только в SVM и нейросетях, как в CS229 |
| Векторы | столбцы; $x^\top y$; $\langle x, y\rangle$ в ядрах | Координаты в тексте — $(2, 1)$ через запятую |
| Градиент | $\nabla_\theta J$ той же формы, что $\theta$; $\nabla_A f$ — формы $A$ | **Не как в MML**, где градиент — строка |
| Якобиан | $J_f \in \mathbb{R}^{m \times n}$ для $f: \mathbb{R}^n \to \mathbb{R}^m$ | Правило цепочки: $\nabla_x (g \circ f) = J_f^\top \nabla g$ |
| Гессиан | $H$, $\nabla^2 f$ | — |
| Определитель, след | $\det A$, $\operatorname{tr} A$ | CS229 пишет $\lvert\Sigma\rvert$ — предупредить, что это определитель, не модуль; не $\operatorname{Sp}$ |
| PSD / PD | $A \succeq 0$ / $A \succ 0$, только для симметричных $A$ | Оба термина: «положительно полуопределённая (неотрицательно определённая)» |
| Вероятность | $p(\cdot)$ и для PMF, и для PDF; $P(A)$ для событий | Разница $p(y \mid x; \theta)$ (параметр) и $p(y \mid x, \theta)$ (случайная величина) — разбирается явно |
| Матожидание, дисперсия | $\mathbb{E}$, $\operatorname{Var}$, $\operatorname{Cov}$ | Не $\mathsf{M}\xi$, $\mathsf{D}\xi$ — их упомянуть на полях |
| Нормальное | $\mathcal{N}(\mu, \sigma^2)$, второй параметр — дисперсия | Типичная ошибка: в NumPy `scale` — это $\sigma$ |
| Индикатор | $1\{\cdot\}$ | Скобка Айверсона $[\cdot]$ — на полях |
| Логарифм | $\log = \ln$ | Энтропия в натах |
| Числа | десятичная точка: $0.5$ | Как в коде и CS229. Typograf не трогает числа внутри формул |

## Конфликты символов

| Символ | Значения | Как разводим |
|---|---|---|
| $\Sigma$ | ковариация; знак суммы; диагональ SVD | В SVD пишем $A = USV^\top$ |
| $\sigma$ | стандартное отклонение; сигмоида | Сигмоида — $g(z)$, как в CS229, или $\operatorname{sigmoid}$ |
| $\lambda$ | собственное значение; коэффициент регуляризации | В уроках про регуляризацию собственные значения — $\lambda_i(A)$ с аргументом |
| $\ell$ | логарифм правдоподобия; номер слоя | Номер слоя — $[\ell]$ в квадратных скобках |
| $J$ | функция потерь; якобиан | Якобиан — $J_f$ с индексом |
| $\eta$ | шаг градиентного спуска (математика II.6); натуральный параметр экспоненциального семейства (IV.5, GLM) | В курсах ML шаг — $\alpha$, как в CS229, а $\eta$ — только натуральный параметр; на полях урока «Основ ML» 1.2 — пометка-«переводчик» |

## Курсы ML

Нотация — как в конспекте CS229; основное выше действует и здесь. Курсы — `docs/program/catalog.md`.

| Тема | Пишем | Комментарий |
|---|---|---|
| Классы | $k$ классов, $y \in \{1, \dots, k\}$; логиты $t = (\theta_1^\top x, \dots, \theta_k^\top x)$; $\operatorname{softmax}(t)_i = \dfrac{\exp t_i}{\sum_j \exp t_j}$ | Двоичный случай: $y \in \{0, 1\}$, в SVM — $\{-1, 1\}$ |
| Шаг обучения | $\alpha$ | Без индекса. С индексом $\alpha_i$ — двойственные переменные SVM |
| Потери | $J^{(i)}(\theta)$ на объекте, $J(\theta) = \tfrac{1}{n} \sum_i J^{(i)}(\theta)$; мини-батч $B$ | С регуляризацией: $J_\lambda(\theta) = J(\theta) + \lambda R(\theta)$ |
| Ядра | признаковое отображение $\phi(x)$; ядро $K(x, z) = \langle \phi(x), \phi(z) \rangle$, матрица Грама $K_{ij} = K(x^{(i)}, x^{(j)})$ | Ядро всегда с аргументами |
| SVM | $w, b$; функциональный зазор $\hat\gamma^{(i)}$, геометрический $\gamma^{(i)}$; штрафы $\xi_i$, параметр $C$ | — |
| Нейросети | слои $\ell = 1, \dots, r$; $z^{[\ell]} = W^{[\ell]} a^{[\ell-1]} + b^{[\ell]}$, $a^{[\ell]} = \sigma(z^{[\ell]})$, $a^{[0]} = x$ | $\sigma$ здесь — функция активации (ReLU и др.), как в CS229 |
| Обучение без учителя | кластеры $c^{(i)} \in \{1, \dots, k\}$, центры $\mu_j$; скрытые $z^{(i)}$, веса смеси $\phi_j$, ответственности $w^{(i)}_j$; распределения $Q_i$ в EM | ELBO — «нижняя оценка правдоподобия», термин даём на полях |
| PCA, ICA | компоненты $u_1, \dots, u_k$; источники $s$, смешивающая матрица $A$, разделяющая $W = A^{-1}$ | — |
| Последовательности | токены $x_1, \dots, x_T$, словарь $V$; внимание $\operatorname{softmax}\!\big(QK^\top / \sqrt{d_k}\big) V$ | — |
| RL | состояния $S$, действия $A$, переходы $P_{sa}$, дисконт $\gamma$, награда $R(s)$, стратегия $\pi$, ценность $V^\pi(s)$, $V^*(s)$, $Q^\pi(s, a)$ | — |

**Конфликты в курсах ML** (разводим так, на полях — пометка):

| Символ | Значения | Как разводим |
|---|---|---|
| $\gamma$ | геометрический зазор SVM; дисконт в RL | Зазор — в «Классических методах»; дисконт — в «Обучении с подкреплением» и уроке ★ о выравнивании в LLM |
| $\alpha$ | шаг обучения; двойственные переменные | Шаг — без индекса; двойственные — $\alpha_i$ |
| $\sigma$ | стандартное отклонение; сигмоида; функция активации | Сигмоида — $g(z)$; активация — $\sigma$ в «Глубоком обучении» и LLM; в остальных курсах $\sigma$ — стандартное отклонение |
| $k$ | число классов; кластеров; компонент PCA | Значение объявляется в начале урока и не меняется внутри урока |
| $K$, $Q$, $V$ | ядро; ключи, запросы и значения внимания; функция ценности и словарь | Ядро — с аргументами $K(x, z)$; внимание — матрицы $Q, K, V$ только в LLM; ценность — $V^\pi(s)$, $Q^\pi(s, a)$ с аргументами |
| $\phi$ | доля положительного класса $p(y = 1)$ (как в GDA); признаковое отображение; веса смеси | Без аргумента — доля класса; $\phi(x)$ — признаковое отображение; $\phi_j$ с индексом — веса смеси |
| $A$ | матрица; множество действий; смешивающая матрица ICA | Действия — только в RL, элемент $a \in A$ |
| $\pi$ | число $\pi$; стратегия | Стратегия — только в RL, всегда как функция $\pi(s)$ или $\pi(a \mid s)$ |

## Цвета ролей

Роль символа в уроке задаёт его цвет (см. `src/design-system/README.md`): данные — бирюза, параметры — оранжевый, ответы — пурпур, вспомогательное — карандаш. Роль закреплена на весь урок.
