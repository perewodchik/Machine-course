# Формулы и выводы как данные

Формулы, у которых есть вывод или которые используются в нескольких местах, живут в реестре `content/formulas/`, а не в тексте урока. Так курс может показывать, на что опирается формула, раскрывать обоснования и проверять каждый шаг численно. Пошаговая инструкция — скилл `.claude/skills/new-formula`.

## Виды записей

| Вид | ID | Где | Что содержит |
|---|---|---|---|
| Правило | `rule.*` | `formulas/rules/` | Атомарное тождество: $(AB)^\top = B^\top A^\top$, $\nabla_x\, x^\top A x = (A + A^\top)x$. Проверка `identity` или `gradient` |
| Формула | `f.*` | `formulas/<раздел>/` | Утверждение, символы, условия, вывод (план + шаги), типичные ошибки, связи |

## Символы

Каждый символ описан в `symbols`: `name`, `tex`, `meaning`, `shape`, `role`. Из этого курс берёт:

- цвет и подсветку (`role`);
- подсказку при наведении и легенду (`meaning`, `shape`);
- случайные значения для численной проверки (`shape`, `sample`).

В TeX символ с ролью пишется `\sym{name}{tex}`. Голый `\theta` в формуле с ролями — ошибка валидации.

## Проверки

Проверки — выражения NumPy; харнесс `code/mlf/formulas.py` подставляет случайные массивы нужных форм (n = 7, d = 3 …) на трёх seed.

| Проверка | Смысл |
|---|---|
| `identity: lhs, rhs` | Тождество выполняется |
| `gradient: f, grad, wrt` | Аналитический градиент совпадает с конечными разностями |
| шаг `same: py` | Значение совпадает с предыдущим шагом `same` |
| шаг `gradient: py, wrt` | Градиент последнего `same` |
| шаг `stationary: lhs, rhs` | Равенство в найденной точке |
| шаг `solution: py, wrt` | Точка минимума: в ней градиент равен нулю |

Несогласованные размерности NumPy ловит сам: выражение не вычислится, тест упадёт.

## YAML

- Только блочный стиль. TeX — в `'…'` или `|`.
- Тексты с двоеточием и пробелом — в кавычках.
- После правки: `cd code && pytest`.
