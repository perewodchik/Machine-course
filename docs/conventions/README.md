# Соглашения

Правила для всех, кто пишет уроки, формулы, виджеты, игры и код курса, включая Claude Code (см. `CLAUDE.md`). Если правило мешает — меняйте его здесь, а не обходите молча.

| Документ | О чём |
|---|---|
| [`sources.md`](sources.md) | На что опираться: иерархия источников, как ссылаться, что нельзя копировать |
| [`notation.md`](notation.md) | Обозначения (как в CS229) и расхождения с русской традицией |
| [`pedagogy.md`](pedagogy.md) | Устройство урока: циклы, проверки, выводы, пройденные уроки, аналитика |
| [`authoring.md`](authoring.md) | Как писать: тон, типографика, блоки, нумерация, заметки, термины, MDX |
| [`formulas.md`](formulas.md) | Формулы и выводы как данные: YAML, символы, численные проверки |
| [`python.md`](python.md) | Код в уроках и лабораторных: сниппеты, среды выполнения, проверки, CI |
| [`games.md`](games.md) | Мини-игры: когда игра учит, механики, контракт, тесты |
| [`code.md`](code.md) | Код сайта: слои, имена, тесты, версии, ветки и коммиты |

Внешний вид — в [`src/design-system/README.md`](../../src/design-system/README.md).
