# Python в курсе

## Где выполняется код

| Среда | Роль | Почему |
|---|---|---|
| **Pyodide в Web Worker** (Pyodide 314: Python 3.14, NumPy 2.4) | Основная: короткие ячейки прямо в уроке | Без аккаунта и установки, в дизайне курса |
| **JupyterLite** | Лабораторная целиком в браузере | Тот же `.ipynb`, без аккаунта |
| **Google Colab** | Запасная: полный CPython, тяжёлые вычисления | Нужен Google-аккаунт; для части аудитории из РФ регистрация затруднена; версии пакетов меняются без предупреждения |
| Локально | Для тех, у кого есть Python | `pip install -e code` |

Не используем: Binder (урезанные мощности, холодный старт — минуты), Thebe (не развивается), marimo — сильный вариант, но третий формат интерфейса; вернуться к нему после MVP.

## Ячейка в уроке

- 3–10 строк, меньше 2 минут. Схема PRIMM: предскажи → запусти → исследуй → измени → напиши.
- Один воркер на страницу, создаётся по кнопке «Запустить». Ядро Pyodide (~6.5 MB) и пакеты раздаются со своего домена с постоянным кэшем.
- Без `SharedArrayBuffer` (на статическом хостинге нет заголовков COOP/COEP): кнопка «Стоп» вызывает `worker.terminate()`.
- Графики рисует курс, а не matplotlib: Python возвращает массивы, компоненты рисуют их в цветах ролей.
- Задания на код проверяются скрытыми тестами; сообщения — под типичные ошибки («y должен иметь форму (n,)»).

## Лабораторные

- Одна-две на модуль, 40–120 минут: реализовать алгоритм с нуля и сверить с `np.linalg`/`scipy`.
- Исходник — Jupytext (`notebooks/src/**/*.py`), решения между `# BEGIN SOLUTION` и `# END SOLUTION`; ученическая версия собирается скриптом.
- После задания — ячейка проверки с `mlf.check`.
- Ссылка Colab — на тег релиза; для Colab репозиторий с ноутбуками должен быть публичным.
- Только базовые `ipywidgets`.

## Единый источник кода

- Код уроков и лабораторных живёт в `code/snippets/` с регионами `# region name`. Урок вставляет регион при сборке, ноутбук — директивой `# snippet:`. Неразрешённая директива ломает сборку.
- Числа, которые урок показывает, закреплены тестом в `code/tests/`.

## CI

- `pytest code/` на CPython той же версии, что в Colab, и в Pyodide (`pyodide venv`).
- `pytest --nbmake` по версиям ноутбуков с решениями, с таймаутом.
- Раз в неделю — прогон на свежих версиях пакетов, чтобы заметить обновления Colab.
