# Как писать уроки

## Тон

- Учебник, а не реклама: спокойно, точно, на «вы» в обращении к ученику («подберите», «заметьте»).
- Никаких «очевидно», «легко видеть», «просто». Если очевидно — покажите за одну строку.
- Одно предложение — одна мысль. Абзац — до 5 предложений.
- Сначала конкретный пример, потом общее определение.
- Интерфейсные тексты — по скиллу `ux-copy`: кнопка называет действие («Показать минимум», не «ОК»).

## Типографика

- Кавычки «ёлочки», внутри — „лапки“. Тире — длинное (—) с неразрывным пробелом перед ним; дефис в составных словах; минус в формулах — через TeX.
- Неразрывный пробел после однобуквенных предлогов и союзов и между числом и единицей. На этапе 1 это делает Typograf при сборке, но в YAML пишите сразу правильно.
- Десятичная точка: 0.5, как в коде (см. `notation.md`).
- Ё — пишем.
- Формула внутри строки — короткая. Дроби, матрицы, суммы с пределами — выключными формулами. Матрица в строке — только `smallmatrix`.

## Блоки

| Блок | Когда | Заголовок |
|---|---|---|
| Определение | Новое понятие | «Определение 2.» |
| Теорема | Ключевой результат, который будет использоваться | «Теорема 1.» |
| Интуиция / «Сначала попробуйте сами» | Наглядный смысл, попытка до объяснения | «Интуиция.» |
| Вывод | Рассуждение, которое можно пропустить при повторении | «Вывод.» |
| Типичная ошибка | Конкретная ошибка: неверное зачёркнуто, исправление рядом, пометка на полях | «Типичная ошибка.» |
| Упражнение / Проверка | Действие ученика | «Упражнение 3.», «Проверка.» |

Нумерация формул, рисунков, определений и упражнений — сквозная внутри урока. Из другого урока: «формула 4 урока V.1».

## Заметки на полях

- Английский термин при первом появлении: «собственный вектор (*eigenvector*)». Термин добавляется в `content/glossary.yaml`.
- Ссылка на CS229: издание и название раздела.
- «Переводчик» обозначений, если русская традиция отличается.
- Пометка учителя (красная) — только рядом с типичной ошибкой.
- Не больше одной заметки на абзац. Заметка не должна быть нужна для понимания основного текста.

## Рисунки и виджеты

- У рисунка есть номер, подпись (что показано и что делать) и текстовая альтернатива.
- Символы на рисунке — того же цвета и начертания, что в формулах.
- Подпись прямо у линии лучше легенды.
- Интерактив — только если действие ученика что-то объясняет. Анимация ради анимации запрещена.

## MDX

- Frontmatter: `id`, `title`, `number`, `concepts`, `minutes`, `cs229`.
- Импортов в MDX нет: компоненты (`Formula`, `Derivation`, `Exercise`, виджеты) передаёт сайт.
- Формула с ролями — из реестра: `<Formula formula="f.normal-equations" />`. Разовая формула — TeX с `\sym{…}{…}` для символов с ролями.
- Код — из сниппетов: `<PyCode src="la/normal_equations.py#solve" run />`.
