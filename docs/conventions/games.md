# Мини-игры

## Когда игра учит

1. **Игровое действие — это математическая операция.** В игре «Матрица-пазл» ученик задаёт столбцы матрицы и видит, куда уходят базисные векторы. Викторина с очками за ответы — не игра.
2. **Обратная связь — математическое следствие на рисунке**, а не «неверно».
3. **Сначала предсказание, потом раскрытие.**
4. **Очки — метрика самого понятия:** точность, число ходов против оптимума, правило Брайера или логарифмическое правило для вероятностей. Не скорость.
5. **Уровни подводят к граничному случаю:** вырожденная матрица, недостижимая цель, расходящийся спуск.
6. **Разбор после уровня:** 1–2 вопроса, которые переводят стратегию в формулу.
7. **Партия 2–5 минут**, с seed, без декоративного сюжета и таймера.

## Где игры в курсе

- в начале цикла — свободное исследование без очков;
- после формализации — режим с очками;
- в конце модуля — смешанный финальный уровень.

Игры ставим прежде всего туда, где ученики бросают курс: I.5–I.7, II.3, III.10–III.11, IV.4.

## Техника

Контракт — `src/games/_engine/types.ts`, инструкция — скилл `new-game`. Коротко: чистый редьюсер, случайность только из `rng` с seed, партия = seed + журнал действий, текстовое описание состояния, управление с клавиатуры, тесты на детерминизм и решаемость уровней.
