| Область | Решение | Изменение после ревью |
|---|---|---|
| Персона | Рефрешер: «знал, но забыл», цель — CS229, 4–6 ч в неделю | **Решено** 14.10.2026 |
| Программа | Математика: 6 модулей, 54 урока, ≈ 106–128 ч. ML: 8 курсов по 20–45 ч | Было 47 уроков, 65–85 ч: добавлены интеграл, NumPy, SGD, Ньютон, Лагранж, замена переменных, смеси, экспоненциальное семейство. v0.5: модели CS229 из модуля V — в курсах ML |

### Фронтенд-архитектура

| Находка | Что сделано |
|---|---|
| Astro 7: Markdown обрабатывает Sätteri, remark-плагины — только через `unified()` | Ядро обработки (`src/markdown/`) не зависит от процессора; выбор — в ADR |
| Фокус по символам внутри KaTeX невозможен: HTML-часть под `aria-hidden` | Легенда символов кнопками (есть в прототипе) |
| KaTeX < 0.16.21 уязвим (CVE-2025-23207) | Прототип на 0.19.0; `trust` и `strict` — функции |
| Бюджет 100 KB JS не выдержать с React на каждой странице | Педагогические компоненты без React; React только в островах |
| Подсветка символов между островами | Атом nanostores + делегирование событий без фреймворка |
| YAML портит TeX в двойных кавычках | Правило «только блочный стиль, TeX в `'…'`»; ловушка воспроизведена и задокументирована |
| Проверке выводов не на чем работать | Шаги получили `check` с выражениями NumPy; харнесс и тесты написаны |
| Хостинг в РФ, Safari стирает localStorage через 7 дней | Аудитория из РФ не нужна — Cloudflare Pages; `storage.persist()`, экспорт прогресса файлом, `schemaVersion` |
| Игры — без отдельного движка | Контракт `GameSpec`: чистый редьюсер, seed, журнал действий |

### EdTech и педагогика

| Находка | Что сделано |
|---|---|
| Две персоны в одном продукте | Основная — «знал, но забыл» **[решить]** |
| Практика в конце урока | Циклы с проверкой каждые 3–5 минут |
| Нет интервальных повторений и перемешанной практики | Повторения сняты решением заказчика; осталась перемешанная итоговая проверка модуля и «Ещё задача» |
| Вывод без плана; «какое правило?» проверяет только узнавание | План из подцелей (в прототипе), предсказание шага, самообъяснение, угасание подсказок, «найди ошибку» |
| Мотивация далеко: до ML больше 50 часов | Урок-тизер 0.1, сквозной кейс «Квартиры», капстоун в каждом модуле |
| «Прочитано / подтверждено» создаёт иллюзию прогресса | Заказчик выбрал самоотметку «знаю» (для рефрешера это быстрый пропуск известного). Противовес: курс сам ставит галочку после итоговой проверки, итоговая проверка модуля мягко показывает расхождения с отметками, проверки внутри урока остаются |
| Колаб как основа рискован для РФ | Снято решением «РФ не нужна»: Colab — основная среда лабораторных, JupyterLite — без аккаунта, Pyodide — ячейки в уроке |
| Нужна учебная аналитика | Журнал событий без бэкенда, пилот на 6–10 человек с критериями «продолжаем / нет» |

### Дизайн-критика (по скиллам `design-critique` и `frontend-design`)

Вердикт: направление годное, не выглядит сгенерированным; системная ошибка — в цвете.

| Находка | Что сделано |
|---|---|
| Цвета символов сливаются с ручками ($y$ = «верно», $X$ = ссылка, $\theta$ = ошибка) | Новая палитра из 3 ролей + карандаш; расстояние до ручек ≥ 10.7 (было 1.5) |
| Блоки «определение» и «упражнение» в цветах ручек | Определение — чернила; упражнение — синяя ручка как действие ученика; интуиция — карандаш |
| Пустые блоки ответа видны (`hidden` перебит) | Исправлено |
| Карта на главной без заливки прогресса | Исправлено |
| Подписи на рисунке другим начертанием (θ как ϑ) | Подписи шрифтом KaTeX с подложкой; индексы меньшим кеглем |
| Рисунок узкий, код широкий | Наоборот; колонка обоснований выровнена по полям |
| Мобильная версия: сжатый рисунок, нет оглавления, мелкие цели касания | Рисунок пересчитывает `viewBox` по ширине; выдвижное оглавление; цели касания 44 px |
| Логотип похож на иконку «открыть во внешнем окне» | Новый знак: точки и прямая на клетке |
| Тёмная тема похожа на GitHub Dark | Графит с зеленцой — «грифельная доска» |
| Нужен один смелый жест тетради | «Типичная ошибка» как правка красной ручкой с пометкой на полях |

## 3. Дизайн-система

Подробно — [`src/design-system/README.md`](../src/design-system/README.md), скриншоты — [`docs/design/screenshots/`](design/screenshots).

- **Образ:** рабочая тетрадь в клетку. Бумага холодная белая; клетка только в рисунках (деления осей совпадают с клеткой); справа поля с красной линией для заметок, английских терминов и ссылок на CS229.
- **Ручки — интерфейс:** синяя — всё, что делает ученик; красная — ошибки и правки; зелёная — «верно» и галочка «знаю».
- **Символы — математика:** бирюза (данные), оранжевый (параметры), пурпур (ответы), карандаш (вспомогательное); один цвет у символа в формуле, на рисунке и на ползунке.
- **Шрифты:** Literata для чтения, IBM Plex Sans для интерфейса и заголовков, IBM Plex Mono для кода, KaTeX для формул и подписей на рисунках.
- **Скругление растёт с размером** (3/6/10 px), теней нет, кроме всплывающих слоёв.

## 6. Python, игры, аналитика

- **Python** ([`docs/conventions/python.md`](conventions/python.md)): ячейки в уроке на Pyodide; лабораторные — Jupytext-исходники, из которых собираются ученические ноутбуки и версии с решениями для CI; Colab — по ссылке на тег релиза из публичного репозитория.
