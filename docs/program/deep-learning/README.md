## Проект P5. «Цифры с нуля»

- **Зачем:** полный цикл обучения сети и её отладки; в портфолио — двухслойная сеть на NumPy с проверкой градиента, CNN в PyTorch и перенос обучения с сравнением.
- **Данные:** цифры 8×8 (UCI, CC BY 4.0) для сети с нуля; MNIST (CC BY-SA 3.0) для CNN.
- **Метрика:** точность на отложенной выборке; кривые обучения; время обучения.
- **Этапы:** 1) сеть на NumPy: прямой и обратный проход (автопроверка: относительная ошибка проверки градиента < $10^{-6}$); 2) обучение мини-батчами, инициализация, регуляризация (автопроверка: точность на тесте цифр 8×8 не ниже порога [уточнить по бейзлайну]); 3) CNN в PyTorch на MNIST (автопроверка: точность ≥ 98% [уточнить]); 4) анализ ошибок: матрица ошибок, худшие примеры, отчёт.
- **Ловушки:** softmax без вычитания максимума (переполнение); забытый `model.eval()`; нормализация по тесту; подбор по тесту.
- **Где и сколько:** этап 1–2 — браузер или Colab без GPU; этап 3 — Colab с GPU; 10–12 часов.

## Выходные критерии

Ученик реализует двухслойную сеть с обратным распространением на NumPy и проверяет градиенты; объясняет и применяет инициализацию, импульс, Adam, нормализацию, dropout; объясняет двойной спуск и неявную регуляризацию; переносит модель в PyTorch и пишет цикл обучения; строит CNN и ResNet-блок; применяет перенос обучения и выбирает между линейной пробой и дообучением; сдаёт P5.
