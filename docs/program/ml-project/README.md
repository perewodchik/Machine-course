## Проект P9. «Свой проект»

- **Темы-примеры:** прогноз спроса для магазина; классификация обращений в поддержку; поиск дефектов на фото деталей; рекомендации статей; детектор аномалий в логах; агент для настольной игры. Можно предложить свою.
- **Требования к данным:** открытая лицензия или своё; без персональных данных без согласия; размер посильный для Colab.
- **Этапы и проверка:**
  1. **Заявка:** задача, метрика, бейзлайн, данные, риски — проверка по чек-листу (автоматическая часть: метрика и разбиение определены, бейзлайн воспроизводится).
  2. **Промежуточный отчёт:** бейзлайн и 3–5 экспериментов в журнале, анализ ошибок.
  3. **Итоговый отчёт и защита:** результаты на отложенной выборке, абляции, ограничения, следующие шаги; защита 10 минут (видео или созвон).
- **Рубрика:** постановка и метрика; качество данных и разбиения; бейзлайн и эксперименты; анализ ошибок; честность оценки; ясность отчёта и кода — уровни «зачтено / хорошо / отлично».
- **Отзыв:** взаимная проверка двух участников по рубрике; ИИ-тьютор — после решения вопроса в `docs/analysis.md` §9.
- **Где и сколько:** Colab или локально; 20–40 часов.

## Выходные критерии

Ученик формулирует ML-задачу с метрикой и бейзлайном; ведёт журнал экспериментов и делает анализ ошибок; честно оценивает итоговую модель; пишет отчёт и README, понятные работодателю; защищает проект по рубрике.

**CS229:** «Project guidelines», лекция «ML advice».
