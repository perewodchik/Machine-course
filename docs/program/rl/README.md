## Проект P8. «Агент»

- **Зачем:** RL в миниатюре от начала до конца; в портфолио — агент для сеточного мира и CartPole с кривыми обучения и разбором неудач.
- **Данные:** наш сеточный мир; CartPole из Gymnasium (MIT).
- **Метрика:** средняя награда за эпизод по 100 эпизодам; число эпизодов до решения среды; разброс по 5 seed.
- **Этапы:** 1) сеточный мир: итерация по ценности и стратегиям (автопроверка: $V^*$ совпадает с эталоном до $10^{-6}$); 2) влияние $\gamma$ и наград (отчёт с предсказаниями до запуска); 3) Q-обучение (автопроверка: стратегия оптимальна в контрольных клетках); 4) CartPole: REINFORCE с базовой линией (автопроверка: средняя награда ≥ 195 [уточнить по бейзлайну]); 5) отчёт: кривые по 5 seed, что не сработало.
- **Ловушки:** выводы по одному seed; утечка «будущей» награды в расчёт отдачи; слишком большой шаг.
- **Где и сколько:** браузер (сеточный мир) и Colab без GPU; 8–10 часов.

## Выходные критерии

Ученик записывает уравнения Беллмана для $V^\pi$ и $V^*$ и объясняет сходимость итерации по ценности; реализует итерацию по ценности и стратегиям, Q-обучение и REINFORCE с базовой линией; оценивает модель переходов по опыту; объясняет компромисс исследования и использования; сдаёт P8.

**CS229:** «Reinforcement learning» (MDPs, value and policy iteration, learning a model, continuous state MDPs), «LQR, DDP and LQG», «Policy gradient (REINFORCE)».
