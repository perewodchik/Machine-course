# Модуль V. Мост к ML

**4–6 часов, 2 урока.** Модуль закрывает курс математики. В уроке V.1 линейная алгебра, анализ, вероятность и статистика сходятся в одной модели: формулу весов линейной регрессии выводим тремя путями. Урок V.2 — итоговая проверка: ученик восстанавливает математические шаги в выводах из машинного обучения и получает карту готовности к курсам ML.

Модели CS229 — логистическая регрессия, GLM, GDA и наивный Байес, ядра и SVM, нейросети, смещение и разброс, k-means и EM, PCA — разбираются в отдельных курсах направления ML (`docs/program/catalog.md`). Здесь — только математика, на которую они опираются.

---

### V.1. Линейная регрессия тремя способами

**Время:** 2.5 ч. **Опирается на:** I.8, II.3, II.5, IV.3. **CS229:** «Linear regression».

**Цели.** Ученик выводит $\theta^\star = (X^\top X)^{-1}X^\top y$ тремя путями:
1. проекция $y$ на пространство столбцов $X$ (I.8);
2. минимум $J(\theta)$ через градиент (II.3, II.5);
3. MLE при гауссовом шуме: максимизация правдоподобия равна минимизации суммы квадратов (IV.3).

И объясняет, почему три вывода дают одну формулу.

**Формулы:** `f.normal-equations` (реестр, вывод проверен численно); $\ell(\theta) = n \log\dfrac{1}{\sqrt{2\pi}\sigma} - \dfrac{1}{2\sigma^2}\sum_i (y^{(i)} - \theta^\top x^{(i)})^2$.

**Типичные ошибки:** $(X\theta)^\top = X^\top\theta^\top$; решать через `inv`.

**Практика:** прототип урока (`prototype/lesson.html`); лабораторная «Нормальные уравнения» (`notebooks/src/la/normal_equations.py`); игра «Подгони прямую». Дальше — «Основы ML», урок 1.2: та же модель, обученная спуском.

### V.2. Итоговая проверка: математика в выводах ML

**Время:** 1.5–3 ч. **Опирается на:** модули 0–IV, V.1. **CS229:** «Classification and logistic regression», «Generalized linear models», «Generative learning algorithms», «Deep learning» — как источник фрагментов.

**Идея урока.** Выводы в машинном обучении собраны из нескольких приёмов математики: правило цепочки, матричное дифференцирование, логарифм правдоподобия, неравенство Йенсена, собственные векторы. Если ученик узнаёт каждый приём в чужом выводе, курсы ML читаются без остановок.

**Цели.** Ученик:
- восстанавливает пропущенный шаг во фрагменте вывода и называет правило, на котором он стоит;
- находит подложенную ошибку в выводе: знак, транспонирование, потерянный множитель;
- получает карту готовности: какие уроки математики освежить перед каждым курсом ML.

**Фрагменты** (свои формулировки, не текст конспекта):

| Фрагмент | Математика | Курс ML |
|---|---|---|
| Градиент логарифма правдоподобия логистической регрессии: $\nabla_\theta \ell = X^\top (y - g(X\theta))$ | 0.5 (производная сигмоиды), II.3, IV.3 | Основы |
| Гессиан $H = -X^\top D X$ и вогнутость $\ell(\theta)$ | II.4, II.5, I.10 | Основы |
| Отклик GLM: $\mathbb{E}[T(y) \mid x] = \nabla_\eta a(\eta)$ | IV.5 | Основы |
| MLE параметров GDA: $\phi$, $\mu_0$, $\mu_1$, $\Sigma$ | IV.4, III.11 | Классические методы |
| Двойственная задача через множители Лагранжа | II.8, II.9★ | Классические методы |
| Обратный проход двухслойной сети для мини-батча | II.2, II.3, I.3 | Глубокое обучение |
| E- и M-шаги EM для смеси гауссиан через неравенство Йенсена | III.5, III.12, IV.4 | Без учителя |
| Главная компонента как собственный вектор выборочной ковариации | I.9, I.11, III.10 | Без учителя |

**Типичные ошибки:** путать подъём и спуск (знак шага); терять транспонирование при переходе от суммы к матричной записи; применять неравенство Йенсена не в ту сторону.

**Практика:**
- **Проверки:** 2–3 задания на фрагмент: «какое правило применено?», «восстанови строку», «найди ошибку».
- **Итог:** карта готовности к курсам ML — по каждому курсу уроки математики, где ответы неверны, со ссылками.

**Зачем на практике:** ученик видит свои пробелы до того, как они остановят его в середине вывода.
