### I.1. Векторы, линейные комбинации, оболочка

**Время:** 2 ч. **Опирается на:** 0.3, 0.8.

**Цели.** Ученик:
- складывает векторы и умножает их на число, геометрически и в координатах;
- определяет, лежит ли вектор в линейной оболочке данных векторов;
- проверяет линейную независимость и находит базис и размерность подпространства.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Вектор | vector | Элемент $\mathbb{R}^n$; столбец чисел |
| Линейная комбинация | linear combination | $c_1 v_1 + \dots + c_k v_k$ |
| Линейная оболочка | span | Все линейные комбинации данных векторов |
| Подпространство | subspace | Множество, замкнутое относительно сложения и умножения на число |
| Линейная независимость | linear independence | Ни один вектор не выражается через остальные |
| Базис, размерность | basis, dimension | Независимый набор, порождающий пространство; его размер |

**Формулы:** $c_1 v_1 + \dots + c_k v_k = 0 \Rightarrow c_1 = \dots = c_k = 0$ (независимость).

**Типичные ошибки:** считать, что любые $n$ векторов в $\mathbb{R}^n$ — базис; путать оболочку с самим набором векторов.

**Практика:** виджет «оболочка двух векторов» (прямая или плоскость); игра «Попади в точку»: подобрать коэффициенты при $a$ и $b$ или заявить «невозможно».

### I.2. Скалярное произведение и нормы

**Время:** 2.5 ч. **Опирается на:** I.1. **CS229:** «Kernel methods», «Regularization and model selection» (L1, L2).

**Цели.** Ученик:
- считает скалярное произведение и угол между векторами;
- доказывает и применяет неравенство Коши — Буняковского;
- сравнивает нормы $\ell_1$, $\ell_2$, $\ell_\infty$ и норму Фробениуса; проецирует вектор на вектор.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Скалярное произведение | inner (dot) product | $x^\top y = \sum_i x_i y_i$ |
| Норма | norm | Длина вектора: $\lVert x\rVert_2 = \sqrt{x^\top x}$ |
| Неравенство Коши — Буняковского | Cauchy–Schwarz inequality | $\lvert x^\top y\rvert \le \lVert x\rVert \lVert y\rVert$ |
| Угол | angle | $\cos\varphi = \dfrac{x^\top y}{\lVert x\rVert\lVert y\rVert}$ — в $\mathbb{R}^n$ это определение |
| Ортогональность | orthogonality | $x^\top y = 0$ |
| Норма Фробениуса | Frobenius norm | $\lVert A\rVert_F = \sqrt{\sum_{ij} A_{ij}^2}$ |
| Проекция на вектор | projection onto a vector | $\dfrac{a^\top b}{a^\top a}\, a$ |

**Типичные ошибки:** путать $\lVert x\rVert^2$ и $\lVert x\rVert$; считать угол в $\mathbb{R}^n$ «интуитивным» без Коши — Буняковского.

**Практика:** виджет «единичные шары норм»; виджет «проекция с подвижным углом».

### I.3. Умножение матриц: четыре взгляда

**Время:** 3 ч. **Опирается на:** I.2. **CS229:** «Linear regression», «Deep learning» (векторизация).

**Цели.** Ученик:
- вычисляет $AB$ четырьмя способами: скалярные произведения строк и столбцов, сумма внешних произведений, комбинации столбцов, комбинации строк;
- определяет, когда произведение определено и какой формы результат;
- пользуется блочным умножением и отличает адамарово произведение от матричного.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Матрица | matrix | Таблица $m \times n$; в ML — данные или отображение |
| Произведение матриц | matrix product | $(AB)_{ij} = \sum_k A_{ik} B_{kj}$ |
| Внешнее произведение | outer product | $x y^\top$ — матрица ранга 1 |
| Блочная матрица | block matrix | Матрица из подматриц; умножается «по блокам» |
| Адамарово произведение | Hadamard (elementwise) product | $(A \odot B)_{ij} = A_{ij} B_{ij}$ |

**Формулы:** $AB = \sum_k a_{:,k}\, b_{k,:}$; $Ax = \sum_j x_j a_{:,j}$.

**Типичные ошибки:** считать, что $AB = BA$; путать `*` и `@` в NumPy.

**Практика:** виджет «переключатель взглядов» на одном произведении; игра «Тетрис размерностей».

### I.4. Матрица как линейное отображение

**Время:** 2.5 ч. **Опирается на:** I.3.

**Цели.** Ученик:
- по матрице $2 \times 2$ предсказывает, как преобразуется сетка плоскости;
- по картинке «до и после» восстанавливает матрицу (столбцы — образы базисных векторов);
- объясняет, почему композиция отображений — это произведение матриц и почему порядок важен.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Линейное отображение | linear map | Сохраняет сложение и умножение на число |
| Образ базисного вектора | image of a basis vector | $Ae_j$ — $j$-й столбец $A$ |
| Композиция | composition | $(AB)x = A(Bx)$: сначала $B$, потом $A$ |
| Единичная, диагональная матрица | identity, diagonal matrix | $I$ ничего не меняет; диагональная растягивает по осям |

**Типичные ошибки:** читать $AB$ слева направо как «сначала $A$».

**Практика:** виджет «деформация сетки»; игра «Матрица-пазл» (есть в прототипе).

### I.5. Транспонирование, симметрия, след

**Время:** 2 ч. **Опирается на:** I.3. **CS229:** «Linear regression» (вывод нормальных уравнений через след).

**Цели.** Ученик:
- применяет $(AB)^\top = B^\top A^\top$ и проверяет его размерностями;
- пользуется циклической перестановкой под следом и тождеством $x^\top A x = \operatorname{tr}(A x x^\top)$;
- узнаёт симметричные матрицы и разлагает любую квадратную матрицу на симметричную и кососимметричную части.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Транспонирование | transpose | $(A^\top)_{ij} = A_{ji}$ |
| Симметричная матрица | symmetric matrix | $A = A^\top$ |
| След | trace | $\operatorname{tr} A = \sum_i A_{ii}$ |
| Циклическая перестановка | cyclic property | $\operatorname{tr}(ABC) = \operatorname{tr}(CAB) = \operatorname{tr}(BCA)$ |

**Формулы:** $(AB)^\top = B^\top A^\top$; $\operatorname{tr}(AB) = \operatorname{tr}(BA)$; $x^\top A x = x^\top \tfrac{A + A^\top}{2} x$.

**Типичные ошибки:** $(AB)^\top = A^\top B^\top$ (это правка красной ручкой в уроке V.1); переставлять под следом не циклически.

**Практика:** тренажёр тождеств с проверкой размерностями; «найди ошибку» в выводе.

### I.6. Системы уравнений и ранг

**Время:** 3 ч. **Опирается на:** I.1, I.4.

**Цели.** Ученик:
- определяет, сколько решений у $Ax = b$, по рангу $A$ и расширенной матрицы;
- находит пространство столбцов и ядро матрицы;
- применяет теорему о ранге и дефекте.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Пространство столбцов (образ) | column space, range | Все $Ax$ — оболочка столбцов |
| Ядро | null space | Все $x$, для которых $Ax = 0$ |
| Ранг | rank | Размерность пространства столбцов (= числу независимых строк) |
| Теорема о ранге | rank–nullity theorem | $\operatorname{rank} A + \dim \ker A = n$ для $A \in \mathbb{R}^{m \times n}$ |

**Типичные ошибки:** считать, что квадратная система всегда имеет единственное решение.

**Практика:** виджет «$Ax = b$: нет решений, одно, бесконечно много»; игра «Попади в точку» (уровни с недостижимой целью).

### I.7. Обратная матрица и определитель

**Время:** 2.5 ч. **Опирается на:** I.4, I.6. **CS229:** «Generative learning algorithms» (плотность гауссианы), «Independent components analysis».

**Цели.** Ученик:
- объясняет, когда матрица обратима, и находит обратную к $2 \times 2$;
- интерпретирует определитель как коэффициент изменения площади (объёма) со знаком ориентации;
- применяет $\det(AB) = \det A \det B$ и $\det A = 0 \iff$ матрица вырождена.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Обратная матрица | inverse | $A^{-1}A = AA^{-1} = I$ |
| Вырожденная матрица | singular matrix | Необратимая: $\det A = 0$, ранг меньше $n$ |
| Определитель | determinant | Объём образа единичного куба со знаком |

**Формулы:** $(AB)^{-1} = B^{-1}A^{-1}$; $\det(A^{-1}) = 1/\det A$; $\det(A^\top) = \det A$.

**Типичные ошибки:** $(AB)^{-1} = A^{-1}B^{-1}$; считать обратную через `inv` там, где нужна система.

**Практика:** виджет «квадрат → параллелограмм» с площадью со знаком; упражнение «предскажи знак определителя по картинке».

### I.8. Ортогональность и проекции

**Время:** 3 ч. **Опирается на:** I.2, I.6. **CS229:** «Linear regression» (геометрия МНК), «Support vector machines» (расстояние до гиперплоскости).

**Цели.** Ученик:
- проецирует вектор на подпространство и выводит матрицу проекции $X(X^\top X)^{-1}X^\top$;
- объясняет МНК как проекцию $y$ на пространство столбцов $X$ (остаток ортогонален столбцам);
- находит расстояние от точки до гиперплоскости $w^\top x + b = 0$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Ортонормированный базис | orthonormal basis | Попарно ортогональные векторы единичной длины |
| Ортогональная матрица | orthogonal matrix | $Q^\top Q = I$; сохраняет длины и углы |
| Проекция на подпространство | orthogonal projection | Ближайшая точка подпространства; остаток ему ортогонален |
| Гиперплоскость | hyperplane | $\{x : w^\top x + b = 0\}$ |
| ★ Процесс Грама — Шмидта, QR | Gram–Schmidt, QR decomposition | Построение ортонормированного базиса |

**Формулы:** $\hat y = X(X^\top X)^{-1}X^\top y$; $X^\top(y - \hat y) = 0$; расстояние $= \dfrac{\lvert w^\top x + b\rvert}{\lVert w\rVert}$.

**Типичные ошибки:** считать ортогональной любую матрицу с ортогональными столбцами (нужна ещё единичная длина).

**Практика:** виджет «проекция $y$ на плоскость столбцов» (3D, лениво); лабораторная к I.12.

### I.9. Собственные значения и векторы

**Время:** 3 ч. **Опирается на:** I.4, I.7. **CS229:** «Principal components analysis».

**Цели.** Ученик:
- находит собственные значения и векторы матрицы $2 \times 2$ через характеристический многочлен;
- диагонализует матрицу и объясняет смысл $A = V\Lambda V^{-1}$;
- применяет спектральную теорему для симметричных матриц: $A = Q\Lambda Q^\top$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Собственный вектор, значение | eigenvector, eigenvalue | $Av = \lambda v$, $v \ne 0$ |
| Характеристический многочлен | characteristic polynomial | $\det(A - \lambda I)$ |
| Диагонализация | diagonalization | $A = V\Lambda V^{-1}$ |
| Спектральная теорема | spectral theorem | Симметричная матрица: вещественные $\lambda$, ортонормированные собственные векторы |

**Типичные ошибки:** считать, что у любой матрицы есть вещественные собственные векторы (поворот на 90° — контрпример); забывать, что собственный вектор определён с точностью до множителя.

**Практика:** игра «Охота на собственные векторы»: вращать $v$, поймать $Av \parallel v$, оценить $\lambda$.

### I.10. Квадратичные формы и знакоопределённость

**Время:** 3 ч. **Опирается на:** I.5, I.9. **CS229:** «Kernel methods» (матрица Грама), «Generative learning algorithms» (ковариация).

**Цели.** Ученик:
- проверяет положительную (полу)определённость симметричной матрицы по собственным значениям и по определению;
- рисует линии уровня $x^\top A x = c$ и объясняет, почему это эллипсы только при $A \succ 0$;
- находит экстремумы отношения Рэлея; строит $A^{1/2}$ и объясняет матрицу Грама.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Квадратичная форма | quadratic form | $x^\top A x$, $A$ — симметричная |
| Положительно (полу)определённая | positive (semi)definite, PD/PSD | $x^\top A x > 0$ ($\ge 0$) при всех $x \ne 0$ |
| Отношение Рэлея | Rayleigh quotient | $\dfrac{x^\top A x}{x^\top x}$; максимум — $\lambda_{\max}$ |
| Матрица Грама | Gram matrix | $K = X X^\top$, $K_{ij} = x^{(i)\top} x^{(j)}$; всегда $\succeq 0$ |
| Квадратный корень матрицы | matrix square root | $A^{1/2} = Q\Lambda^{1/2}Q^\top$ для $A \succeq 0$ |
| ★ Разложение Холецкого | Cholesky decomposition | $A = LL^\top$ для $A \succ 0$ |

**Формулы:** $\lambda_{\min} \le \dfrac{x^\top A x}{x^\top x} \le \lambda_{\max}$; полуоси эллипса $x^\top A x = 1$ равны $1/\sqrt{\lambda_i}$.

**Типичные ошибки:** определять PSD для несимметричных матриц (контрпример: $\begin{psmallmatrix}1 & 2\\ -2 & 1\end{psmallmatrix}$ даёт $x^\top A x = \lVert x\rVert^2$, но собственные значения комплексные); путать полуоси $1/\sqrt{\lambda}$ (для $A$) и $\sqrt{\lambda}$ (для $\Sigma$ в III.11).

**Практика:** виджет «линии уровня $x^\top A x$» (эллипсы, полосы, гиперболы при изменении $A$).

### I.11. Сингулярное разложение и псевдообратная

**Время:** 3 ч. **Опирается на:** I.9, I.10. **CS229:** «Principal components analysis», «Generalization» (решение минимальной нормы).

**Цели.** Ученик:
- описывает $A = USV^\top$ как «ортогональное преобразование — растяжение — ортогональное преобразование»;
- строит наилучшее приближение ранга $k$ и оценивает ошибку по сингулярным числам;
- находит псевдообратную и объясняет решение минимальной нормы.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Сингулярное разложение | singular value decomposition (SVD) | $A = USV^\top$, $U, V$ ортогональные, $S$ диагональная $\ge 0$ |
| Сингулярные числа | singular values | Корни из собственных значений $A^\top A$ |
| Малоранговое приближение | low-rank approximation | Оставить $k$ наибольших сингулярных чисел (теорема Эккарта — Янга) |
| Псевдообратная | Moore–Penrose pseudoinverse | $A^+ = V S^+ U^\top$ |
| Решение минимальной нормы | minimum-norm solution | $x = A^+ b$ — самое короткое из решений МНК |

**Типичные ошибки:** называть $U$ и $V$ «поворотами» (они могут включать отражение); писать $\Sigma$ вместо $S$ — конфликт с ковариацией.

**Практика:** виджет «окружность → эллипс по шагам»; упражнение «сжать картинку SVD».
