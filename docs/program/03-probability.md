### III.1. Вероятностное пространство

**Время:** 2 ч. **Опирается на:** 0.3, 0.4.

**Цели.** Ученик:
- задаёт пространство исходов, события и вероятность для простых экспериментов;
- выводит следствия аксиом: вероятность дополнения, объединения;
- ★ считает комбинации и число мономов степени не выше $k$: $\binom{d + k}{k}$ (пригодится для полиномиальных ядер).

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Пространство исходов | sample space | Множество $\Omega$ всех исходов |
| Событие | event | Подмножество $\Omega$ |
| Аксиомы вероятности | probability axioms | $P(A) \ge 0$, $P(\Omega) = 1$, аддитивность для несовместных |
| Формула включений-исключений | inclusion–exclusion | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ |

**Типичные ошибки:** складывать вероятности совместных событий.

**Практика:** виджет «события как области».

### III.2. Условная вероятность и независимость

**Время:** 2 ч. **Опирается на:** III.1. **CS229:** «Generative learning algorithms» (Naive Bayes assumption).

**Цели.** Ученик:
- считает условную вероятность как «сужение мира»;
- применяет формулу умножения вероятностей;
- различает независимость и условную независимость, приводит примеры, где одно есть, а другого нет.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Условная вероятность | conditional probability | $P(A \mid B) = P(A \cap B) / P(B)$ |
| Формула умножения вероятностей | chain rule of probability | $P(A_1 \cap \dots \cap A_n) = \prod_i P(A_i \mid A_1, \dots, A_{i-1})$ |
| Независимость | independence | $P(A \cap B) = P(A)P(B)$ |
| Условная независимость | conditional independence | $P(A \cap B \mid C) = P(A \mid C)P(B \mid C)$ |

**Типичные ошибки:** путать $P(A \mid B)$ и $P(B \mid A)$; считать несовместные события независимыми.

**Практика:** симуляция «условие сужает мир».

### III.3. Формула полной вероятности и Байес

**Время:** 2 ч. **Опирается на:** III.2. **CS229:** «Generative learning algorithms».

**Цели.** Ученик:
- применяет формулу полной вероятности и формулу Байеса;
- объясняет ошибку игнорирования базовой частоты на примере медицинского теста;
- обновляет вероятности последовательно по мере поступления улик.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Формула полной вероятности | law of total probability | $P(A) = \sum_k P(A \mid B_k) P(B_k)$ |
| Формула Байеса | Bayes' rule | $P(B \mid A) = \dfrac{P(A \mid B) P(B)}{P(A)}$ |
| Априорная, апостериорная | prior, posterior | До и после учёта данных |
| Базовая частота | base rate | Доля события в популяции |

**Типичные ошибки:** игнорировать базовую частоту.

**Практика:** виджет «сетка из 1000 человек»; игра «Байес-детектив» (очки по логарифмическому правилу).

### III.4. Случайные величины: PMF, PDF, CDF

**Время:** 2.5 ч. **Опирается на:** III.1, 0.7.

**Цели.** Ученик:
- описывает дискретную величину функцией вероятности, непрерывную — плотностью, любую — функцией распределения;
- пользуется индикатором: $\mathbb{E}\,1\{A\} = P(A)$;
- находит плотность $g(X)$ для монотонной $g$ (замена переменной в одномерной плотности);
- понимает, что такое независимые одинаково распределённые величины.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Случайная величина | random variable | Функция из $\Omega$ в $\mathbb{R}$ |
| Функция вероятности | probability mass function (PMF) | $p(x) = P(X = x)$ |
| Плотность | probability density function (PDF) | $P(a \le X \le b) = \int_a^b p(x)\,dx$ |
| Функция распределения | cumulative distribution function (CDF) | $F(x) = P(X \le x)$ |
| i.i.d. | independent and identically distributed | Независимые с одним распределением |

**Формулы:** $p_Y(y) = p_X(g^{-1}(y)) \left\lvert \dfrac{d}{dy} g^{-1}(y) \right\rvert$.

**Типичные ошибки:** считать значение плотности вероятностью (оно может быть больше 1).

**Практика:** виджет «плотность и CDF при перетаскивании порога».

### III.5. Матожидание, дисперсия, неравенство Йенсена

**Время:** 2.5 ч. **Опирается на:** III.4. **CS229:** «The EM algorithm» (Jensen's inequality).

**Цели.** Ученик:
- считает матожидание и дисперсию, применяет линейность матожидания и LOTUS;
- выводит $\operatorname{Var} X = \mathbb{E}X^2 - (\mathbb{E}X)^2$ и $\operatorname{Var}(aX + b) = a^2 \operatorname{Var} X$;
- применяет неравенство Йенсена (одномерная выпуклость вводится прямо здесь).

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Матожидание | expectation | Центр масс распределения |
| LOTUS | law of the unconscious statistician | $\mathbb{E}\,g(X) = \sum_x g(x)p(x)$ или $\int g(x)p(x)\,dx$ |
| Дисперсия | variance | $\mathbb{E}(X - \mathbb{E}X)^2$ |
| Неравенство Йенсена | Jensen's inequality | $f(\mathbb{E}X) \le \mathbb{E}f(X)$ для выпуклой $f$ |

**Типичные ошибки:** $\mathbb{E}\,g(X) = g(\mathbb{E}X)$; $\operatorname{Var}(X + Y) = \operatorname{Var} X + \operatorname{Var} Y$ без независимости.

**Практика:** виджет «матожидание как центр масс».

### III.6. Дискретные распределения

**Время:** 2 ч. **Опирается на:** III.5. **CS229:** «Classification and logistic regression» (Bernoulli), «Generative learning algorithms» (multinomial event model), «Generalized linear models» (Poisson).

**Цели.** Ученик:
- узнаёт по сюжету распределения Бернулли, биномиальное, геометрическое, Пуассона, категориальное, мультиномиальное;
- считает их матожидание и дисперсию.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Бернулли | Bernoulli | $P(X = 1) = \phi$ |
| Биномиальное | binomial | Число успехов в $n$ испытаниях Бернулли |
| Геометрическое | geometric | Номер первого успеха |
| Пуассона | Poisson | Число редких событий: $P(k) = e^{-\lambda}\lambda^k / k!$ |

**Типичные ошибки:** путать биномиальное и геометрическое; забывать, что у Пуассона $\mathbb{E} = \operatorname{Var} = \lambda$.

**Практика:** виджет «обозреватель распределений»; игра «Зоопарк распределений».

### III.8. Предельные теоремы и метод Монте-Карло

**Время:** 2.5 ч. **Опирается на:** III.6, III.7. **CS229:** «Generalization» (union bound, Hoeffding).

**Цели.** Ученик:
- формулирует и иллюстрирует закон больших чисел и центральную предельную теорему;
- оценивает матожидание и интеграл методом Монте-Карло и его погрешность $\sim 1/\sqrt{n}$;
- применяет оценку объединения; ★ неравенство Хёффдинга.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Закон больших чисел | law of large numbers | Выборочное среднее сходится к матожиданию |
| Центральная предельная теорема | central limit theorem | Нормированная сумма i.i.d. → $\mathcal{N}(0, 1)$ |
| Метод Монте-Карло | Monte Carlo estimation | Оценка $\mathbb{E}\,g(X)$ средним по выборке |
| Оценка объединения | union bound | $P(\cup A_i) \le \sum P(A_i)$ |
| ★ Неравенство Хёффдинга | Hoeffding's inequality | Экспоненциальная оценка отклонения среднего |

**Типичные ошибки:** считать, что ЦПТ делает нормальной каждую величину, а не сумму.

**Практика:** виджеты «бегущее среднее» и «гистограмма суммы $n$ величин»; лабораторная «ЦПТ на симуляциях».

### III.9. Совместные распределения и ковариация

**Время:** 2.5 ч. **Опирается на:** III.5, III.8. **CS229:** «Generalization» (условное матожидание), «Reinforcement learning».

**Цели.** Ученик:
- переходит от совместного распределения к маргинальным и условным;
- считает ковариацию и корреляцию и объясняет, почему некоррелированность не означает независимость;
- применяет закон полного матожидания $\mathbb{E}X = \mathbb{E}[\mathbb{E}[X \mid Y]]$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Совместное, маргинальное, условное | joint, marginal, conditional | $p(x, y)$; $p(x) = \sum_y p(x, y)$; $p(x \mid y)$ |
| Ковариация | covariance | $\operatorname{Cov}(X, Y) = \mathbb{E}(X - \mathbb{E}X)(Y - \mathbb{E}Y)$ |
| Корреляция | correlation | $\rho = \operatorname{Cov}/(\sigma_X \sigma_Y)$, $\lvert\rho\rvert \le 1$ (Коши — Буняковский) |
| Условное матожидание | conditional expectation | $\mathbb{E}[X \mid Y]$ — случайная величина, функция от $Y$ |

**Типичные ошибки:** некоррелированность = независимость.

**Практика:** игра «Угадай корреляцию»; виджет «облако точек с перетаскиванием».

### III.10. Случайные векторы и линейные преобразования

**Время:** 2 ч. **Опирается на:** III.9, I.10, II.10. **CS229:** «Principal components analysis», «Independent components analysis».

**Цели.** Ученик:
- записывает среднее и ковариационную матрицу случайного вектора;
- доказывает, что $\Sigma \succeq 0$;
- применяет $\operatorname{Cov}(AX + b) = A\Sigma A^\top$ и формулу плотности $p_Y(y) = p_X(A^{-1}(y - b))\,\lvert\det A\rvert^{-1}$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Случайный вектор | random vector | Вектор случайных величин |
| Ковариационная матрица | covariance matrix | $\Sigma = \mathbb{E}(X - \mu)(X - \mu)^\top$ |
| Линейное преобразование вектора | linear transformation | $Y = AX + b$ |

**Типичные ошибки:** $\operatorname{Cov}(AX) = A\Sigma$; забыть модуль определителя.

**Практика:** виджет «линейное преобразование облака точек».

### III.11. Многомерное нормальное распределение

**Время:** 3 ч. **Опирается на:** III.10, I.9, I.10. **CS229:** «Generative learning algorithms» (GDA), «The EM algorithm».

**Цели.** Ученик:
- записывает плотность $\mathcal{N}(\mu, \Sigma)$ и объясняет каждый множитель (существует при $\Sigma \succ 0$);
- рисует линии уровня: эллипсы с осями вдоль собственных векторов $\Sigma$ и полуосями $\propto \sqrt{\lambda_i(\Sigma)}$;
- строит выборку через $\Sigma^{1/2}$; знает, что маргинальные и условные распределения гауссовы.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Многомерное нормальное | multivariate Gaussian | $p(x) = \dfrac{1}{(2\pi)^{d/2}\lvert\Sigma\rvert^{1/2}} \exp\!\left(-\tfrac12 (x - \mu)^\top \Sigma^{-1} (x - \mu)\right)$ |
| Расстояние Махаланобиса | Mahalanobis distance | $\sqrt{(x - \mu)^\top \Sigma^{-1} (x - \mu)}$ |
| Изолинии | isocontours | Эллипсы постоянной плотности |
| ★ Условное гауссово | conditional Gaussian | $\mu_{1\mid 2} = \mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$ |

**Типичные ошибки:** полуоси $\propto 1/\sqrt{\lambda_i(\Sigma)}$ (это для матрицы формы, а в плотности стоит $\Sigma^{-1}$); читать $\lvert\Sigma\rvert$ как модуль.

**Практика:** игра «Скульптор $\Sigma$»: подогнать эллипс под облако точек; виджет «редактор $\mu$ и $\Sigma$».

### III.13. Энтропия, кросс-энтропия, KL

**Время:** 2 ч. **Опирается на:** III.5, III.6. **CS229:** «Classification and logistic regression» (log loss), «Deep learning» (cross-entropy loss), «The EM algorithm» (ELBO).

**Цели.** Ученик:
- считает энтропию, кросс-энтропию и KL-дивергенцию для дискретных распределений;
- доказывает $D_{KL}(p \,\Vert\, q) \ge 0$ через неравенство Йенсена;
- показывает, что минимизация кросс-энтропии — это максимизация правдоподобия.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Энтропия | entropy | $H(p) = -\sum p \log p$ |
| Кросс-энтропия | cross-entropy | $H(p, q) = -\sum p \log q$ |
| KL-дивергенция | Kullback–Leibler divergence | $D_{KL}(p \,\Vert\, q) = \sum p \log \dfrac{p}{q}$, не симметрична |
| ★ ELBO | evidence lower bound | Нижняя оценка логарифма правдоподобия через Йенсена |

**Типичные ошибки:** считать KL расстоянием (она не симметрична).

**Практика:** виджет «KL между двумя распределениями»; капстоун модуля — лабораторная «Наивный Байес на данных „Квартиры“».
