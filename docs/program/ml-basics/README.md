## Для кого и с чем приходить

Персона — рефрешер из курса математики: разработчик или аналитик, 6–8 часов в неделю. Нужны уроки математики: I.1–I.8 (векторы, матрицы, проекции), II.1–II.7 (градиент, матричное дифференцирование, выпуклость, градиентный спуск, Ньютон), III.1–III.7 (вероятность, распределения), IV.2–IV.3 (оценки, MLE), IV.6–IV.7 (MAP, риск и кросс-валидация), V.1 (линейная регрессия тремя способами). Урок 1.1 начинается с входной проверки: она отмечает уроки математики, которые стоит освежить.

## Проекты

### P1. «Цена квартиры»

- **После:** модуля 1 (оценка — по урокам 2.4–2.5, если пройдены; иначе — отложенная выборка).
- **Зачем:** полный цикл регрессии: данные → бейзлайн → признаки → обучение → честная оценка → анализ ошибок. В портфолио — ноутбук и README с выводами.
- **Данные:** «Квартиры» (наш синтетический, 2 000 объектов) для разминки; California Housing (20 640 районов, scikit-learn) — основной набор. Сложность: выбросы, ограниченная сверху цена, географические признаки.
- **Метрика:** RMSE в долларах на отложенной выборке; дополнительно — MAE и ошибка по срезам (по дальности от побережья).

| Этап | Что сделать | Автопроверка |
|---|---|---|
| 1. Бейзлайн | Разбиение, константная модель, линейная регрессия по всем признакам | функция разбиения детерминирована по seed; RMSE линейной модели не хуже бейзлайна-среднего |
| 2. LMS с нуля | Пакетный и стохастический спуск, масштабирование признаков | скрытые тесты: градиент совпадает с конечными разностями; веса совпадают с `LinearRegression` до $10^{-3}$ |
| 3. Признаки | Логарифмы, полиномы, взаимодействия; LWR на подвыборке | улучшение RMSE на валидации относительно этапа 1 [порог уточнить по бейзлайну] |
| 4. Оценка и ошибки | Итоговая модель один раз на тесте; ошибки по срезам; три гипотезы, что улучшить | тест не использован при выборе (проверка журнала запусков); отчёт по шаблону |

**Критерии:** корректность разбиения и отсутствие утечек; реализация LMS; обоснованность признаков; честность итоговой оценки; качество анализа ошибок; ясность отчёта — каждый на уровнях «зачтено / хорошо / отлично».

**Ловушки:** масштабирование по всей выборке до разбиения; подбор признаков по тесту; RMSE на логарифме цены без обратного преобразования; выводы по одной случайной разбивке.

**Где и сколько:** браузер (разминка) и Colab без GPU; 6–8 часов.

### P2. «Отклик на предложение банка»

- **После:** модуля 2.
- **Зачем:** классификация с несбалансированными классами и ценой ошибок — так выглядит большинство задач в продукте. В портфолио — модель, выбор порога с экономическим обоснованием, калибровка.
- **Данные:** Bank Marketing (UCI, CC BY 4.0, ~41 000 звонков, отклик ~11%). Сложность: дисбаланс; признак «длительность звонка» известен только после звонка — утечка, которую надо найти.
- **Метрика:** ожидаемая прибыль кампании при заданных стоимости звонка и выгоде от отклика; вспомогательные — PR-AUC и калиброванность (Brier).

| Этап | Что сделать | Автопроверка |
|---|---|---|
| 1. Данные и утечка | Разведка, разбиение, поиск признака-утечки | признак длительности исключён; разбиение стратифицировано |
| 2. Логистическая регрессия | С нуля (Ньютон) и `LogisticRegression`; one-hot для категорий | веса совпадают с библиотекой до $10^{-3}$ при одинаковой регуляризации |
| 3. Регуляризация и выбор | L1 и L2, $\lambda$ по кросс-валидации; кривые обучения | выбор по валидации; PR-AUC на тесте не ниже порога [уточнить по бейзлайну] |
| 4. Порог и калибровка | Порог по ожидаемой прибыли; калибровочная кривая | порог максимизирует прибыль на валидации (сверка с перебором); Brier не хуже некалиброванной модели |

**Критерии:** обнаружение утечки; корректная реализация; честный выбор гиперпараметров; экономическое обоснование порога; качество калибровки; отчёт.

**Ловушки:** accuracy при 11% положительных; порог 0.5 по умолчанию; подбор порога на тесте; калибровка на тех же данных, на которых обучали.

**Где и сколько:** Colab без GPU; 8–10 часов.

## Выходные критерии курса

Ученик без справочников:

- реализует с нуля и сверяет с scikit-learn: LMS (пакетный и стохастический), логистическую регрессию (градиентный подъём и Ньютон), softmax-регрессию, гребневую регрессию и лассо, k-кратную кросс-валидацию;
- выводит градиенты и гессиан логарифма правдоподобия логистической регрессии и объясняет вогнутость;
- строит GLM по трём допущениям для данного распределения отклика;
- выбирает метрику и порог под цену ошибок, строит ROC и PR, проверяет калибровку;
- раскладывает ошибку на шум, смещение и разброс и по кривым обучения решает, что делать дальше;
- выбирает модель без утечек: валидация, кросс-валидация, отложенный тест;
- сдаёт проекты P1 и P2 по критериям.
