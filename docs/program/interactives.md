# Интерактивы и игры курса математики

Курс «Математика для машинного обучения». Сводка из карточек уроков (`00-start.md` … `05-bridge.md`, строки «Практика»); интерактивы курсов ML — в их программах (`catalog.md`). Источник правды — карточки; при правке карточки обновите и эту таблицу. Правила игр — `docs/conventions/games.md`, виджетов — `src/README.md`, раздел «Обязательные свойства виджетов и игр».

**Итого:** 19 игр, 33 виджета, 8 лабораторных; в уроках — ячейки Python в браузере. Уроки этапа 2 (вертикальный срез) помечены **срез**.

## В каждом уроке

| Что | Как работает | Этап |
|---|---|---|
| Подсветка символов | Наведение или выбор в легенде подсвечивает символ во всех формулах, на рисунке и в коде; цвет закреплён за ролью | 1 |
| Вывод по шагам | План вывода, шаги с обоснованием, режим «сначала предскажи шаг» | 1 |
| Проверки каждые 3–5 минут | Выбор с разбором каждого неверного варианта, число, матрица, порядок шагов, «предскажи, потом проверь» | 2 |
| «Ещё задача» | Параметрические задачи с seed: новые числа при каждой попытке, ответ считает код | 2 |
| Живые числа | Число в тексте можно потянуть, и пересчитываются следствия (компонент `Scrub`) | 2 |
| Python в браузере | Ячейка Pyodide со сниппетом урока; «Открыть в Colab» для лабораторных | 2 |
| Галочка «знаю» | Ученик отмечает урок сам; курс ставит её после итоговой проверки | 2 |
| Свой вывод с проверкой каждой строки | Ученик пишет вывод, каждая строка проверяется численно, ошибка указывается точно (идеи A1, A2) | 3 |
| Размерности на лету | Форма выражения видна рядом с формулой и в коде (идея A6) | 3 |

## Пробелы и кандидаты

`docs/conventions/games.md` просит ставить игры туда, где ученики бросают курс: I.5–I.7, II.3, III.10–III.11, IV.4. Игр пока нет в I.5, I.7, III.10 и IV.4. Кандидаты (не в плане, решает заказчик):

- **I.7 «Площадь со знаком»**: по картинке параллелограмма предсказать знак и величину определителя, потом проверить; уровни подводят к вырожденной матрице.
- **III.10 «Скульптор облака»**: подобрать матрицу $A$, чтобы облако $Ax$ совпало с целевым; очки — расстояние между ковариациями $A\Sigma A^\top$ и целевой.
- **I.5 и IV.4:** игра не нужна. Здесь работает «найди ошибку» в выводе и проверка своего вывода по строкам (этап 3).
