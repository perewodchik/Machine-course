## Проект P6. «Сегменты клиентов»

- **Зачем:** сегментация — частая задача аналитика; главное — не алгоритм, а честный выбор числа кластеров и понятное описание сегментов. В портфолио — сегменты с портретами и обоснованием.
- **Данные:** Online Retail (UCI, CC BY 4.0, ~540 000 транзакций британского интернет-магазина).
- **Метрика:** без разметки: искажение и силуэт по $k$, устойчивость сегментов на бутстрэпе, интерпретируемость.
- **Этапы:** 1) признаки RFM из транзакций (автопроверка: признаки совпадают с эталонными на контрольных клиентах); 2) k-means и смесь гауссиан, выбор $k$ (автопроверка: устойчивость разбиения выше порога [уточнить]); 3) PCA для визуализации и проверка разделимости; 4) портреты сегментов и рекомендации для бизнеса.
- **Ловушки:** k-means без масштабирования; выбор $k$ только по «локтю»; интерпретация осей PCA как исходных признаков.
- **Где и сколько:** Colab без GPU; 7–9 часов.

## Выходные критерии

Ученик реализует k-means, k-means++ и EM для смеси гауссиан и объясняет связь с MLE и неравенством Йенсена; выводит нижнюю оценку правдоподобия; реализует PCA через SVD и объясняет долю объяснённой дисперсии; применяет контрастное обучение и линейную пробу; выбирает число кластеров и проверяет устойчивость; сдаёт P6.

**CS229:** «Clustering and the k-means algorithm», «EM algorithms» (mixture of Gaussians, ELBO, variational inference, VAE), «Principal components analysis», «Independent components analysis», «Self-supervised learning and foundation models».
