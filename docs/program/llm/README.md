## Проект P7. «Умный поиск по курсу»

- **Зачем:** RAG — самый частый способ применить LLM в продукте; в портфолио — поиск с измеренным качеством, а не демо «вроде отвечает».
- **Данные:** тексты наших курсов (глоссарий, карточки уроков); 100–200 вопросов с эталонными фрагментами (размечаем сами).
- **Метрика:** recall@5 и MRR для поиска; доля ответов, подтверждённых найденным фрагментом; ручная оценка 30 ответов по рубрике.
- **Этапы:** 1) разбиение текстов на фрагменты, эмбеддинги небольшой открытой моделью (автопроверка: размерности и нормировка); 2) поиск и его оценка на размеченных вопросах (автопроверка: recall@5 не ниже порога [уточнить по бейзлайну]); 3) классификатор темы вопроса линейной пробой (автопроверка: точность выше бейзлайна-частоты); 4) генерация ответа с цитатой источника и оценка; LoRA-дообучение — по желанию.
- **Ловушки:** оценка на вопросах, по которым подбирали параметры; слишком крупные или мелкие фрагменты; «оценка» без эталона.
- **Где и сколько:** Colab с GPU; 10–12 часов.

## Выходные критерии

Ученик объясняет языковую модель как цепное правило и считает перплексию; реализует внимание с маской причинности и объясняет формы матриц; выбирает между дообучением, LoRA и обучением в контексте; строит RAG-систему и измеряет качество поиска и ответов; сдаёт P7.
