# Модуль 0. Старт

**8–10 часов, 9 уроков.** Модуль снимает барьер нотации и даёт инструменты, без которых дальше не обойтись: суммы, логарифмы, производная, интеграл, NumPy. Начинается с тизера — регрессии руками, — чтобы ученик сразу увидел, куда идёт курс.

Основная персона может пройти большую часть модуля тест-аутом в уроке 0.2.

---

### 0.1. Регрессия руками за 15 минут

**Время:** 15 мин. **Опирается на:** —. **CS229:** «Linear regression» (как цель курса).

**Цели.** Ученик:
- проводит прямую через облако точек и сравнивает варианты по сумме квадратов ошибок;
- формулирует, чего не хватает, чтобы находить лучшую прямую не на глаз.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Модель | model, hypothesis | Правило, которое по признаку предсказывает ответ: $\hat y = \theta_0 + \theta_1 x$ |
| Ошибка (остаток) | residual | Разница между ответом и предсказанием |
| Функция потерь | loss, cost function | Число, которое измеряет, насколько модель плоха |

**Формулы:** $\hat y = \theta_0 + \theta_1 x$; $J = \tfrac12 \sum_i (y^{(i)} - \hat y^{(i)})^2$.

**Типичные ошибки:** минимизировать сумму ошибок со знаком (они взаимно гасятся).

**Практика:** игра «Подгони прямую» на данных «Квартиры»; в конце — карта курса: «чтобы находить минимум точно, нужны матрицы (I), градиенты (II), вероятность шума (III) и оценки (IV)».

### 0.2. Как устроен курс и входная диагностика

**Время:** 30–40 мин. **Опирается на:** 0.1.

**Цели.** Ученик:
- понимает устройство урока: циклы, проверки, выводы с обоснованиями, уровни усвоения, повторение;
- проходит адаптивную диагностику и получает персональный маршрут.

**Основные понятия:** уровень усвоения (знаком, умею, устойчиво, пора повторить); граф понятий; повторение.

**Практика:** адаптивная диагностика по графу: 3 вопроса на понятие для тест-аута, не больше 25 минут. Результат — «знаком» и ранние повторения для пропущенных уроков.

### 0.3. Язык математики: множества, отображения, кванторы

**Время:** 50 мин. **Опирается на:** —.

**Цели.** Ученик:
- читает записи с $\in$, $\subset$, $\forall$, $\exists$, $f: \mathbb{R}^n \to \mathbb{R}$;
- отличает функцию, её значение и множество значений;
- понимает $\arg\min$, $\arg\max$ и знак пропорциональности $\propto$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Множество, элемент, подмножество | set, element, subset | $x \in A$, $A \subset B$ |
| Отображение (функция) | map, function | Правило $f: A \to B$, сопоставляющее каждому элементу $A$ элемент $B$ |
| Композиция | composition | $(g \circ f)(x) = g(f(x))$ |
| $\mathbb{R}^n$ | real coordinate space | Упорядоченные наборы из $n$ чисел |
| Аргмин | argmin | Точка, в которой достигается минимум, а не сам минимум |
| Пропорционально | proportional to | $p(\theta) \propto g(\theta)$: равны с точностью до множителя, не зависящего от $\theta$ |

**Типичные ошибки:** путать $\min$ и $\arg\min$; читать $\propto$ как равенство.

**Практика:** перевод записей «туда и обратно» (текст ↔ символы).

### 0.4. Суммы, произведения, индикатор

**Время:** 60 мин. **Опирается на:** 0.3. **CS229:** нотация всех разделов; «Reinforcement learning» (дисконтированная сумма).

**Цели.** Ученик:
- раскрывает и сворачивает $\sum$ и $\prod$, переставляет порядок суммирования;
- записывает скалярное произведение и $x^\top A y$ через суммы;
- пользуется индикатором $1\{\cdot\}$ и суммой геометрического ряда.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Знак суммы, произведения | summation, product notation | $\sum_{i=1}^n a_i$, $\prod_{i=1}^n a_i$ |
| Двойная сумма | double sum | $\sum_i \sum_j a_{ij}$; порядок можно менять для конечных сумм |
| Индикатор | indicator function | $1\{A\} = 1$, если $A$ истинно, иначе $0$ |
| Геометрический ряд | geometric series | $\sum_{t=0}^{\infty} \gamma^t = \dfrac{1}{1-\gamma}$ при $\lvert\gamma\rvert < 1$ |

**Формулы:** $x^\top A y = \sum_i \sum_j x_i A_{ij} y_j$; $\sum_i 1\{y^{(i)} = k\}$ — число объектов класса $k$.

**Типичные ошибки:** выносить из-под суммы то, что зависит от индекса; путать $\left(\sum a_i\right)^2$ и $\sum a_i^2$.

**Практика:** игра «Переводчик сумм» (собрать матричную запись из индексной).

### 0.5. Экспонента, логарифм, сигмоида

**Время:** 60 мин. **Опирается на:** 0.4. **CS229:** «Classification and logistic regression».

**Цели.** Ученик:
- применяет $\log \prod = \sum \log$ и объясняет, зачем логарифмировать правдоподобие;
- выводит $g'(z) = g(z)(1 - g(z))$ для сигмоиды;
- предсказывает потерю точности при перемножении многих вероятностей во float.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Натуральный логарифм | natural logarithm | $\log = \ln$, обратная к $e^x$ |
| Сигмоида (логистическая функция) | sigmoid, logistic function | $g(z) = \dfrac{1}{1 + e^{-z}}$, переводит $\mathbb{R}$ в $(0, 1)$ |
| Потеря точности снизу | underflow | Произведение малых чисел становится нулём во float |
| log-sum-exp | log-sum-exp | Устойчивое вычисление $\log \sum e^{z_i}$ |

**Формулы:** $\log(ab) = \log a + \log b$; $g'(z) = g(z)(1-g(z))$; $1 - g(z) = g(-z)$.

**Типичные ошибки:** $\log(a + b) = \log a + \log b$; считать $\log$ десятичным.

**Практика:** игра «Underflow»: перемножать вероятности 1000 объектов, предсказать, при каком $n$ произведение станет нулём, перейти к логарифмам.

### 0.6. Производная и правило цепочки

**Время:** 60 мин. **Опирается на:** 0.5.

**Цели.** Ученик:
- дифференцирует многочлены, $e^x$, $\log x$, произведения и частные;
- применяет правило цепочки к композициям из 2–3 функций;
- проверяет производную численно: $\dfrac{f(x+h) - f(x-h)}{2h}$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Производная | derivative | Скорость изменения функции: предел отношения приращений |
| Правило цепочки | chain rule | $(g \circ f)'(x) = g'(f(x))\, f'(x)$ |
| Центральная разность | central difference | Численная оценка производной с ошибкой $O(h^2)$ |

**Типичные ошибки:** забыть внутреннюю производную; брать слишком маленький шаг $h$ во float.

**Практика:** проверка производных численно в ячейке Python.

### 0.7. Интеграл

**Время:** 70 мин. **Опирается на:** 0.6. **CS229:** «Probability review» (нормировка плотности, матожидание).

**Цели.** Ученик:
- интерпретирует интеграл как площадь и как «непрерывную сумму»;
- находит первообразные простых функций и пользуется формулой Ньютона — Лейбница;
- понимает несобственный интеграл и то, что $\int_{-\infty}^{\infty} e^{-x^2/2}\,dx = \sqrt{2\pi}$ (без вывода, вывод — в II.10).

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Определённый интеграл | definite integral | Предел сумм площадей прямоугольников |
| Первообразная | antiderivative | $F$, для которой $F' = f$ |
| Несобственный интеграл | improper integral | Интеграл по бесконечному промежутку как предел |
| Замена переменной | substitution | $\int f(g(x))\,g'(x)\,dx = \int f(u)\,du$ |

**Формулы:** $\int_a^b f(x)\,dx = F(b) - F(a)$; $\int_0^\infty \lambda e^{-\lambda x}\,dx = 1$.

**Типичные ошибки:** забыть множитель $g'(x)$ при замене; считать, что любой интеграл по $\mathbb{R}$ конечен.

**Практика:** виджет «сумма прямоугольников → площадь»; Монте-Карло-оценка интеграла в Python.

### 0.8. Минимум NumPy: массивы, формы, векторизация

**Время:** 70 мин. **Опирается на:** 0.4. **CS229:** «Deep learning» (векторизация).

**Цели.** Ученик:
- создаёт массивы, читает `shape`, различает `(n,)` и `(n, 1)`;
- пользуется `@`, транспонированием, broadcasting и агрегатами по осям;
- переписывает цикл по объектам векторизованным выражением.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Массив и форма | array, shape | `x.shape == (n, d)` |
| Матричное умножение | matrix product | `A @ B` |
| Поэлементные операции | elementwise operations | `A * B` — не матричное умножение |
| Broadcasting | broadcasting | Автоматическое растяжение измерений размера 1 |
| Векторизация | vectorization | Замена цикла операцией над массивом |

**Типичные ошибки:** `A * B` вместо `A @ B`; путаница `(n,)` и `(n, 1)` даёт матрицу `n × n` при вычитании; `np.random.seed` вместо `default_rng`.

**Практика:** лабораторная «NumPy за час»: задачи «предскажи форму результата», «векторизуй цикл», «почини баг».

### 0.9. Обозначения курса и CS229

**Время:** 30 мин. **Опирается на:** 0.3, 0.8.

**Цели.** Ученик:
- читает нотацию CS229: $x^{(i)}$, $x_j$, $n$, $d$, $\theta$, $h_\theta$, $J$, $\ell$;

**Основные понятия:** см. `docs/conventions/notation.md` — урок построен на этой таблице.

**Типичные ошибки:** читать $x^{(i)}$ как степень; считать $\lvert\Sigma\rvert$ модулем.

**Практика:** «переводчик»: фрагмент формулы из CS229 переписать словами и наоборот.
