## Проект P4. «Кредитный скоринг»

- **Зачем:** самая типичная табличная задача в банках и финтехе; в портфолио — честный конвейер, сравнение бустинга с логистической регрессией, обоснованный порог, карточка модели.
- **Данные:** Default of Credit Card Clients (UCI, CC BY 4.0, 30 000 клиентов, дефолт ~22%). Сложность: история платежей по месяцам (утечка при неправильном разбиении), категории, дисбаланс.
- **Метрика:** ROC-AUC и ожидаемые потери банка при выбранном пороге; калиброванность (Brier).
- **Этапы:** 1) схема валидации и конвейер признаков (автопроверка: преобразования обучаются только на обучающей части); 2) логистическая регрессия — бейзлайн (автопроверка: AUC не ниже порога [уточнить по бейзлайну]); 3) градиентный бустинг с ранней остановкой (автопроверка: подбор по валидации, тест не тронут); 4) порог по потерям банка и калибровка (автопроверка: порог оптимален на валидации, Brier не хуже некалиброванной); 5) интерпретация и карточка модели (данные, метрики по группам, ограничения).
- **Ловушки:** кодирование целевой по всей выборке; ранняя остановка по тесту; важность признаков бустинга как причинность; порог 0.5.
- **Где и сколько:** Colab без GPU; 10–12 часов.

## Выходные критерии

Ученик выбирает схему валидации под устройство данных; строит конвейер признаков без утечек; реализует дерево решений и градиентный бустинг с нуля; обучает CatBoost или LightGBM и объясняет влияние главных гиперпараметров; выбирает порог по цене ошибок и калибрует вероятности; объясняет прогноз через важности и SHAP и знает их ограничения; пишет карточку модели; сдаёт P4.

**CS229:** лекции «Decision trees», «Boosting» (осень 2025), «ML advice»; «Generalization» (смещение и разброс ансамблей).
