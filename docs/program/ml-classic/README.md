## Проект P3. «Фильтр сообщений»

- **Зачем:** классификация текстов и честное сравнение моделей; главный вывод — генеративная модель выигрывает при малых данных, дискриминативная — при больших. В портфолио — отчёт со сравнением и кривыми обучения.
- **Данные:** SMS Spam Collection (UCI, CC BY 4.0, 5 574 сообщения, ~13% спама); наш корпус «Отзывы» на русском (синтетика).
- **Метрика:** PR-AUC и $F_1$ при выбранном пороге; кривые обучения по $n$.
- **Этапы:** 1) мешок слов и наивный Байес с нуля (автопроверка: логарифмы вероятностей совпадают с `MultinomialNB` при том же сглаживании); 2) логистическая регрессия и SVM с линейным ядром (автопроверка: выбор $C$ по кросс-валидации, тест не тронут); 3) кривые обучения трёх моделей, точка пересечения (автопроверка: кривые построены на одинаковых разбиениях); 4) анализ ошибок и отчёт.
- **Ловушки:** словарь, построенный по всем данным до разбиения; accuracy при дисбалансе; сравнение моделей на разных разбиениях.
- **Где и сколько:** Colab без GPU; 7–9 часов.

## Выходные критерии

Ученик выводит MLE параметров GDA и показывает, что апостериорная логистическая; реализует наивный Байес со сглаживанием Лапласа; объясняет ядровой трюк и проверяет, является ли функция ядром; формулирует прямую и двойственную задачи SVM, условия KKT и роль опорных векторов; реализует упрощённый SMO; оценивает нужный объём выборки для конечного класса гипотез; связывает MAP с регуляризацией; сдаёт P3.
