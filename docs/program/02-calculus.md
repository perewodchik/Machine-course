### II.1. Частные производные и градиент

**Время:** 2.5 ч. **Опирается на:** 0.6, I.2. **CS229:** «Linear regression» (LMS).

**Цели.** Ученик:
- считает частные производные и градиент функции нескольких переменных;
- объясняет, почему градиент — направление наискорейшего роста и почему он перпендикулярен линиям уровня;
- находит производную по направлению и критические точки.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Частная производная | partial derivative | Производная по одной переменной при фиксированных остальных |
| Градиент | gradient | Вектор частных производных той же формы, что аргумент |
| Производная по направлению | directional derivative | $D_u f = \nabla f^\top u$ |
| Линия (поверхность) уровня | level set | $\{x : f(x) = c\}$ |
| Критическая точка | critical (stationary) point | $\nabla f = 0$ |

**Формулы:** $f(x + h) \approx f(x) + \nabla f(x)^\top h$.

**Типичные ошибки:** записывать градиент строкой (как в MML) — в курсе он той же формы, что $x$.

**Практика:** виджет «поле градиентов над линиями уровня».

### II.2. Многомерное правило цепочки и якобиан

**Время:** 2.5 ч. **Опирается на:** II.1, I.3. **CS229:** «Deep learning» (backpropagation).

**Цели.** Ученик:
- строит якобиан отображения $f: \mathbb{R}^n \to \mathbb{R}^m$;
- применяет правило цепочки $\nabla_x (g \circ f) = J_f^\top \nabla g$;
- считает производные по вычислительному графу вперёд и назад.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Якобиан | Jacobian | Матрица $m \times n$ частных производных $\partial f_i / \partial x_j$ |
| Дифференциал | differential | Линейная часть приращения: $df = J_f\, dx$ |
| Вычислительный граф | computational graph | Разложение функции на элементарные операции |
| Обратный проход | backward pass | Правило цепочки от выхода к входам |

**Типичные ошибки:** перемножать якобианы в неправильном порядке; путать размерности $J_f$ и $J_f^\top$.

**Практика:** виджет «вычислительный граф»: прямой и обратный проход для $L = (\theta^\top x - y)^2$.

### II.3. Матричное дифференцирование

**Время:** 3 ч. **Опирается на:** II.1, II.2, I.5. **CS229:** «Linear regression» (normal equations), «Generative learning algorithms» (MLE для GDA).

**Цели.** Ученик:
- выводит градиенты $b^\top x$, $x^\top A x$, $\operatorname{tr}(AB)$, $\log\lvert\det A\rvert$ и проверяет их конечными разностями;
- проверяет любой матричный градиент размерностями;
- выводит нормальные уравнения через градиент.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Градиент по вектору и по матрице | gradient w.r.t. vector / matrix | Той же формы, что аргумент |
| Проверка размерностей | dimension check | Форма каждого слагаемого должна совпадать |
| Проверка конечными разностями | gradient check | Сравнение с $\dfrac{f(x + h e_i) - f(x - h e_i)}{2h}$ |

**Формулы (правила в `content/formulas/rules/`):**
- $\nabla_x\, b^\top x = b$;
- $\nabla_x\, x^\top A x = (A + A^\top)x$, для симметричной $A$ — $2Ax$;
- $\nabla_A \operatorname{tr}(AB) = B^\top$;
- $\nabla_A \log\lvert\det A\rvert = A^{-\top}$.

**Типичные ошибки:** писать $\nabla_A \log\det A = A^{-\top}$ без модуля (верно только при $\det A > 0$); забывать, что для симметричной $A$ «симметричная» производная другая — CS229 это ограничение игнорирует, минимум от этого не меняется.

**Практика:** игра «Тетрис размерностей»; вывод нормальных уравнений по шагам (формула `f.normal-equations`); «найди ошибку» в выводе.

### II.4. Гессиан, ряд Тейлора, критические точки

**Время:** 2 ч. **Опирается на:** II.3, I.10. **CS229:** «Classification and logistic regression» (Newton's method).

**Цели.** Ученик:
- считает гессиан и строит квадратичное приближение функции;
- классифицирует критическую точку (минимум, максимум, седло) по собственным значениям гессиана.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Гессиан | Hessian | Матрица вторых производных $\nabla^2 f$ |
| Ряд Тейлора второго порядка | second-order Taylor expansion | $f(x + h) \approx f(x) + \nabla f^\top h + \tfrac12 h^\top H h$ |
| Седловая точка | saddle point | $\nabla f = 0$, у $H$ есть собственные значения разных знаков |

**Типичные ошибки:** считать, что $\nabla f = 0$ означает минимум.

**Практика:** игра «Минимум, максимум или седло» (классификация по картинке и по спектру).

### II.5. Выпуклость

**Время:** 2.5 ч. **Опирается на:** II.4. **CS229:** «Classification and logistic regression», «Generalized linear models» (выпуклость NLL).

**Цели.** Ученик:
- проверяет выпуклость множества и функции по определению и по критериям первого и второго порядка;
- доказывает, что у выпуклой функции локальный минимум глобален;
- доказывает выпуклость функции потерь логистической регрессии через операции, сохраняющие выпуклость.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Выпуклое множество | convex set | С любыми двумя точками содержит отрезок между ними |
| Выпуклая функция | convex function | $f(tx + (1-t)y) \le t f(x) + (1-t) f(y)$ |
| Критерий первого порядка | first-order condition | $f(y) \ge f(x) + \nabla f(x)^\top (y - x)$ |
| Критерий второго порядка | second-order condition | $H \succeq 0$ на открытой выпуклой области (для $C^2$ — эквивалентность) |
| Строгая выпуклость | strict convexity | $H \succ 0$ достаточно, но не необходимо ($x^4$) |
| Операции, сохраняющие выпуклость | convexity-preserving operations | Неотрицательные суммы, композиция с аффинной функцией, максимум |

**Типичные ошибки:** проверять $H \succeq 0$ в одной точке; считать, что строгая выпуклость требует $H \succ 0$.

**Практика:** виджет «хорда над графиком»; упражнение «выпукла ли функция» с разбором.

### II.6. Градиентный спуск и SGD

**Время:** 3 ч. **Опирается на:** II.5. **CS229:** «Linear regression» (batch vs stochastic gradient descent), «Classification and logistic regression» (gradient ascent), «Clustering and the k-means algorithm».

**Цели.** Ученик:
- реализует градиентный спуск и подъём; объясняет роль шага и условие сходимости $\eta < 2/\lambda_{\max}$ на квадратичной функции;
- сравнивает полный, стохастический и мини-батч спуск;
- объясняет обусловленность и покоординатный спуск.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Градиентный спуск (подъём) | gradient descent (ascent) | $\theta := \theta - \eta \nabla J(\theta)$ |
| Шаг обучения | learning rate | $\eta$; слишком большой — расходимость |
| Стохастический градиент | stochastic gradient descent (SGD) | Градиент по одному объекту или мини-батчу |
| Число обусловленности | condition number | $\lambda_{\max} / \lambda_{\min}$; чем больше, тем медленнее спуск |
| Покоординатный спуск | coordinate descent | Оптимизация по одной переменной за раз |

**Типичные ошибки:** путать спуск и подъём; оценивать сходимость SGD по одному шагу.

**Практика:** игра «Спуск в тумане» и «Порог расходимости»; капстоун модуля — лабораторная «Квартиры: GD, SGD и нормальные уравнения».

### II.7. Метод Ньютона

**Время:** 2 ч. **Опирается на:** II.4, II.6. **CS229:** «Classification and logistic regression» (Newton's method).

**Цели.** Ученик:
- выводит одномерный метод Ньютона как поиск нуля производной;
- применяет многомерную форму $\theta := \theta - H^{-1}\nabla\ell(\theta)$;
- сравнивает число итераций и цену шага с градиентным спуском.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Метод Ньютона | Newton's method (Newton–Raphson) | Шаг к минимуму квадратичного приближения |
| Квадратичная сходимость | quadratic convergence | Число верных знаков удваивается за итерацию |

**Типичные ошибки:** обращать гессиан вместо решения системы; применять метод вдали от минимума без контроля шага.

**Практика:** виджет «касательные Ньютона»; упражнение «шаг Ньютона для логистической регрессии» (подготовка к V.2).

### II.8. Множители Лагранжа

**Время:** 2.5 ч. **Опирается на:** II.5, I.10. **CS229:** «Principal components analysis», «Generative learning algorithms» (MLE категориального распределения), «The EM algorithm» (веса смеси).

**Цели.** Ученик:
- решает задачу с ограничениями-равенствами через лагранжиан;
- выводит, что максимум $u^\top \Sigma u$ при $\lVert u\rVert = 1$ достигается на собственном векторе;
- находит MLE категориального распределения с ограничением $\sum_k \phi_k = 1$.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Ограничение-равенство | equality constraint | $h(x) = 0$ |
| Лагранжиан | Lagrangian | $\mathcal{L}(x, \lambda) = f(x) + \lambda h(x)$ |
| Множитель Лагранжа | Lagrange multiplier | $\lambda$; в оптимуме $\nabla f \parallel \nabla h$ |

**Типичные ошибки:** забыть уравнение самого ограничения; путать $\lambda$ множителя и собственное значение (в PCA они совпадают — разобрать явно).

**Практика:** виджет «касание линии уровня и ограничения».

### II.9. ★ Двойственность и условия KKT

**Время:** 2 ч. **Опирается на:** II.8. **CS229:** «Support vector machines» (Lagrange duality, optimal margin classifiers).

**Цели.** Ученик:
- записывает задачу с ограничениями-неравенствами и её двойственную;
- объясняет слабую и сильную двойственность и условия KKT, включая дополняющую нежёсткость.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Двойственная задача | dual problem | Максимизация нижней оценки по множителям |
| Слабая / сильная двойственность | weak / strong duality | $d^* \le p^*$; равенство при условиях (Слейтер) |
| Условия Каруша — Куна — Таккера | KKT conditions | Стационарность, допустимость, дополняющая нежёсткость |
| Дополняющая нежёсткость | complementary slackness | $\alpha_i g_i(w) = 0$ |

**Практика:** виджет «активное и неактивное ограничение» (подготовка к опорным векторам в V.5).

### II.10. Кратные интегралы и замена переменных

**Время:** 2 ч. **Опирается на:** 0.7, II.2, I.7. **CS229:** «Independent components analysis», «Probability review» (многомерные плотности).

**Цели.** Ученик:
- считает двойной интеграл как повторный;
- применяет замену переменных с $\lvert\det J\rvert$;
- выводит $\int e^{-x^2/2}\,dx = \sqrt{2\pi}$ через полярные координаты.

**Основные понятия**

| Понятие | English | Коротко |
|---|---|---|
| Кратный интеграл | multiple integral | Интеграл по области в $\mathbb{R}^n$ |
| Теорема Фубини | Fubini's theorem | Кратный интеграл как повторный |
| Замена переменных | change of variables | $dx = \lvert\det J\rvert\, du$ |

**Типичные ошибки:** забыть модуль якобиана; забыть якобиан полярных координат $r$.

**Практика:** виджет «как растягивается площадь при замене переменных» (связь с определителем из I.7).
