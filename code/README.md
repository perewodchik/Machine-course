# code — Python-часть курса

Единый источник Python-кода: сниппеты уроков, проверки для лабораторных и численная проверка формул.

```bash
cd code
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest                    # формулы, выводы, сниппеты, проверки
```

| Путь | Что |
|---|---|
| `mlf/check.py` | Проверки ответов в лабораторных с сообщениями для ученика (например, про `(n,)` и `(n, 1)`) |
| `mlf/formulas.py` | Численная проверка `content/formulas/**.yaml`: тождества, градиенты (конечные разности), шаги выводов |
| `snippets/<раздел>/*.py` | Код уроков. Регионы `# region name` … `# endregion` вставляются в урок (`<PyCode src="la/normal_equations.py#solve">`) и в ноутбук |
| `tests/` | pytest. `test_formulas.py` проходит по всем формулам на трёх seed и проверяет, что подложенная ошибка в выводе ловится |

Правила:

- Сниппет — это функция с докстрингом, без глобального состояния; данные — через `seed`.
- Числа, которые показывает урок (как `θ = [0.798 0.548]`), закреплены тестом: урок и код не разойдутся.
- В проверках формул вектор-столбец `[d, 1]` — одномерный массив длины `d`.
- Код должен работать и в CPython (Colab, локально), и в Pyodide (браузер): без C-расширений, кроме NumPy и SciPy.
