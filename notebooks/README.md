# notebooks — лабораторные

Исходники лабораторных — Python-файлы в формате Jupytext (`src/**/*.py`). Готовые `.ipynb` собираются скриптом и не правятся руками.

```bash
pip install -e "code[dev]"
python scripts/build_notebooks.py --solutions /tmp/nb-solutions   # ученические .ipynb + версия с решениями
pytest --nbmake /tmp/nb-solutions                                 # решения выполняются без ошибок
```

| Путь | Что |
|---|---|
| `src/<раздел>/<имя>.py` | Исходник: ячейки `# %%`, решения между `# BEGIN SOLUTION` и `# END SOLUTION` |
| `<раздел>/<имя>.ipynb` | Версия для ученика: решения заменены на `raise NotImplementedError`, выходов нет |

Где запускать:

| Среда | Когда | Как |
|---|---|---|
| В уроке (Pyodide) | Короткие ячейки, 3–10 строк | Кнопка «Запустить», без аккаунта |
| Google Colab | Основная среда для лабораторных: полный CPython | `https://colab.research.google.com/github/perewodchik/Machine-course/blob/<тег>/notebooks/<путь>.ipynb` |
| JupyterLite | Лабораторная без аккаунта, прямо в браузере | Кнопка «Открыть в браузере» (этап 3) |
| Локально | Для тех, у кого есть Python | `pip install -e code` и Jupyter |

Ограничения Colab: нужен Google-аккаунт, репозиторий с ноутбуками должен быть публичным, версии пакетов в Colab меняются без предупреждения (их ловит еженедельный прогон CI). Ссылки ведут на тег релиза, а не на ветку: код в ноутбуке совпадает с версией урока.

Правила:

- Ячейка проверки идёт сразу после задания и вызывает `mlf.check`: ученик видит понятное сообщение, а не трассировку.
- Код данных и решений берётся из `code/snippets` (директива `# snippet: путь#регион`; на этапе 2 её раскроет сборка).
- В ноутбуках только базовые `ipywidgets` (`interact`, слайдеры): они работают и в Colab, и в JupyterLite.
